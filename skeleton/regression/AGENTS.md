# AGENTS.md

이 폴더에서 일하는 코딩 에이전트(Codex, Claude Code 등)가 따르는 규칙이다.
사람이 R 코드를 직접 쓸 때도 같은 규칙을 따른다.

## 이 폴더

[회귀분석 - 상관에서 위계적 회귀까지](https://qmakescl.github.io/class-material/statistics/regression-analysis.html)
자료의 01–08절 "프롬프트로 따라 하기"를 하는 실습 폴더다.

- 자료: `dataset/raw/Galton.tsv`(갈턴의 부모와 자녀 키, 01–06·08절), R 패키지 HSAUR3의 `BtheB`(우울증 임상시험, 07절).
- 절마다 **분석 → 보고서** 순서로 일한다. 원자료를 들여와 다듬거나 범주의 순서를 정해야 하는 절(01, 05, 07)만 그 앞에 **데이터 처리**를 한다.
- 02–06, 08절은 01절이 만든 `dataset/working/galton_cm.rds`를 읽는다. 그 파일이 없으면 01절의 데이터 처리부터 하라고 사용자에게 알린다.

## 폴더와 경로

```text
regression/
├── AGENTS.md        # 이 규칙
├── scripts/         # R 스크립트 (.R)
├── dataset/
│   ├── raw/         # 원자료. 읽기만 한다
│   └── working/     # 데이터 처리 단계가 저장한 분석용 자료 (.rds)
└── output/          # 표(CSV), 그림(PNG), 보고서(.md)
```

- 작업 폴더는 언제나 `regression/`이다. 스크립트 안의 경로는 이 폴더를 기준으로 한 상대 경로로
  적는다. 예: `dataset/raw/Galton.tsv`, `output/reg02_coef.csv`.
- `setwd()`나 사용자 컴퓨터의 절대 경로(`/Users/...`, `C:\...`)를 쓰지 않는다.
- `dataset/raw/`의 파일은 고치거나 덮어쓰지 않는다. 단위 변환(인치 → cm, `× 2.54`)처럼
  고칠 것은 코드에서 처리하고, 저장할 때는 `dataset/working/`에 새 파일로 쓴다.
  패키지에 든 자료를 원자료 사본으로 남길 때만 `dataset/raw/`에 새 파일을 만든다(예: `btheb.csv`).
- 파일 이름은 절 번호로 시작한다: 데이터 처리 `scripts/reg05_prepare.R`, 분석 `scripts/reg05_dummy.R`,
  표 `output/reg05_coef.csv`, 그림 `output/reg05_lines.png`, 보고서 `output/reg05_report.md`.
  프롬프트가 파일 이름을 정해 주면 그것을 따른다.

## R 규칙

- **tidyverse를 쓴다.** 스크립트 맨 위에서 `library(tidyverse)`로 불러온다.
  - 파일은 readr(`read_tsv()`, `read_csv()`, `write_csv()`, `read_rds()`, `write_rds()`)로 읽고 쓴다.
  - 자료 가공은 dplyr(`filter()`, `mutate()`, `select()`, `summarise()`, `across()`)로 한다.
  - 파이프는 tidyverse(magrittr)의 `%>%`를 쓴다. R 기본 파이프 `|>`는 쓰지 않는다.
- 모형 적합은 R 기본 함수(`lm()`, `glm()`, `anova()`, `predict()`, `confint()`)를 쓴다.
  결과를 표로 정리할 때는 tidyverse와 함께 설치되는 **broom**(`tidy()`, `glance()`, `augment()`)을 쓴다.
- **범주형 변수는 factor로 만들고 범주의 순서를 직접 정한다**(`factor(x, levels = ..., labels = ...)`).
  첫 수준이 회귀의 기준 범주가 된다. 글자 그대로 두거나 숫자 코드로 모형에 넣지 않는다.
  순서형 factor(`ordered = TRUE`)는 사용자가 원할 때만 쓴다.
- 표의 숫자가 잘려 보이지 않도록 스크립트 앞부분에 `options(pillar.sigfig = 7, width = 150)`을 둔다.
- 결과 표는 콘솔에 출력하고(결과 화면), 같은 표를 `output/`에 CSV로 저장한다. 보고서 단계는 이 CSV만 읽는다.
- 회귀모형을 적합하면 계수표와 함께 **모형 전체의 검정과 설명력**을 반드시 저장한다.
  선형회귀는 F, 두 자유도, p, 결정계수, 수정 결정계수, 잔차 표준오차,
  로지스틱 회귀는 설명변수가 없는 모형과의 가능도비 χ², 자유도, p, McFadden 의사 결정계수, AIC.
- 결과를 사람에게 보일 때는 단위(cm, 점)를 함께 적는다.

## 시각화 규칙

- **그림은 tidyverse에 들어 있는 ggplot2로만 그린다.** base 그래픽(`plot()`, `hist()`,
  `curve()`, `barplot()`)과 다른 그래픽 패키지는 쓰지 않는다.
- 그림은 `ggsave()`로 `output/`에 PNG로 저장한다. 크기는 인치로 정한다(예: `width = 6, height = 4.5`).
- 축 이름과 제목은 한국어로 쓰고, 단위를 괄호로 붙인다. 예: `"아버지 키 (cm)"`.
- 색은 자료 점에 `#2f6fed`(파랑), 두 번째 집단·곡선에 `#e2662a`(주황), 직선·기준선에 `#0b1220`을 쓴다.

## 한글 글꼴 규칙

- **한글은 showtext로 Google Fonts의 Noto Sans KR을 쓴다.** 그림을 그리는 스크립트 앞부분에 다음을 둔다.

  ```r
  library(showtext)
  font_add_google("Noto Sans KR", "notosanskr")
  showtext_auto()
  showtext_opts(dpi = 300)   # ggsave()의 기본 해상도와 맞춘다
  ```

- ggplot의 테마에는 `base_family = "notosanskr"`를 준다. 예: `theme_minimal(base_family = "notosanskr")`.
- extrafont, 시스템에 설치된 다른 한글 글꼴, `par(family = ...)`는 쓰지 않는다.
- `font_add_google()`은 처음 한 번 인터넷에서 글꼴을 내려받는다. 인터넷이 없어 실패하면
  다른 글꼴로 바꾸지 말고 그 사실을 사용자에게 알린다.

## 보고서 규칙

- 보고서는 output/ 에 Markdown 파일(.md)로 쓴다.
- 숫자는 분석 단계가 저장한 표 파일(output/*.csv)에서만 가져온다. 표에 없는 통계량을 새로 추정하지 않는다. 표의 수를 더하거나 나누는 간단한 계산은 해도 되고, 그렇게 했다고 밝힌다. 필요한 숫자가 표에 없으면 지어내지 말고 무엇이 더 필요한지 알린다.
- 통계 기호(r, t, F, p, b, M, SD, R²)는 기울임으로 쓰고 자유도는 기호 뒤 괄호에 넣는다. 예: r(463) = .39, t(463) = 9.15, F(1, 463) = 83.72, χ²(2) = 145.72.
- 소수는 둘째 자리까지 쓴다. p 는 셋째 자리까지 쓰고 .001 보다 작으면 p < .001 로 쓴다. 셋째 자리로 반올림하면 .05 가 되어 판단이 가려지는 p, 둘째 자리에서 0 이 되는 값은 한 자리 더 쓴다.
- 1 을 넘을 수 없는 값(r, p, R², β)은 소수점 앞의 0 을 쓰지 않는다(.39). 1 을 넘을 수 있는 값(b, 오즈비, 평균)은 0 을 쓴다(0.45).
- 신뢰구간은 "95% CI [하한, 상한]" 으로 쓴다.
- 회귀모형의 결과는 먼저 모형 전체를 보고한다. 선형회귀는 모형 전체의 F 검정과 그 유의성, 결정계수(R²), 수정 결정계수(수정 R²)를 쓴다. 로지스틱 회귀는 설명변수가 없는 모형과 비교한 가능도비 χ² 검정과 그 유의성, 의사 결정계수(McFadden R²)를 쓰고, 수정 R² 대신 AIC로 모형을 견준다.
- 결과 문단은 무엇을 분석했나 → 모형 전체의 검정과 설명력 → 개별 효과(방향, 크기, 신뢰구간, 검정) → 해석의 순서로 쓰고, 효과의 크기를 단위(cm, 점)와 함께 말로 풀어 쓴다. 모형 전체가 유의하다는 것과 개별 변수의 효과가 유의하다는 것은 구별해 쓴다.
- 보고서에는 결과 문단과 함께 표를 반드시 넣는다. 문단에 쓴 숫자는 표에도 있어야 한다.
- 회귀모형의 보고서는 첫 표로 "모형의 유의성" 표를 둔다. 선형회귀는 모형마다 F, 두 자유도, p, R², 수정 R², 잔차 표준오차를, 로지스틱 회귀는 가능도비 χ², 자유도, p, 의사 R², AIC를 적는다. 모형을 여럿 비교하거나 단계를 나누었으면 모형(단계)마다 한 행씩 둔다. 이어서 회귀계수 표(b, SE, 95% CI, t 또는 z, p, 로지스틱은 오즈비)를 둔다.
- 범주형 설명변수가 있으면 무엇이 기준 범주인지 밝힌다.
- 표에는 "표 1-1"처럼 번호와 제목을 붙이고, 단위와 약어, 검정의 영가설은 표 아래 "주."에 적는다. 문단에서는 "(표 1-1)"처럼 표를 가리킨다.
- 유의하지 않은 결과를 "효과가 없다"로 쓰지 않는다. 상관이나 회귀계수를 원인으로 쓰지 않는다.

## 실행과 보고

- 스크립트를 쓰면 `regression/`에서 `Rscript scripts/<파일>.R`로 실제로 실행해 오류가 없는지 확인한다.
- 사용자에게는 실행한 명령, 콘솔에 나온 주요 수치, 저장한 파일 경로를 알린다.
  숫자를 지어내거나 실행하지 않은 결과를 적지 않는다.
- 설명은 한국어로 한다. 통계 용어는 자료 페이지의 표기를 따른다(예: 영가설, 대안가설, 결정계수, 수정 결정계수).
