점추정과 신뢰구간

하나의 숫자로 모수를 짚어내는 점추정에서 출발해, 그 추정이 얼마나 믿을 만한지를 구간으로 말해주는 신뢰구간까지 — 직접 표본을 뽑아보며 확인합니다.

01

점추정

모수 하나를 대표하는 값 하나를 계산하는 가장 단순한 추론 방법입니다.

Point Estimation

추정량과 추정치

모수 \(\theta\)를 추정하기 위해 표본 \(X_{1},\ldots ,X_{n}\)의 함수로 정의한 확률변수를 추정량(estimator)이라 하고, 실제로 관측된 표본값 \(x_{1},\ldots ,x_{n}\)을 대입해 얻은 구체적인 숫자를 추정치(estimate)라 부릅니다.

\[\hat{\theta } = g(X_{1}, X_{2}, \ldots , X_{n})\]
추정량 — 표본을 뽑기 전에는 값이 정해지지 않은 확률변수

가장 흔한 예는 모평균 \(\mu\)의 추정량으로 쓰는 표본평균입니다.

\[\bar{X} = \frac{X_{1} + X_{2} + \cdots + X_{n}}{n}\]

아래 버튼을 누르면 학생 6명의 통계 시험 점수를 새로 뽑아봅니다. 왼쪽은 언제나 같은 형태를 가진 추정량, 오른쪽은 표본을 뽑을 때마다 달라지는 추정치입니다.

추정량 (고정된 식)

\[\bar{X} = \frac{X_{1}+\cdots +X_{6}}{6}\]

추정치 (뽑을 때마다 달라짐)

–

추정량의 평균, 분산, 표준편차

위 버튼을 여러 번 눌러 보면 추정치가 매번 달라집니다. 즉 추정량 \(\bar{X}\)는 표본을 뽑기 전에는 값이 정해지지 않은 확률변수이고, 따라서 다른 확률변수처럼 분포와 그 분포의 평균·분산·표준편차를 가집니다. 이 세 값이 추정량이 “어디를 중심으로, 얼마나 흩어져서” 나오는지를 말해 줍니다.

모집단의 평균이 \(\mu\), 분산이 \(\sigma^2\)이고 표본 \(X_1, \ldots, X_n\)이 서로 독립이라고 하면 표본평균에 대해 다음이 성립합니다.

\[E[\bar{X}] = \mu, \qquad \mathrm{Var}(\bar{X}) = \frac{\sigma^{2}}{n}, \qquad \mathrm{SD}(\bar{X}) = \sqrt{\mathrm{Var}(\bar{X})} = \frac{\sigma}{\sqrt{n}}\]
평균 · 분산 · 표준편차 (추정량 \(\bar{X}\)의 분포에 대한 값)

평균 \(E[\bar{X}]\) — 중심

표본을 무수히 반복해서 뽑았을 때 추정치들이 모이는 중심입니다. \(E[\bar{X}] = \mu\)이므로 표본평균은 모평균을 중심으로 나옵니다.

분산 \(\mathrm{Var}(\bar{X})\) — 흩어짐

추정치들이 그 중심에서 얼마나 멀리 퍼지는지를 제곱 단위로 나타냅니다. 표본이 클수록 \(1/n\)배로 줄어듭니다.

표준편차 \(\mathrm{SD}(\bar{X})\) — 원래 단위의 흩어짐

분산의 제곱근으로, 점수라면 “점” 단위로 읽습니다. 추정량의 표준편차를 특별히 표준오차(standard error, SE)라 부릅니다.

모르는 \(\sigma\)는 \(s\)로 대체

\(\sigma\)를 모를 때는 표본표준편차 \(s\)로 바꾼 추정된 표준오차 \(\widehat{\mathrm{SE}} = s/\sqrt{n}\)을 씁니다.

왜 이 값들이 나올까? 기댓값의 선형성과 독립인 변수들의 분산의 덧셈 성질만 쓰면 됩니다.

\[E[\bar{X}] = \frac{1}{n}\sum_{i=1}^{n}E[X_i] = \frac{1}{n}\cdot n\mu = \mu\] \[\mathrm{Var}(\bar{X}) = \frac{1}{n^{2}}\sum_{i=1}^{n}\mathrm{Var}(X_i) = \frac{1}{n^{2}}\cdot n\sigma^{2} = \frac{\sigma^{2}}{n}\]

상수 \(1/n\)이 분산에서는 제곱(\(1/n^2\))되어 밖으로 나오는 점에 주의하세요. 이 유도는 아래 “좋은 추정량의 성질”의 펼침 메뉴에서 숫자 예제와 함께 다시 다룹니다.

숫자로 이해하기. 위의 통계 시험 점수를 모집단 평균 \(\mu = 75\), 표준편차 \(\sigma = 8\)로 두고, 표본크기 \(n\)을 바꿔 봅니다.

  • 분산은 \(1/n\)배: \(n=6\)에서 \(n=24\)(4배)로 늘리면 분산은 \(10.667 \to 2.667\), 정확히 \(1/4\)이 됩니다.

Properties of Estimators

좋은 추정량의 성질

같은 모수를 추정하는 방법은 여러 가지일 수 있습니다. 그중 무엇이 더 나은 추정량인지 판단하는 기준은 다음과 같습니다.

불편성 (Unbiasedness)

추정량의 기댓값이 참값과 정확히 일치하면 불편추정량이라 합니다. 체계적으로 크거나 작게 치우치지 않는다는 뜻입니다.

\(E[\hat{\theta }] = \theta\)

효율성 (Efficiency)

불편추정량들 중에서는 분산이 가장 작은 추정량이 더 효율적입니다. 값이 참값 주변에 더 촘촘히 모인다는 뜻입니다.

\(\mathrm{Var}(\hat{\theta }_{1}) < \mathrm{Var}(\hat{\theta }_{2}) \ \Rightarrow\ \hat{\theta }_{1}\text{이 더 효율적}\)

일치성 (Consistency)

표본크기 \(n\)이 커질수록 추정치가 참값에 확률적으로 가까워지는 성질입니다. 자료가 많아질수록 믿을 만해집니다.

\(\hat{\theta}_{n} \xrightarrow{p} \theta \quad (n \to \infty)\)

충분성 (Sufficiency)

표본이 가진 모수에 대한 정보를 하나도 잃지 않고 요약해 담고 있으면 충분통계량이라 합니다.

더 이상의 정보가 표본에 남아있지 않음

불편성과 효율성은 양궁 과녁에 비유하면 이해하기 쉽습니다. 빨간 십자가 참값, 파란 점들이 반복해서 얻은 추정치입니다.

불편성 — 왜 \(E[\bar{X}] = \mu\)이고, 분산은 왜 \(n-1\)로 나눌까? 수식 · 숫자
수식 전개 ① 표본평균은 불편추정량

기댓값의 선형성 \(E[aX + bY] = aE[X] + bE[Y]\)를 쓰면 됩니다. 각 \(X_i\)는 같은 모집단에서 뽑았으므로 \(E[X_i] = \mu\)입니다.

\[E[\bar{X}] = E\!\left[\frac{1}{n}\sum_{i=1}^{n} X_i\right] = \frac{1}{n}\sum_{i=1}^{n} E[X_i] = \frac{1}{n}\cdot n\mu = \mu\]

따라서 \(\mathrm{Bias}(\bar{X}) = E[\bar{X}] - \mu = 0\)입니다.

수식 전개 ② \(n\)으로 나눈 분산은 치우친다

표본분산을 만들 때 가장 자연스러운 식은 편차 제곱의 평균, 즉 \(n\)으로 나눈 값입니다. 그런데 이 값의 기댓값이 \(\sigma^2\)이 되는지 확인해 보면 그렇지 않습니다. 아래에서 단계별로 보입니다. 쓰는 사실은 세 가지뿐입니다.

  • \(E[X_i] = \mu\), \(\mathrm{Var}(X_i) = E[(X_i-\mu)^2] = \sigma^2\) (\(X_i\)는 같은 모집단에서 독립으로 뽑음)
  • \(\displaystyle\sum_{i=1}^{n}(X_i - \mu) = n\bar{X} - n\mu = n(\bar{X}-\mu)\)
  • \(\mathrm{Var}(\bar{X}) = \sigma^2/n\) (독립인 변수들의 합의 분산은 분산의 합: \(\dfrac{1}{n^2}\cdot n\sigma^2\))

단계 1. 편차를 \(\mu\) 기준으로 다시 쓰기. 각 편차에 \(\mu\)를 더하고 빼면 \(\bar{X}\)로부터의 편차를 “\(\mu\)로부터의 편차” 둘의 차로 나타낼 수 있습니다.

\[X_i - \bar{X} = (X_i - \mu) - (\bar{X} - \mu)\]

단계 2. 제곱해서 모두 더하기. \((a-b)^2 = a^2 - 2ab + b^2\)를 각 항에 적용하고 \(i=1\)부터 \(n\)까지 합합니다. \(\bar{X} - \mu\)는 \(i\)에 관계없는 상수이므로 합 기호 밖으로 나옵니다.

\[\sum_{i=1}^{n}(X_i - \bar{X})^2 = \sum_{i=1}^{n}(X_i - \mu)^2 \;-\; 2(\bar{X}-\mu)\sum_{i=1}^{n}(X_i - \mu) \;+\; \sum_{i=1}^{n}(\bar{X}-\mu)^2\]

단계 3. 가운데 항과 마지막 항 정리. 위의 두 번째 사실 \(\sum(X_i-\mu) = n(\bar{X}-\mu)\)를 가운데 항에 넣고, 마지막 항은 같은 값을 \(n\)번 더한 것이라 \(n(\bar{X}-\mu)^2\)입니다.

\[-2(\bar{X}-\mu)\cdot n(\bar{X}-\mu) + n(\bar{X}-\mu)^2 = -2n(\bar{X}-\mu)^2 + n(\bar{X}-\mu)^2 = -n(\bar{X}-\mu)^2\]

따라서 다음 항등식이 성립합니다. (이 식은 어떤 표본에서도 항상 맞는, 확률과 무관한 대수 관계입니다.)

\[\sum_{i=1}^{n}(X_i - \bar{X})^2 = \sum_{i=1}^{n}(X_i - \mu)^2 - n(\bar{X} - \mu)^2\]

우변의 뜻을 읽어 보면, \(\bar{X}\) 주변의 흩어짐은 \(\mu\) 주변의 흩어짐에서 \(n(\bar{X}-\mu)^2\)만큼을 뺀 값입니다. 뺄셈의 대상이 0 이상이므로 언제나 \(\bar{X}\) 주변의 흩어짐이 더 작거나 같습니다.

단계 4. 양변에 기댓값 취하기. 기댓값은 합과 상수배를 그대로 통과합니다(선형성).

\[E\!\left[\sum_{i=1}^{n}(X_i - \bar{X})^2\right] = \sum_{i=1}^{n}E\big[(X_i-\mu)^2\big] - n\,E\big[(\bar{X}-\mu)^2\big]\]

첫 항: \(E[(X_i-\mu)^2] = \sigma^2\)이 \(n\)개이므로 \(n\sigma^2\).
둘째 항: \(E[\bar{X}] = \mu\)이므로 \(E[(\bar{X}-\mu)^2]\)는 \(\bar{X}\)의 분산 \(\mathrm{Var}(\bar{X}) = \sigma^2/n\) 그 자체입니다.

\[E\!\left[\sum_{i=1}^{n}(X_i - \bar{X})^2\right] = n\sigma^2 - n\cdot\frac{\sigma^2}{n} = n\sigma^2 - \sigma^2 = (n-1)\,\sigma^2\]

단계 5. 어느 값으로 나눠야 불편이 되는지 결정. 위 결과를 어떤 수 \(c\)로 나눈 추정량 \(\dfrac{1}{c}\sum(X_i-\bar{X})^2\)의 기댓값은 \(\dfrac{(n-1)\sigma^2}{c}\)입니다. 이것이 \(\sigma^2\)과 같으려면 \(c = n-1\)이어야 합니다.

\[E[\tilde{S}^2] = E\!\left[\frac{1}{n}\sum(X_i-\bar{X})^2\right] = \frac{n-1}{n}\sigma^2 < \sigma^2, \qquad E[S^2] = E\!\left[\frac{1}{n-1}\sum(X_i-\bar{X})^2\right] = \sigma^2\]

\(n\)으로 나눈 \(\tilde{S}^2\)의 편향은 \(\mathrm{Bias}(\tilde{S}^2) = \dfrac{n-1}{n}\sigma^2 - \sigma^2 = -\dfrac{\sigma^2}{n}\)로, 항상 작게 치우치고 \(n\)이 커질수록 0에 가까워집니다.

직관적인 이유 두 가지.
① 중심이 표본에 맞춰져 있다. \(\bar{X}\)는 \(\sum(X_i-c)^2\)를 가장 작게 만드는 \(c\)입니다. 표본에서 계산한 \(\bar{X}\) 주변으로 편차를 재면, 진짜 중심 \(\mu\) 주변으로 잴 때보다 항상 작게 나옵니다(단계 3의 \(-n(\bar{X}-\mu)^2\)). 이만큼이 체계적으로 모자라는 부분입니다.
② 자유도가 \(n-1\)이다. \(\bar{X}\)를 먼저 정하고 나면 편차 \(X_i-\bar{X}\)들의 합은 항상 0이라, \(n\)개 편차 중 \(n-1\)개가 정해지면 마지막 하나는 자동으로 정해집니다. 실제로 자유롭게 움직이는 편차는 \(n-1\)개이므로 \(n-1\)로 나누어야 “편차 한 개당 평균”이 맞습니다.
숫자로 확인 (공통 예제, \(n=2\))
  1. 표본평균 9개의 평균: \(\dfrac{2+3+4+3+4+5+4+5+6}{9} = \dfrac{36}{9} = 4 = \mu\) ✓ 불편.
  2. \(n-1 = 1\)로 나눈 \(s^2\)의 평균: \(\dfrac{24}{9} \approx 2.667 = \sigma^2\) ✓ 불편.
  3. \(n = 2\)로 나눈 \(\tilde{s}^2\)의 평균: \(\dfrac{12}{9} \approx 1.333 = \dfrac{n-1}{n}\sigma^2 = \dfrac{1}{2}\times 2.667\) → 정확히 절반으로 과소추정.

항등식과 기댓값 계산을 숫자로 따라가기. 위 단계 3~4를 9가지 표본에서 직접 확인합니다(\(\mu = 4\), \(n = 2\)).

효율성 — 같은 불편추정량이면 분산이 작은 쪽이 낫다 수식 · 숫자
정의 불편추정량 두 개를 어떻게 비교할까

모평균 \(\mu\)를 추정하는 방법이 둘 이상이고 모두 불편이라면, 평균적으로는 둘 다 참값을 맞힙니다. 차이는 한 번 뽑았을 때 얼마나 흩어지는가, 즉 분산입니다. 분산이 작은 쪽이 참값 근처의 값을 더 안정적으로 내므로 더 효율적(efficient)이라 하고, 두 추정량 \(\hat{\theta}_1, \hat{\theta}_2\)의 상대효율은 분산의 비로 나타냅니다.

\[\mathrm{eff}(\hat{\theta}_1,\ \hat{\theta}_2) = \frac{\mathrm{Var}(\hat{\theta}_2)}{\mathrm{Var}(\hat{\theta}_1)} \quad (>1\text{이면 } \hat{\theta}_1 \text{이 더 효율적})\]

불편추정량 가운데 분산이 가장 작은 것을 최소분산 불편추정량(MVUE)이라 합니다. 정규모집단에서 \(\bar{X}\)가 \(\mu\)의 MVUE입니다.

수식 전개 표본평균과 첫 관측값의 비교

\(X_1, \ldots, X_n\)이 독립이면 합의 분산은 분산의 합이고, 상수 \(1/n\)은 제곱되어 밖으로 나옵니다.

\[\mathrm{Var}(\bar{X}) = \frac{1}{n^2}\sum_{i=1}^{n}\mathrm{Var}(X_i) = \frac{1}{n^2}\cdot n\sigma^2 = \frac{\sigma^2}{n}\]

표본 중 첫 번째 값 하나만 쓰는 추정량 \(X_1\)도 \(E[X_1] = \mu\)인 불편추정량이지만 \(\mathrm{Var}(X_1) = \sigma^2\)입니다. 따라서

\[\mathrm{eff}(\bar{X},\ X_1) = \frac{\mathrm{Var}(X_1)}{\mathrm{Var}(\bar{X})} = \frac{\sigma^2}{\sigma^2/n} = n\]

표본 전체를 쓰는 \(\bar{X}\)는 \(X_1\)보다 \(n\)배 효율적입니다. \(n\)개의 관측값을 다 쓴 만큼 정보를 알뜰하게 쓴다는 뜻입니다.

숫자로 확인 (공통 예제, \(n=2\), \(\mu = 4\))
  1. \(\bar{X}\)의 9개 값은 2, 3, 4, 3, 4, 5, 4, 5, 6이고 평균 4(불편)입니다. 분산은 \(\dfrac{(-2)^2 + (-1)^2 + 0 + (-1)^2 + 0 + 1^2 + 0 + 1^2 + 2^2}{9} = \dfrac{12}{9} \approx 1.333 = \dfrac{\sigma^2}{n}\).
  2. \(X_1\)의 9개 값은 2, 2, 2, 4, 4, 4, 6, 6, 6이고 평균 4(불편)입니다. 분산은 \(\dfrac{4\cdot 3 + 0 + 4\cdot 3}{9} = \dfrac{24}{9} \approx 2.667 = \sigma^2\).
  3. 둘 다 불편이지만 상대효율 \(= 2.667 / 1.333 = 2 = n\) → \(\bar{X}\)가 2배 효율적입니다.
분산 1.333과 2.667은 추정치가 흩어지는 정도입니다. \(X_1\)은 2, 4, 6 중 어느 값이든 나올 수 있지만, \(\bar{X}\)는 2나 6이 나올 확률이 1/9로 줄고 4 근처(3, 4, 5)에 모입니다.
보조 편향이 있는 추정량까지 비교하려면 — MSE

분산 비교는 두 추정량이 모두 불편일 때만 공정합니다. 편향이 있는 추정량까지 한 잣대로 비교하려면 참값에서 벗어난 정도의 제곱의 평균, 즉 평균제곱오차 \(\mathrm{MSE}(\hat{\theta}) = E[(\hat{\theta} - \theta)^2]\)를 씁니다. \(E[\hat{\theta}]\)를 더하고 빼서 묶으면 다음과 같이 분해됩니다.

\[\begin{aligned} E[(\hat{\theta} - \theta)^2] &= E\big[\big((\hat{\theta} - E[\hat{\theta}]) + (E[\hat{\theta}] - \theta)\big)^2\big] \\ &= \underbrace{E[(\hat{\theta} - E[\hat{\theta}])^2]}_{\mathrm{Var}(\hat{\theta})} + 2\,\underbrace{(E[\hat{\theta}] - \theta)}_{\text{상수}}\underbrace{E[\hat{\theta} - E[\hat{\theta}]]}_{=\,0} + \underbrace{(E[\hat{\theta}] - \theta)^2}_{\mathrm{Bias}^2} \end{aligned}\]

가운데 교차항은 \(E[\hat{\theta} - E[\hat{\theta}]] = 0\)이라 사라져 \(\mathrm{MSE} = \mathrm{Var} + \mathrm{Bias}^2\)이 됩니다. 불편추정량이면 편향이 0이라 MSE가 곧 분산이므로, 위 효율성 비교와 정확히 이어집니다.

숫자 예. 일부러 조금 줄인 \(T = 0.9\,\bar{X}\)로 “편향이 있어도 MSE가 작을 수 있는지” 확인해 봅니다. (0.9는 편향과 분산이 맞바뀌는 것을 보이려고 임의로 고른 값이며, 실제 추정에서 쓰는 식이 아닙니다.)

  1. 편향: \(E[T] = 0.9 \times 4 = 3.6\)이므로 \(\mathrm{Bias}(T) = -0.4\) — 손해.
  2. 분산: \(\mathrm{Var}(T) = 0.9^2 \times 1.333 = 1.08\) — \(\bar{X}\)의 1.333보다 줄어드는 이득.
  3. \(\mathrm{MSE}(T) = 1.08 + (-0.4)^2 = 1.24\) < \(\mathrm{MSE}(\bar{X}) = 1.333 + 0 = 1.333\). 편향으로 잃은 것(0.16)보다 분산으로 얻은 것(0.253)이 커서 \(T\)의 MSE가 작습니다.
정리: 효율성의 기본은 “불편추정량끼리 분산 비교”이고, MSE는 그 비교를 편향이 있는 추정량까지 넓혀 주는 보조 도구입니다. 편향을 조금 허용해 분산을 크게 줄이는 방법(축소추정 등)이 존재하는 이유이기도 합니다.
일치성 — \(n\)이 커질 때 왜 참값에 다가갈까? 수식 · 숫자
수식 전개 체비쇼프 부등식으로 증명

확률변수 \(Y\)와 \(\varepsilon > 0\)에 대해 체비쇼프 부등식은 \(P(|Y - E[Y]| \ge \varepsilon) \le \dfrac{\mathrm{Var}(Y)}{\varepsilon^2}\)입니다. \(Y = \bar{X}_n\)에 적용하면 \(E[\bar{X}_n] = \mu\), \(\mathrm{Var}(\bar{X}_n) = \sigma^2/n\)이므로

\[P\big(|\bar{X}_n - \mu| \ge \varepsilon\big) \le \frac{\sigma^2}{n\,\varepsilon^2} \xrightarrow{\;n\to\infty\;} 0\]

어떤 \(\varepsilon\)을 잡아도 오른쪽이 0으로 가므로 \(\bar{X}_n \xrightarrow{p} \mu\)입니다. 이것이 대수의 법칙(약법칙)입니다.

일반적으로 편향 → 0 이고 분산 → 0이면 (곧 \(\mathrm{MSE} \to 0\)이면) 그 추정량은 일치추정량입니다.

충분성 — 요약해도 정보가 사라지지 않는다는 것의 의미 수식 · 숫자
수식 전개 조건부 확률로 정의

통계량 \(T = T(X_1, \ldots, X_n)\)가 충분하다는 것은, \(T\)의 값이 주어졌을 때 표본의 조건부 분포가 모수 \(\theta\)에 의존하지 않는다는 뜻입니다. 즉 \(T\)를 알고 나면 원자료는 \(\theta\)에 대해 더 알려줄 것이 없습니다.

예로 동전을 \(n\)번 던져 앞면이 나오면 \(X_i = 1\)인 베르누이 표본(성공확률 \(p\))에서 \(T = \sum X_i\) (앞면 횟수)를 봅시다. 특정 결과 \(x = (x_1, \ldots, x_n)\)에서 \(\sum x_i = t\)이면

\[P(X = x \mid T = t) = \frac{P(X = x)}{P(T = t)} = \frac{p^{t}(1-p)^{n-t}}{\binom{n}{t}\,p^{t}(1-p)^{n-t}} = \frac{1}{\binom{n}{t}}\]

\(p\)가 분자·분모에서 모두 약분되어 사라졌습니다. 즉 \(T = t\)일 때 앞면이 나온 위치는 \(p\)와 무관하게 \(\binom{n}{t}\)가지가 똑같이 일어나므로, 순서 정보는 \(p\)에 대해 쓸모가 없습니다.

숫자로 확인 (동전 \(n = 3\)번, 앞면 1번 나온 경우 \(T = 1\))

\(T = 1\)이 되는 결과는 (1,0,0), (0,1,0), (0,0,1)의 세 가지입니다.

\(P(1,0,0)\)\(P(T=1)\) = 3가지의 합\(P(1,0,0 \mid T=1)\)
\(p = 0.3\)\(0.3 \times 0.7 \times 0.7 = 0.147\)\(3 \times 0.147 = 0.441\)\(0.147 / 0.441 = 1/3\)
\(p = 0.7\)\(0.7 \times 0.3 \times 0.3 = 0.063\)\(3 \times 0.063 = 0.189\)\(0.063 / 0.189 = 1/3\)

\(p\)가 0.3이든 0.7이든 조건부 확률이 똑같이 \(1/3\)입니다. 앞면이 몇 번 나왔는지(\(T\))만 기록해도 \(p\)에 관한 정보는 하나도 잃지 않고, 어느 던지기에서 나왔는지는 버려도 됩니다.

비교: 첫 번째 던지기 결과 \(X_1\)만 기록하면 나머지 두 번의 정보를 버리게 되어 충분하지 않습니다. 충분성은 “자료를 얼마나 압축해도 정보 손실이 없는가”에 대한 기준입니다.
보조 충분통계량을 쉽게 찾는 방법 — 분해정리

충분성을 매번 조건부 확률로 확인하기는 번거롭습니다. 분해정리(Fisher–Neyman)를 쓰면 표본의 결합확률(밀도)을 다음처럼 두 부분으로 쪼갤 수 있는지만 보면 됩니다.

\[f(x;\theta) = g\big(T(x);\ \theta\big)\cdot h(x)\]

\(g\)는 모수 \(\theta\)와 통계량 \(T\)의 값만으로 정해지고, \(h\)는 \(\theta\)와 무관한 부분입니다. 이렇게 쪼개지면 \(T\)가 충분통계량입니다. 모수에 관한 정보는 \(T\)에만 실려 있고, 나머지 \(h(x)\)는 모수를 알아내는 데 쓸모가 없다는 뜻입니다.

  1. 동전 예: \(f(x;p) = \underbrace{p^{t}(1-p)^{n-t}}_{g(t;\,p)}\times\underbrace{1}_{h(x)}\), \(t = \sum x_i\). 따라서 \(T = \sum X_i\)가 충분통계량입니다.
  2. 정규분포 예: 모평균 \(\mu\)만 모르고 모표준편차 \(\sigma\)는 알려진 \(N(\mu, \sigma^2)\)에서, \(\sum(x_i-\mu)^2 = \sum(x_i-\bar{x})^2 + n(\bar{x}-\mu)^2\)임을 이용하면 \[f(x;\mu) = \underbrace{\exp\!\Big(-\frac{n(\bar{x}-\mu)^2}{2\sigma^2}\Big)}_{g(\bar{x};\,\mu)}\times\underbrace{(2\pi\sigma^2)^{-n/2}\exp\!\Big(-\frac{\sum(x_i-\bar{x})^2}{2\sigma^2}\Big)}_{h(x)}\] \(\mu\)가 들어 있는 앞부분은 표본을 \(\bar{x}\)로만 쓰므로 \(\bar{X}\)가 \(\mu\)의 충분통계량입니다.
왜 “\(\sigma\)를 안다”고 가정할까? 충분성은 “무엇에 대한 정보인가”, 즉 추정하려는 모수를 기준으로 판단합니다. \(\sigma\)가 알려진 상수이면 위 \(h(x)\)에 있는 \(\sigma\)는 그냥 숫자라서 \(\mu\)와 무관하게 분리됩니다. 반대로 \(\sigma\)도 모르는 모수라면 \(h(x)\)에 미지의 \(\sigma\)가 들어 있어 분리되지 않으므로, \(\bar{X}\) 하나로는 부족하고 \(\big(\bar{X},\ S^2\big)\)를 함께 알아야 충분해집니다.
The Catch

점 추정의 문제

점추정치는 숫자 하나만 내놓습니다. 그 숫자가 참값에 얼마나 가까운지, 표본이 4개였는지 400개였는지에 대한 정보는 그 안에 전혀 담겨 있지 않습니다.

같은 76점이라도 다릅니다. 표본 4명으로 얻은 평균 76점과 표본 400명으로 얻은 평균 76점은 신뢰도가 전혀 다르지만, 점추정치만 보면 둘을 구분할 방법이 없습니다.
점추정만 제시

“시험 평균은 76점입니다.”

구간추정 병행

“95% 신뢰수준에서 72~80점 사이입니다.”

그래서 통계적 추론은 점추정 하나로 끝나지 않고, 불확실성을 함께 표현하는 구간추정으로 이어집니다.

추정치 하나 대신, 모수를 포함할 가능성이 높은 구간을 제시합니다.

Confidence Interval

100(1 − \(\alpha\))% 신뢰구간 구하기

모분산 \(\sigma ^{2}\)을 알고 있는 정규모집단에서 표본을 뽑으면, 표본평균은 \(\bar{X} \sim N(\mu , \sigma ^{2}/n)\)을 따릅니다. 이를 표준화하면：

\[Z = \frac{\bar{X} - \mu }{\sigma /\sqrt{n}} \sim N(0, 1)\]

표준정규분포에서 가운데 \(1 - \alpha\)만큼의 확률을 차지하는 구간은 \([-z_{\alpha /2}, z_{\alpha /2}]\)입니다.

\[P(-z_{\alpha /2} \le Z \le z_{\alpha /2}) = 1 - \alpha\]

이 부등식을 \(\mu\)에 대해 정리하면 \(100(1-\alpha)\%\) 신뢰구간을 얻습니다.

\[\bar{X} \pm z_{\alpha /2} \cdot \frac{\sigma }{\sqrt{n}}\]
모분산 \(\sigma\)을 모를 때는 표본표준편차 \(s\)와 자유도 \(n-1\)의 \(t\)분포로 대체합니다 (\(\bar{X} \pm t_{\alpha/2,\,n-1} \cdot s/\sqrt{n}\)).

신뢰수준을 바꾸면 \(z_{\alpha /2}\)와 구간의 폭이 어떻게 달라지는지 직접 눌러보세요. 아래 예시는 \(\sigma = 2\), \(n = 4\)일 때입니다.

What 95% Really Means

95% 신뢰구간의 의미

흔한 오해: “이미 계산된 구간이 모평균을 포함할 확률이 95%”가 아닙니다. 모평균은 고정된 상수이므로 이미 정해진 하나의 구간에 대해서는 포함 여부가 확률적이지 않습니다. 정확한 해석은 “같은 절차를 반복해서 신뢰구간을 100번 만들면, 그중 약 95개가 모평균을 포함한다”는 것입니다.

직접 확인해봅시다. 모평균 \(\mu = 1\), 모표준편차 \(\sigma = 2\)인 정규분포에서 크기 \(n = 4\)인 표본을 100번 독립적으로 뽑고, 매번 95% 신뢰구간 \(\bar{x} \pm 1.96\)을 계산합니다. 모평균 1을 포함하지 못한 구간은 붉은색으로 표시됩니다.

모평균을 포함 모평균을 포함하지 못함 모평균 \(\mu = 1\)

x축은 100번의 추출 각각의 번호, y축은 각 추출의 표본평균과 95% 신뢰구간입니다. 매번 다시 뽑을 때마다 실패하는 구간의 개수는 달라지지만, 평균적으로는 약 5개(5%) 근처에서 흔들립니다 — 이것이 “95% 신뢰수준”이 실제로 의미하는 바입니다.

03

표본오차 읽기

여론조사 보고서의 “95% 신뢰수준에서 표본오차는 ±3.1%p” — 이 한 문장을 신뢰구간의 언어로 다시 읽어봅니다.

Margin of Error

표본오차는 어떻게 계산할까

여론조사는 모집단 중 지지율 같은 비율(proportion) \(p\)를 추정합니다. 표본에서 얻은 응답 비율 \(\hat{p}\)은 표본크기 \(n\)이 충분히 크면 근사적으로 정규분포를 따릅니다.

\[\hat{p} \sim N\!\left(p,\ \frac{p(1 - p)}{n}\right)\]

앞서 살펴본 것과 같은 방식으로 \(p\)에 대한 \(100(1-\alpha)\%\) 신뢰구간을 만들 수 있습니다.

\[\hat{p} \pm z_{\alpha /2} \cdot \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}\]
± 뒤에 붙는 이 값이 바로 표본오차(margin of error)입니다.

실제 응답 비율 \(\hat{p}\)은 문항마다 다르지만, 여론조사기관은 보고서에 하나의 표본오차만 표시합니다. \(\hat{p}(1 - \hat{p})\)은 \(\hat{p} = 0.5\)일 때 가장 커지므로, 오차가 최대가 되는 이 값을 대입해 가장 보수적인(넓은) 오차를 미리 계산해 두기 때문입니다.

\[E = \frac{z_{\alpha /2}}{2\sqrt{n}}\]
n = 1,000, 95% 신뢰수준일 때: \(E = \dfrac{1.96}{2\sqrt{1000}} \approx 0.031\) → ±3.1%p — 실제 보고서 표현과 일치합니다.

What It Means

표본오차, 이렇게 읽습니다

“95% 신뢰수준에서 표본오차 ±3.1%p”란, 같은 방식으로 조사를 100번 반복하면 그중 약 95번은 실제 모집단의 응답률이 “발표된 응답률 ± 3.1%p” 구간 안에 들어온다는 뜻입니다. 앞서 살펴본 95% 신뢰구간의 해석과 정확히 같은 논리입니다.

표본수를 늘리면 오차는 줄어들지만, \(1/\sqrt{n}\)에 비례해 줄어들기 때문에 오차를 절반으로 줄이려면 표본을 4배로 늘려야 합니다. 위 슬라이더로 n = 1,000에서 n = 4,000으로 옮겨 직접 확인해보세요.

흔한 오해 — “오차범위 내 접전”. 두 후보의 지지율 차이가 표본오차보다 작다고 해서 통계적으로 우열이 없다고 단정할 수는 없습니다. 같은 표본에서 얻은 두 비율의 차이에 대한 오차는 단일 비율의 오차보다 크며(약 \(\sqrt{2}\)배), n = 1,000 · 95% 기준으로는 약 ±4.4%p가 됩니다.

표본오차는 무작위 표집 과정에서 생기는 오차만을 설명합니다. 무응답·응답 거부에 따른 편향, 질문 문항의 설계, 조사 방식(전화면접·ARS·온라인 패널 등)에서 비롯되는 오차는 표본오차에 포함되지 않습니다.
