01

ggplot 플롯의 구성요소

ggplot2는 Wilkinson의 Grammar of Graphics를 Wickham이 레이어 문법으로 재구성한 것입니다. 그림은 데이터·매핑·기하객체·통계변환으로 이루어진 레이어에 척도·좌표계·패싯·테마가 더해져 완성됩니다. 아래 구성요소를 눌러 그림의 어느 부분을 담당하는지 확인하세요.

03
theme()의 구성

    
theme은 데이터와 무관한 모든 잉크를 다룹니다. 설정 하나는 요소 이름 = 요소 함수 형태이고, 요소 이름은 점(.)으로 계층을 이룹니다. 하위 요소는 지정하지 않은 속성을 상위 요소에서 상속합니다.


  
요소 함수 네 가지와 보조 함수

  

    
element_text()
글자: 제목, 축 눈금 레이블, 범례 텍스트, strip
family, face, colour, size, hjust, vjust, angle, lineheight, margin

    
element_line()
선: 격자, 축선, 눈금
colour, linewidth, linetype, lineend, arrow

    
element_rect()
사각형: 배경, 테두리, 범례 키, strip 배경
fill, colour, linewidth, linetype

    
element_blank()
그리지 않음. 공간도 차지하지 않습니다.
인수 없음

    
rel() · margin() · unit()
상대 크기, 여백, 길이 단위

margin(t, r, b, l, unit = "pt")
unit(1, "cm")

plot.title.position"panel"(기본) 또는 "plot"

        
panel.spacingunit(1, "lines")

theme 사용자화

    
완성 테마를 바탕으로 고치고 싶은 요소만 theme()으로 덮어쓰는 것이 기본 흐름입니다. 자주 쓰는 조합은 함수로 만들어 프로젝트 전체에 적용합니다.

나만의 테마 함수 만들기

      
프로젝트에서 반복할 설정을 함수로 묶고 theme_set()으로 기본값을 바꿉니다. 인수로 base_size, base_family를 열어 두면 학술지·슬라이드별로 크기만 바꿔 재사용할 수 있습니다.

      

    

    

      
+와 %+replace%의 차이

      
+ theme()은 지정한 속성만 기존 요소에 병합합니다. %+replace%는 요소를 통째로 교체하므로 지정하지 않은 속성은 비어 있게 되고, 상위 요소의 값을 상속합니다.

      

      
완성 테마를 처음부터 정의할 때는 %+replace%가 안전하고, 그림 하나를 다듬을 때는 + theme()이 편합니다.

06
showtext로 한글 처리하기

    
R 그래픽 장치는 장치마다 글꼴을 찾는 방식이 다릅니다. 한글 글꼴이 없는 장치에서는 한글이 네모(□)로 깨지거나 점으로 바뀝니다. showtext는 글꼴 파일을 직접 읽어 글자를 도형으로 그려 넣으므로 장치와 운영체제에 상관없이 같은 결과를 얻습니다.

  

    

      
증상과 해결을 직접 켜 보기

      

      

        

      

      

      

      

    

    
  


  

    
자주 만나는 문제

    

      
증상원인해결

      
        
한글이 □□□ 또는 ..로 보임장치가 한글 글꼴을 찾지 못함 (리눅스 서버, pdf() 장치 등)font_add_google() + showtext_auto()

        
저장한 PNG의 글자가 매우 작음showtext 기본 dpi(96)와 ggsave(dpi = 300) 불일치showtext_opts(dpi = 300)을 저장 dpi와 맞춤

        
축은 나눔고딕인데 점 레이블만 다른 글꼴geom_text()는 theme의 글꼴을 따르지 않음geom_text(family = "nanum") 또는 update_geom_defaults("text", list(family = "nanum"))

        
지정한 family 이름이 안 먹힘R 안에서 붙인 별칭과 다르게 씀font_families()로 등록된 이름 확인

        
PDF에서 글자가 선택·검색되지 않음showtext는 글자를 도형(path)으로 그림텍스트 검색이 필요하면 cairo_pdf()와 시스템 글꼴 사용

        
R Markdown/Quarto에서 글자 크기가 이상함청크마다 dpi가 다름청크 옵션 fig.showtext = TRUE

      
    

    

      

        
로컬 글꼴 파일 쓰기

        
Pretendard처럼 Google Fonts에 없는 글꼴은 파일 경로로 등록합니다. 굵은꼴 파일을 함께 주면 face = "bold"가 제대로 동작합니다.

        

      

      

        
대안: ragg 장치

        
ragg 장치는 systemfonts로 시스템에 설치된 글꼴을 직접 찾습니다. 컴퓨터에 한글 글꼴이 설치되어 있다면 showtext 없이도 PNG가 잘 나옵니다. RStudio에서는 Tools › Global Options › General › Graphics의 Backend를 AGG로 바꾸면 미리보기 창도 같은 방식으로 그립니다.
