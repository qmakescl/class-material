# 국민건강영양조사 원시자료를 두는 곳

이 폴더에 질병관리청에서 각자 내려받은 **2024년 기본 DB** `hn24_all.sas7bdat`를 넣는다.

- 받는 곳: [국민건강영양조사 누리집](https://knhanes.kdca.go.kr/knhanes/main.do) 첫 화면의 "원시자료 다운로드"
  메뉴에서 이용자 등록과 요청서 작성을 거쳐 내려받는다.
- 이름이 비슷한 `hn24_24rc.sas7bdat`(24시간 회상 식품섭취조사)가 아니라 기본 DB(`hn24_all`)를 쓴다.
- 원시자료는 이용 조건상 다른 사람에게 다시 나눠 줄 수 없다. 이 폴더의 파일은 `.gitignore`로
  커밋되지 않게 막아 두었다. 파일을 공유 폴더나 저장소에 올리지 않는다.
- 변수 이름과 응답 코드는 해당 연도 「원시자료 이용지침서」로 확인한다.
