기초 통계 구하기

평균과 퍼짐, 분포, 집단 비교, 상관을 구하고 그림으로 확인한다.

이 장을 마치면
  • 평균과 중앙값, 표준편차와 사분위수를 구하고 뜻을 설명할 수 있다.
  • 히스토그램과 상자그림으로 분포를 볼 수 있다.
  • 집단별 요약과 상관계수를 구할 수 있다.

R
library(tidyverse)
daily <- read_csv("../dataset/working/daily.csv")
Python
import pandas as pd
import matplotlib.pyplot as plt
daily = pd.read_csv("../dataset/working/daily.csv",
                    parse_dates=["날짜"])

daily는 2025년의 하루가 한 행인 표다(365행). 승차는 그날 1~8호선에서 탄 횟수의 합이다.

5.1가운데: 평균과 중앙값

하루 승차 인원의 “보통”은 얼마일까. 평균은 모두 더해 나눈 값, 중앙값은 크기 순으로 줄 세웠을 때 가운데 값이다.

R
daily |>
  summarise(평균 = mean(승차),
            중앙값 = median(승차))
Python
daily["승차"].agg(["mean", "median"])

두 값이 꽤 다르게 나온다면 이유를 생각해 본다. 이 데이터에는 승차가 적은 주말과 공휴일이 섞여 있어 평균이 아래로 끌려간다.

5.2퍼짐: 범위, 사분위수, 표준편차

R
daily |>
  summarise(최소 = min(승차),
            Q1 = quantile(승차, 0.25),
            Q3 = quantile(승차, 0.75),
            최대 = max(승차),
            표준편차 = sd(승차))

summary(daily$승차)   # 한 번에 보기

daily["승차"].agg(["min", "max", "std"])
daily["승차"].quantile([0.25, 0.75])

daily["승차"].describe()   # 한 번에 보기

5.3분포 보기

숫자 몇 개로는 모양을 알 수 없다. 히스토그램을 그린다.

R
ggplot(daily, aes(x = 승차)) +
  geom_histogram(bins = 30) +
  labs(x = "하루 승차 인원", y = "일수")
Python
plt.hist(daily["승차"], bins=30)
plt.xlabel("하루 승차 인원")
plt.ylabel("일수")
plt.show()

봉우리가 둘 이상으로 보인다면 서로 다른 집단이 섞여 있다는 신호다. 어떤 집단일까?

그림의 한글이 네모로 나올 때 Python은 글꼴을 지정해야 한다. Windows는 plt.rcParams["font.family"] = "Malgun Gothic", macOS는 "AppleGothic"을 그림 그리기 전에 한 번 실행한다. 겨울에는 영하의 기온이 있어 5.6의 그림에서 축의 음수 부호가 네모로 나올 수 있다. plt.rcParams["axes.unicode_minus"] = False도 함께 실행해 둔다.

5.4집단별 비교

평일과 주말로 나누어 다시 요약한다.

R
daily |>
  group_by(주말) |>
  summarise(일수 = n(),
            평균 = mean(승차),
            표준편차 = sd(승차))

ggplot(daily, aes(x = 주말, y = 승차)) +
  geom_boxplot()
Python
(daily.groupby("주말")["승차"]
      .agg(["size", "mean", "std"]))

daily.boxplot(column="승차", by="주말")
plt.show()

나눈 뒤 각 집단의 표준편차가 전체보다 얼마나 작아지는지 본다. 많이 작아진다면 전체의 퍼짐 대부분이 “평일이냐 주말이냐”에서 나온다는 뜻이다. 평일 쪽에 유난히 낮은 점이 있다면 날짜를 찾아본다. 공휴일일 가능성이 높다. 본문에서는 그대로 두고 과제에서 다룬다.

5.6두 변수의 관계

기온과 승차 인원을 산점도로 그리고 상관계수를 구한다.

R
ggplot(daily, aes(x = 기온, y = 승차,
                  colour = 주말)) +
  geom_point()

cor(daily$기온, daily$승차)
Python
plt.scatter(daily["기온"], daily["승차"],
            c=daily["주말"])
plt.xlabel("평균기온(°C)")
plt.ylabel("하루 승차 인원")
plt.show()

daily["기온"].corr(daily["승차"])

상관계수는 직선 관계의 세기를 −1에서 1 사이로 나타낸다. 0에 가깝다고 해서 관계가 없다는 뜻은 아니다. 그림을 먼저 보고 숫자를 읽는다.

5.7요약표 만들어 저장하기

R
요약 <- daily |>
  group_by(주말, 비) |>
  summarise(일수 = n(),
            평균승차 = mean(승차),
            .groups = "drop")

write_csv(요약, "../output/요약표.csv")
Python
요약 = (daily
        .groupby(["주말", "비"])
        .agg(일수=("승차", "size"),
             평균승차=("승차", "mean"))
        .reset_index())

요약.to_csv("../output/요약표.csv",
            index=False, encoding="utf-8-sig")
