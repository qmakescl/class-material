흉부 X선 28×28로 배우는 딥러닝의 전 과정

손글씨 숫자 MNIST 대신, 같은 크기(28×28 픽셀)의 흉부 X선 사진 PneumoniaMNIST로 "데이터 → 전처리 → 모델 → 손실 → 학습 → 평가"를 한 바퀴 돌아봅니다. 5단계에서는 이 브라우저 안에서 실제로 모델을 학습시킵니다.

0 · 전체 흐름

MNIST식 과정이란 무엇인가

MNIST(Modified NIST)는 0~9 손글씨 숫자 7만 장을 28×28 흑백 이미지로 모은 데이터셋으로, 1998년 LeCun 등이 공개한 뒤 딥러닝 입문의 표준 예제가 되었습니다. "MNIST 과정"이란 이 데이터로 분류기를 만들 때 거치는 다음 여섯 단계를 가리킵니다. 사진이 숫자든 폐 사진이든 순서는 같습니다.

1 데이터 보기→2 전처리→3 모델→4 손실 함수→5 학습→6 평가

PneumoniaMNIST는 무엇이 다른가

MNISTPneumoniaMNIST
내용손글씨 숫자소아 흉부 X선(정면)
크기28×28, 흑백28×28, 흑백 (원본을 축소)
정답 종류10개 (0~9)2개 (정상 0 / 폐렴 1)
이미지 수70,0005,030 (Kaggle 사본 기준)
클래스 균형거의 균등폐렴이 더 많음 (학습용 90.0% · 검증용 74.2% · 시험용 62.5%)

이 페이지는 Kaggle의 "PneumoniaMNIST classification" 데이터셋을 실제로 읽어 확인한 값을 따릅니다. 28×28 흑백 흉부 X선 이미지가 NumPy 배열로 저장되어 있고, 정답은 1이 폐렴, 0이 정상입니다. 학습용 3,882장 · 검증용 524장 · 시험용 624장으로 나뉘며 합계는 5,030장입니다. MedMNIST v2 공식 버전(총 5,856장, 학습용 4,708장)과는 장 수와 분할이 다르므로, 공식 논문 수치와 섞어 쓰지 마세요. 원본 X선은 Kermany et al.(2018)이 공개한 광저우 여성아동의료센터 1~5세 소아 영상입니다.

두 가지 차이가 이후 단계에 영향을 줍니다. 정답이 2개라서 출력은 "폐렴일 확률" 하나면 되고(4단계), 폐렴 사진이 훨씬 많아서(특히 학습용은 90%) "정확도"만 보면 속기 쉽습니다(6단계).

1 · 데이터 보기

컴퓨터에게 사진은 784개의 숫자다

아래 사진들은 실제 데이터가 아니라 이 페이지가 만들어 낸 합성 예시입니다설명용 합성 데이터. 폐 영역은 어둡고(공기), 폐렴이 있으면 염증으로 폐 일부가 뿌옇게 밝아진다는 특징만 흉내 냈습니다. 사진을 고른 뒤 확대 화면 위에 손가락이나 마우스를 올려 보세요.

픽셀을 가리키면 값이 나옵니다

각 칸은 픽셀(pixel) 하나이고, 0(검정)부터 255(흰색)까지의 정수 하나로 저장됩니다. 28×28 = 784개 숫자. 모델이 받는 것은 사진이 아니라 이 숫자 목록뿐입니다.

실제 PneumoniaMNIST도 28×28(흑백, NumPy 배열)이라 갈비뼈나 작은 음영은 거의 뭉개집니다. 원본은 수백~수천 픽셀 크기이며, MedMNIST+(v3)는 64·128·224 크기 버전도 제공합니다.

데이터는 세 묶음으로 나눈다

묶음용도장 수정상 / 폐렴
학습용(train)모델이 숫자를 조정할 때 보는 문제집3,882388 / 3,494 (폐렴 90.0%)
검증용(validation)학습 중 설정(학습률 등)을 고를 때 쓰는 모의고사524135 / 389 (폐렴 74.2%)
시험용(test)마지막에 한 번만 보는 수능624234 / 390 (폐렴 62.5%)
묶음마다 폐렴 비율이 다릅니다. 학습용은 폐렴이 90%이고 시험용은 62.5%입니다. 학습 때 본 비율과 시험 때 만나는 비율이 다르면 정확도의 의미도 달라집니다. 비유의 한계: 사람은 문제집을 풀며 개념을 익히지만, 모델은 학습용 사진의 정답을 맞히도록 숫자를 조정할 뿐입니다. 그래서 시험용을 학습 중에 한 번이라도 보면 점수가 부풀려집니다.
2 · 전처리

숫자를 모델이 다루기 좋은 모양으로

① 정규화(Normalization): 0~255 → 0~1

모든 픽셀 값을 255로 나눕니다. 값의 크기가 비슷해야 학습 단계에서 가중치를 고르게 조정할 수 있습니다. 평균과 표준편차로 한 번 더 맞추기도 합니다.

② 펼치기(Flatten): 28×28 → 784

가장 단순한 모델은 사진을 한 줄로 늘어놓은 벡터(vector)를 받습니다. 윗줄부터 차례로 이어 붙입니다.

펼치면 이웃한 두 픽셀이 위아래였는지 알 수 없게 됩니다. 이 정보 손실을 막으려고 3단계의 합성곱 신경망은 펼치지 않고 28×28 모양 그대로 받습니다.

③ 정답 붙이기

정상은 0, 폐렴은 1. 정답이 둘뿐이라 이것으로 충분합니다. MNIST처럼 정답이 10개면 [0,0,1,0,…] 같은 원-핫(one-hot) 벡터를 씁니다.

3 · 모델

숫자 784개를 확률 하나로 바꾸는 함수

모델(model)은 입력 숫자에 가중치(weight)를 곱해 더하는 계산을 여러 겹 쌓은 함수입니다. 학습 전 가중치는 무작위라서 엉뚱한 답을 냅니다. 가장 단순한 형태부터 보겠습니다.

z = w₁x₁ + w₂x₂ + … + w₇₈₄x₇₈₄ + b
p = σ(z) = 1 / (1 + e−z)

x₁…x₇₈₄: 정규화된 픽셀 값 · w₁…w₇₈₄: 픽셀마다 하나씩 있는 가중치(이 픽셀이 밝으면 폐렴 쪽으로 얼마나 기울일지) · b: 절편(bias), 모든 픽셀이 0일 때의 기본 점수 · z: 점수 · σ: 시그모이드(sigmoid), 어떤 점수든 0~1 사이 확률로 눌러 담는 함수 · p: 모델이 말하는 "폐렴일 확률".

이것이 로지스틱 회귀(logistic regression)이고, 층이 하나뿐인 신경망입니다. 5단계에서 이 모델을 직접 학습시킵니다. 실전에서는 아래의 합성곱 층을 앞에 쌓은 합성곱 신경망(CNN, Convolutional Neural Network)을 씁니다.

합성곱(Convolution): 작은 돋보기로 훑기

CNN은 3×3 크기의 작은 가중치 묶음(필터)을 돋보기처럼 사진 위에서 한 칸씩 옮기며, 겹친 9칸을 곱해 더합니다. 필터마다 "가로 경계", "밝은 덩어리" 같은 특정 무늬에 크게 반응합니다. 아래 필터는 사람이 정한 예시이고, 실제 CNN은 이런 필터 수십 개의 값을 학습으로 찾아냅니다. 돋보기와 달리 필터는 사진을 크게 보여 주지 않고, 9칸을 곱해 더한 숫자 하나를 내놓습니다.

입력 (28×28)
필터 (3×3)
결과: 특징 맵 (26×26)

필터가 가장자리 한 칸을 넘지 못하므로 결과는 26×26이 됩니다. 밝을수록 그 자리에서 필터 무늬와 많이 닮았다는 뜻입니다.

ReLU(Rectified Linear Unit)는 음수를 0으로 바꾸는 함수로, 층을 쌓았을 때 모델이 단순한 직선 계산을 넘어서게 해 줍니다.

4 · 손실 함수

얼마나 틀렸는지를 숫자 하나로

학습하려면 "지금 얼마나 틀렸는가"를 숫자로 재야 합니다. 이 숫자가 손실(loss)입니다. 정답이 두 가지일 때는 이진 교차 엔트로피(Binary Cross-Entropy)를 씁니다.

손실 L = −[ y·log(p) + (1−y)·log(1−p) ]

y: 정답(0 또는 1) · p: 모델이 낸 폐렴 확률 · log: 자연로그. y=1이면 −log(p)만 남고, y=0이면 −log(1−p)만 남습니다.

이 사진의 정답:

확신하며 틀릴수록(정답이 폐렴인데 p가 0에 가까울수록) 손실이 가파르게 커집니다. 모델은 "모르겠다"보다 "자신 있게 틀림"에 훨씬 큰 벌점을 받습니다.

5 · 학습

손실이 줄어드는 쪽으로 가중치를 조금씩

경사하강법(Gradient Descent): 가중치 하나하나에 대해 "이 값을 조금 올리면 손실이 늘까, 줄까"를 계산하고(기울기, gradient), 줄어드는 쪽으로 학습률(learning rate)만큼 옮깁니다. 학습용 사진 전체를 한 번 훑는 것을 에폭(epoch)이라고 합니다.

w ← w − η · ∂L/∂w

η(에타): 학습률, 한 번에 움직이는 보폭 · ∂L/∂w: 가중치 w를 아주 조금 바꿨을 때 손실 L이 변하는 비율(기울기).

아래는 3단계의 로지스틱 회귀 모델을 합성 사진 학습용 3,882장(정상 388 · 폐렴 3,494, 실제 학습용과 같은 구성)으로 이 브라우저에서 실제로 학습시키는 장면입니다설명용 합성 데이터. 입력은 0~1로 정규화한 뒤 픽셀마다 학습용 사진들의 평균을 뺀 값입니다(2단계에서 말한 "한 번 더 맞추기").

학습이 진행되면 가중치 지도에서 폐 영역이 붉게 물듭니다. "폐가 뿌옇게 밝으면 폐렴일 가능성이 높다"는 규칙을 사람이 알려 주지 않았는데도 데이터에서 찾아낸 것입니다. 학습 초반에는 학습용의 90%가 폐렴이라 모델이 "모두 폐렴"이라고만 답해 시험 정확도가 62.5%에 머뭅니다. 정상을 가려내기 시작하면서 정확도가 오릅니다. 학습률을 600으로 바꾸면 손실 곡선이 들쭉날쭉해지는 것도 확인해 보세요.

6 · 평가

정확도 하나로는 부족하다

학습에 쓰지 않은 시험용 사진으로 채점합니다. 모델은 확률 p를 내므로, p가 기준값(threshold)을 넘으면 "폐렴"이라고 판정합니다. 기준값을 움직여 보세요. 5단계의 모델과 합성 시험용 사진 624장(정상 234 · 폐렴 390, 실제 시험용과 같은 구성)을 그대로 씁니다설명용 합성 데이터.

5단계에서 학습하지 않은 상태라, 학습률 10으로 40 에폭 자동 학습한 모델로 평가했습니다.

함정: 클래스 불균형. 실제 시험용 624장 중 폐렴은 390장입니다. 사진을 보지도 않고 무조건 "폐렴"이라고 답하는 모델도 정확도 390 ÷ 624 = 62.5%를 얻습니다. 그래서 의료 영상에서는 폐렴을 놓치지 않는 비율(민감도)과 정상을 정상이라 하는 비율(특이도), 그리고 기준값을 0부터 1까지 모두 바꿔 가며 민감도와 특이도를 한꺼번에 요약한 AUC(Area Under the ROC Curve, 1에 가까울수록 좋음)를 함께 봅니다. 기준값을 낮추면 민감도는 오르고 특이도는 떨어집니다. 어느 쪽을 택할지는 모델이 아니라 사용 목적이 정합니다.

참고로 MedMNIST v2 논문의 기준 실험에서 ResNet-18(28×28 입력)은 PneumoniaMNIST 시험 정확도 약 85%, AUC 약 0.94를 보고했습니다. 이 페이지의 합성 데이터 수치와는 비교할 수 없습니다.

위 여섯 단계를 코드로 옮긴 최소 예시입니다. 학습용의 정상이 388장(10%)뿐이라 아래 코드로 학습하면 폐렴 쪽으로 치우치기 쉬우니, 결과는 정확도만 보지 말고 민감도·특이도로 확인하세요. Google Colab에서 그대로 실행할 수 있습니다. medmnist 패키지로 받는 방법을 기본으로 썼고, Kaggle에서 받은 .npz 파일을 쓰는 방법을 주석으로 달았습니다.

전체 코드 
# pip install medmnist torch torchvision scikit-learn
import numpy as np, torch, torch.nn as nn
from torch.utils.data import TensorDataset, DataLoader
from sklearn.metrics import roc_auc_score

# 1. 데이터 불러오기 ------------------------------------------
from medmnist import PneumoniaMNIST
def load(split):
    ds = PneumoniaMNIST(split=split, download=True)
    return ds.imgs, ds.labels            # (N,28,28) uint8, (N,1)
# Kaggle에서 받은 NumPy 배열(.npz)을 쓸 경우 (파일 이름과 키는 받은 파일에서 확인):
# d = np.load("pneumoniamnist.npz")
# load = lambda s: (d[f"{s}_images"], d[f"{s}_labels"])

# 2. 전처리: 0~1 정규화, (N,1,28,28) 모양, 정답은 실수 0/1 ----
def to_loader(split, shuffle):
    x, y = load(split)
    x = torch.tensor(x, dtype=torch.float32).unsqueeze(1) / 255.0
    y = torch.tensor(y, dtype=torch.float32)
    return DataLoader(TensorDataset(x, y), batch_size=64, shuffle=shuffle)
train_dl, val_dl, test_dl = (to_loader(s, s == "train") for s in ["train", "val", "test"])

# 3. 모델: 작은 CNN -------------------------------------------
model = nn.Sequential(
    nn.Conv2d(1, 16, 3), nn.ReLU(), nn.MaxPool2d(2),     # 16×13×13
    nn.Conv2d(16, 32, 3), nn.ReLU(), nn.MaxPool2d(2),    # 32×5×5
    nn.Flatten(), nn.Linear(32 * 5 * 5, 1)               # 점수 z
)

# 4. 손실 함수: 시그모이드 + 이진 교차 엔트로피 ---------------
loss_fn = nn.BCEWithLogitsLoss()
opt = torch.optim.Adam(model.parameters(), lr=1e-3)

def predict(dl):
    model.eval(); ps, ys = [], []
    with torch.no_grad():
        for x, y in dl:
            ps.append(torch.sigmoid(model(x))); ys.append(y)
    return torch.cat(ps).squeeze().numpy(), torch.cat(ys).squeeze().numpy()

# 5. 학습 -----------------------------------------------------
for epoch in range(10):
    model.train()
    for x, y in train_dl:
        opt.zero_grad()
        loss = loss_fn(model(x), y)
        loss.backward()          # 기울기 계산
        opt.step()               # w ← w − η·기울기
    p, y = predict(val_dl)
    print(f"epoch {epoch+1}  val AUC {roc_auc_score(y, p):.3f}")

# 6. 평가: 시험용은 마지막에 한 번 ------------------------------
p, y = predict(test_dl)
pred = (p > 0.5).astype(int)
tp = ((pred == 1) & (y == 1)).sum(); tn = ((pred == 0) & (y == 0)).sum()
print("정확도", (pred == y).mean())
print("민감도", tp / (y == 1).sum(), " 특이도", tn / (y == 0).sum())
print("AUC", roc_auc_score(y, p))

다음 실험 거리: ① 손실 함수에 pos_weight를 줘서 클래스 불균형 보정하기(학습용은 정상 : 폐렴이 약 1 : 9) ② 좌우 반전·회전 같은 데이터 증강(augmentation) 추가하기 ③ 64×64 이상 해상도 버전과 비교하기.

오개념 바로잡기

"AI가 사진을 사람처럼 본다"

모델이 받는 것은 784개의 숫자이고, 하는 일은 곱하고 더하는 계산입니다. "본다"는 비유일 뿐이며, 모델은 폐의 해부학을 모릅니다. 학습 데이터에서 정답과 함께 자주 나타난 픽셀 패턴에 반응할 뿐이라, 병원마다 다른 촬영 장비 표시나 글자 같은 엉뚱한 단서에 기대는 일도 실제로 보고됩니다(Zech et al., 2018).

"정확도 90%면 10명 중 9명을 맞힌다"

정확도는 시험 묶음의 구성에 따라 달라집니다. 폐렴이 62.5%인 시험 묶음과 5%인 실제 외래 환자군에서 같은 모델의 정확도는 크게 다릅니다. 민감도·특이도를 함께 보고, 쓰려는 현장의 비율을 따져야 합니다.

이 페이지는 학습용 교재이며, 모델 결과를 진단에 쓸 수 없습니다.
