Google Colab 사용하기

Google Colab은 Google의 컴퓨팅 자원으로 Python과 R의 Jupyter Notebook을 쓰는 웹 기반 코드·문서 작성 도구다. 설치 없이 브라우저에서 바로 쓸 수 있고, 무료 계정으로도 GPU를 쓸 수 있다.

주소
colab.research.google.com
쓸 수 있는 언어
런타임 설정에 따라 Python 또는 R
파일 저장 위치
Google Drive의 “Colab Notebooks” 폴더(기본값)
01

시작하기

첫 화면에서 + 새 노트를 누르면 Colab Notebook 창이 열린다.

노트북을 활성화하면 Google의 컴퓨팅 환경에 임의의 가상머신(Virtual Machine, VM)이 만들어지고, 이것이 독립된 컴퓨터 한 대처럼 작동한다. 런타임 설정에 따라 GPU, RAM, 디스크 등을 할당받는다. 무료 계정은 지속 시간이 일정하지 않지만 다음 정도의 자원을 제공한다.

자원무료 계정의 제공 수준
GPUT4, VRAM 약 15GB
시스템 RAM약 12GB
디스크약 100GB
02

화면 구성

번호영역하는 일
⓪파일 제목눌러서 파일 이름을 바꾼다. 기본 저장 위치는 Google Drive의 “Colab Notebooks”다.
①상단 메뉴파일, 셀, 런타임 작동 환경 등을 다루는 기본 메뉴다.
②노트북 메뉴명령어 바로가기, 코드 셀과 텍스트 셀 추가, 실행 단추가 있다.
③연결연결 정보를 보여 주고, 현재 런타임 변경과 Google의 다른 환경 연결 등을 지원한다. 03절에서 다룬다.
④좌측 사이드바텍스트 목차, 찾기, 코드 스니펫(미리 만든 코드 조각), Secrets(환경 변수 설정), 파일, 데이터 탐색기 등을 접고 펴는 사이드바다. 파일 항목은 현재 런타임이 제공하는 드라이브 경로를 보여 주며, Google Drive를 별도 경로로 연결할 수 있다.
⑤작업 영역셀 단위로 실행하는 파일 편집기다. 04절에서 다룬다.
⑥변수와 터미널현재 만들어진 변수를 확인하고 런타임의 셸(터미널)을 연다. 05절에서 다룬다.
⑦GeminiColab 안에서 쓰는 AI 대화 창이다. 질문을 하거나 코드 작성의 도움을 받는다.
03

런타임 연결

화면 오른쪽 위의 연결 영역에서 RAM과 디스크 사용량을 확인하고, 옆의 화살표로 메뉴를 연다. GPU를 쓰거나 언어를 바꾸려면 이 메뉴의 런타임 유형 변경을 고른다. 리소스 보기를 고르면 01절의 리소스 표시를 볼 수 있다.

04

코드 셀과 텍스트 셀

코드 셀

런타임 설정에 따라 Python이나 R 코드를 입력하고 셀 단위로 실행한다. 셀 앞의 실행 단추를 누르거나 다음 단축키를 쓴다.

단축키실행한 뒤
Ctrl (Command) + Enter현재 셀에 머문다
Shift + Enter다음 셀로 이동한다
Alt (Option) + Enter다음 셀을 새로 만든다

텍스트 셀

Markdown 문법으로 글을 입력한다. 더블클릭하거나 Enter를 눌러 수정한다.

05

터미널

화면 아래쪽의 터미널을 누르면 런타임의 셸이 열린다. 아래 화면에서는 작업 경로 /content에서 ls -al과 pwd를 실행했다. 옆의 변수는 현재 만들어진 변수를 보여 준다.
