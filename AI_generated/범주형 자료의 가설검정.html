01범주형 자료와 분할표

범주형 변수는 값이 "어느 칸에 속하는가"만 알려 줍니다. 순서가 없는 명목척도(사고유형, 성별)와 순서가 있는 서열척도(체형인식 5단계)로 나뉩니다. 이 교안의 검정은 모두 명목척도를 가정합니다. 서열 정보를 쓰는 방법(선형 추세 검정 등)은 범위 밖입니다.

범주형 자료 분석의 출발점은 빈도입니다. 평균 비교에서 개별 관측값을 그대로 썼다면, 여기서는 관측을 칸별로 세어 만든 표가 분석 대상입니다.

원자료 (한 행 = 사고 1건)→ 빈도표 (변수 1개)→ 분할표 (변수 2개, r × c)

세 가지 표 만들기 방법

같은 표를 만드는 방법이 여럿인 이유는, 결과 객체의 형태가 다르기 때문입니다. tidyverse의 count()는 데이터프레임을 돌려주어 그림과 가공에 편하고, base R의 table()·xtabs()는 검정 함수가 바로 받는 table 객체를 돌려줍니다.

# 데이터프레임 형태: 그림, 가공용
acc %>% count(주야, 사고유형)

# table 객체: 검정 함수 입력용
table(acc$주야, acc$사고유형)
xtabs(~ 주야 + 사고유형, data = acc)

# 보기 좋은 교차표 (행 비율 + 빈도)
acc %>%
  tabyl(주야, 사고유형) %>%
  adorn_percentages("row") %>%
  adorn_pct_formatting(digits = 1) %>%
  adorn_ns()
요점

chisq.test()는 받은 객체의 모양으로 검정을 고릅니다. 1차원 빈도표를 주면 적합도 검정, 2차원 분할표를 주면 독립성 검정을 합니다(LSR 12.6). 그래서 "지금 어떤 모양의 객체를 넘기는가"를 항상 확인해야 합니다.

04단일 비율과 적합도 검정

먼저 생각할 문제: 전수 자료에 검정을 하는가

사망교통사고 자료는 표본이 아니라 그해 경찰에 접수된 사망사고 전체입니다. 그런데도 검정을 하는 근거는, 올해의 사고 건수를 "요일별 사고 발생 확률이라는 생성 과정"에서 나온 하나의 실현값으로 보는 데 있습니다(초모집단 관점). 이때 검정이 답하는 질문은 "올해 숫자가 같았는가"가 아니라 "사고를 만드는 과정이 요일에 따라 다르다고 볼 증거가 있는가"입니다. 수업에서 이 해석을 먼저 짚고 넘어갑니다.

4.1 적합도 검정의 논리

범주가 \(k\)개인 변수에 대해 귀무가설이 각 범주의 확률 \(p_1, \dots, p_k\)를 정해 주면, 표본크기 \(N\)에서 기대도수는 \(E_i = N p_i\)입니다. 관측도수 \(O_i\)와의 차이를 모은 통계량이 Pearson χ²입니다.

\[ X^2 = \sum_{i=1}^{k} \frac{(O_i - E_i)^2}{E_i} \;\; \overset{H_0}{\approx} \;\; \chi^2_{k-1} \]

자유도가 \(k-1\)인 이유는, 총합 \(N\)이 정해지면 마지막 칸의 도수가 나머지에 의해 결정되기 때문입니다. 평균 비교에서 표본분산의 자유도가 \(n-1\)이었던 것과 같은 논리입니다.

손계산 예제 (LSR 12.1의 카드 자료)

200명이 카드 무늬 하나씩을 골랐더니 클로버 35, 다이아 51, 하트 64, 스페이드 50이었습니다. 네 무늬가 같은 확률이라면 기대도수는 모두 50입니다.

\[ X^2 = \frac{(35-50)^2 + (51-50)^2 + (64-50)^2 + (50-50)^2}{50} = \frac{225 + 1 + 196 + 0}{50} = 8.44 \]

자유도 3에서 \(p = .0377\)입니다. 아래 χ² 분포 탐색기에 자유도 3, 통계량 8.44를 넣어 확인해 보세요.

한 해의 요일 수는 같지 않습니다. 365일이면 한 요일이, 윤년이면 두 요일이 53번 나옵니다. "하루당 사고 확률이 같다"를 귀무가설로 삼으려면 요일별 일수에 비례한 확률을 p에 넣습니다. 귀무가설을 말로 정확히 쓰는 연습으로 좋습니다(LSR 12.1.8).

yr <- 2024
days <- tibble(날짜 = seq(as.Date(paste0(yr, "-01-01")),
                          as.Date(paste0(yr, "-12-31")), by = "day")) %>%
  mutate(요일번호 = wday(날짜, week_start = 1)) %>%   # 1 = 월요일
  count(요일번호)

chisq.test(obs_day, p = days$n / sum(days$n))

4.3 단일 비율: 야간 사고는 절반인가

범주가 두 개뿐이면 적합도 검정은 단일 비율 검정과 같아집니다. 이때는 이항분포로 정확한 p-value를 구할 수 있습니다. prop.test()는 같은 질문을 정규근사(연속성 보정 포함)로 답합니다.

n_night <- sum(acc$주야 == "야")
n_all   <- nrow(acc)

binom.test(n_night, n_all, p = 0.5)   # 정확검정 + Clopper-Pearson 신뢰구간
prop.test(n_night, n_all, p = 0.5)    # 정규근사 (= 자유도 1인 χ² 검정)

# Cohen's h: 비율을 아크사인 변환한 척도에서의 차이
p_hat <- n_night / n_all
h <- 2 * asin(sqrt(p_hat)) - 2 * asin(sqrt(0.5))
h

05두 비율 비교와 독립성 검정

5.1 독립성인가, 동질성인가

같은 \(r \times c\) 분할표와 같은 χ² 계산을 쓰지만, 자료를 모은 방식에 따라 귀무가설의 표현이 다릅니다.

독립성 검정동질성 검정
고정된 것전체 \(N\)만집단(행)별 표본크기

06가정 점검과 Fisher 정확검정

6.1 χ² 검정의 두 가정

  1. 관측의 독립. 한 관측이 한 칸에만 들어가고, 관측끼리 서로 영향을 주지 않아야 합니다. 같은 사람을 두 번 세면 이 가정이 깨지며, 이때는 8장의 McNemar 검정을 씁니다(LSR 12.5).
  2. 기대도수가 충분히 큼. 흔히 "모든 기대도수 5 이상"을 기준으로 씁니다. 출처인 Cochran의 원래 권고는 "기대도수 1 미만인 칸이 없고, 5 미만인 칸이 20%를 넘지 않음"에 가깝습니다. Campbell(2007)의 모의실험은 2 × 2 표에서 이 규칙이 생각보다 보수적이라는 점을 보였습니다.

3장에서 철길건널목 사고를 '기타'로 묶은 이유가 여기 있습니다. 한 해에 몇 건 안 되는 유형을 그대로 두면 기대도수가 1 근처로 떨어져 χ² 근사가 무너집니다. 범주 통합은 이론적으로 말이 되는 경우에만 하고, 통합한 사실을 보고합니다.

6.2 Fisher 정확검정

행 합과 열 합을 고정하면 2 × 2 표에서 한 칸의 값이 정해질 때 나머지가 모두 정해지고, 그 칸의 분포는 초기하분포입니다. Fisher 검정은 검정통계량 없이, 관측된 표와 같거나 더 극단적인 표가 나올 확률을 직접 더합니다(LSR 12.7).

\[ P(a \mid \text{행·열 합}) = \frac{\binom{a+b}{a}\binom{c+d}{c}}{\binom{N}{a+c}} \]

LSR의 마녀 예제(행복함 × 화형 중, 16명)에서 chisq.test()는 경고와 함께 Yates 보정 \(p = .069\)를 내지만, Fisher 검정은 \(p = .036\)입니다. 5장 계산기의 "LSR 마녀 예제" 버튼으로 두 값을 나란히 확인해 보세요.

07사후 분석: 표준화 잔차

r × c 표의 χ² 검정이 유의하면 "어딘가 다르다"까지만 알 수 있습니다. 어느 칸이 차이를 만들었는지는 표준화 잔차(adjusted residual)로 봅니다. H₀ 아래에서 근사적으로 표준정규분포를 따르므로, 절댓값이 2(정확히는 1.96)를 넘는 칸을 기대보다 유난히 많거나 적은 칸으로 읽습니다.

\[ r_{ij} = \frac{O_{ij} - E_{ij}}{\sqrt{E_{ij}\,(1 - p_{i\cdot})(1 - p_{\cdot j})}} \]

칸이 많으면 우연히 2를 넘는 칸이 생기기 쉬우므로, 칸 수 \(m\)으로 Bonferroni 보정한 기준 \(z_{1-\alpha/(2m)}\)을 함께 봅니다.

ind_dt <- chisq.test(table(acc$요일, acc$사고유형))
round(ind_dt$stdres, 2)

m <- length(ind_dt$stdres)
cut_bonf <- qnorm(1 - 0.05 / (2 * m))   # 칸이 21개면 약 3.03
cut_bonf

res_df <- as.data.frame(ind_dt$stdres) %>%
  rename(요일 = Var1, 사고유형 = Var2, 잔차 = Freq)

g <- ggplot(res_df, aes(x = 사고유형, y = 요일, fill = 잔차)) +
  geom_tile(color = "white") +
  geom_text(aes(label = sprintf("%.1f", 잔차),
                fontface = if_else(abs(잔차) > cut_bonf, "bold", "plain"))) +
  scale_fill_gradient2(low = "#2F6FA6", mid = "white", high = "#C0563B", midpoint = 0) +
  labs(title = "요일 × 사고유형 표준화 잔차",
       subtitle = "굵은 숫자: Bonferroni 보정 기준을 넘는 칸",
       x = NULL, y = NULL, fill = "표준화 잔차")

ggsave("output/stdres_day_type.png", g, width = 7, height = 5, dpi = 300)

08대응 범주 자료: McNemar 검정

8.1 왜 독립성 검정을 쓰면 안 되는가

국민건강영양조사의 성인 응답자 한 사람마다 두 판정이 있습니다. 본인이 비만이라고 생각하는가(인식), 그리고 BMI 25 이상인가(측정). 이 두 판정으로 2 × 2 표를 만들면 한 사람이 한 칸에 들어가지만, 행과 열이 같은 사람의 두 측정입니다. 질문도 독립성 검정과 다릅니다.

측정: 비만측정: 비만 아님
인식: 비만a (일치)b (과대 인식)
인식: 비만 아님c (과소 인식)d (일치)
  • 독립성 검정은 "인식과 측정이 관련 있는가"를 묻습니다. 같은 사람의 두 판정이니 관련이 있는 것은 당연해서, 대개 아주 작은 p가 나오고 별 정보가 없습니다.
  • McNemar 검정은 "인식 비만 비율 \((a+b)/N\)과 측정 비만 비율 \((a+c)/N\)이 같은가"를 묻습니다(주변 동질성). 두 비율의 차이는 \((b-c)/N\)이므로, 정보는 불일치 칸 b와 c에만 있습니다.
\[ X^2 = \frac{(|b - c| - 1)^2}{b + c} \;\overset{H_0}{\approx}\; \chi^2_1, \qquad H_0:\; b \text{와 } c \text{가 나올 가능성이 같음} \]

H₀ 아래에서 불일치한 \(b+c\)명 중 b에 속할 수는 이항분포 \(\text{Bin}(b+c,\, 0.5)\)를 따르므로, binom.test()로 정확검정도 할 수 있습니다. Fagerland 등(2013)은 작은 표본에서 이 정확 조건부 검정이 지나치게 보수적이므로 mid-p나 보정 없는 근사 검정을 권합니다.

8.3 같은 표, 다른 질문 (LSR 12.9)

LSR은 같은 사람이 카드를 두 번 고른 4 × 4 표에 독립성 검정과 McNemar 검정을 모두 적용해, 결과가 다르게 나오는 것을 보여 줍니다. 첫 번째 선택이 두 번째 선택과 관련 있는가(독립성)와, 두 번째 선택의 무늬 분포가 첫 번째와 달라졌는가(주변 동질성)는 다른 질문이기 때문입니다. 체형 자료에서도 두 검정을 나란히 돌려, 각 p-value가 무엇에 대한 답인지 문장으로 써 보게 합니다.

9.2 다음 단계: 로지스틱 회귀

2 × 2 표의 오즈비는 로지스틱 회귀에서 이분형 설명변수 하나를 넣었을 때의 \(\exp(\beta_1)\)과 같습니다. 분할표 검정은 설명변수가 하나뿐이고 범주형일 때의 특수한 경우이며, 연속형 공변량을 넣거나 여러 변수를 동시에 통제하려면 로지스틱 회귀로 넘어갑니다(James 외, 2013, 4.3절).

fit <- glm(보행자사고 == "차대사람" ~ 주야, family = binomial, data = acc)
summary(fit)
exp(coef(fit))   # '주야야' 계수: 야간 대 주간의 오즈비

oddsratio(tab22) # 주간 대 야간의 오즈비 → 위 값의 역수
anova(fit, test = "Chisq")   # 가능도비 χ² 검정: 독립성 검정과 비슷한 값

두 오즈비가 서로 역수로 나오는 것은 기준 범주가 반대이기 때문입니다. 표에서는 첫 행(주간)이, glm()에서는 첫 수준(주간)이 기준이지만 비교 방향이 뒤집혀 있습니다. 이 차이를 직접 확인하는 것이 로지스틱 회귀 차시로 넘어가는 좋은 연결 고리가 됩니다.
