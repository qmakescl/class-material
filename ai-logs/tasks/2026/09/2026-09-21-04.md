## 사용자 요청

> katex 을 이용하고, 전체 페이지에도 적용하게 해줘. 그리고 네가 말한 것처럼 svg 에는 katex 표현이 그대로 나오니 지금 설정을 유지한다.

## AI 응답 요약

KaTeX를 저장소에 포함하고, 통계 자료 4개 페이지의 수식을 HTML/CSS 흉내 방식에서 KaTeX 표기로 바꿨다. SVG·canvas 글자는 기존 유니코드 표기를 유지했다.

## 수행 작업

- `docs/assets/katex/`에 KaTeX 0.16.11(min JS, auto-render, min CSS, woff2 폰트, LICENSE)을 추가했다.
- `docs/assets/math.js`를 추가해 로드 시 전체 렌더링, JS가 나중에 넣는 문자열의 자동 재렌더링을 처리하게 했다.
- 네 자료 페이지(확률, 점추정과 신뢰구간, 가설검정, 최소제곱과 잔차)의 `.eq`/`.frac`/`.radical`/`.math` 수식, sub/sup, 기호를 `\( \)`·`\[ \]`로 바꾸고 불필요해진 수식용 CSS를 제거했다.
- 페이지 JS가 innerHTML/textContent로 넣는 수식 문자열(표, 결과 패널, 퀴즈 등)도 KaTeX 구분자로 바꿨다. `id="ex-stat-formula"` 등 JS가 참조하는 요소는 유지했다.
- `DESIGN.md`에 "수식 표기" 절을, `README.md`에 안내 문구를 추가했다.

## 검증

- 헤드리스 Chrome DOM 덤프로 4개 페이지 모두 KaTeX 오류 0건, 렌더되지 않은 구분자 잔존 0건, 콘솔 오류 0건 확인
- 4개 페이지 스크린샷으로 정적·동적 수식 렌더링 육안 확인
- 슬라이더 조작 후의 재렌더링은 초기 렌더 결과로만 확인했고 모든 인터랙션 상태를 조작해 보지는 않았다.
