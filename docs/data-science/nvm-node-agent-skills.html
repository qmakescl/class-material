nvm과 Node.js, 에이전트 스킬 설치하기

코딩 에이전트(Antigravity)가 Word 보고서를 잘 만들도록 docx 스킬을 설치한다. 스킬 설치 명령과 스킬이 쓰는 코드가 Node.js로 돌아가므로, 버전 관리 도구 nvm으로 Node.js 24를 먼저 설치한다. 컴퓨터마다 한 번만 하면 되고, 스킬은 작업 폴더마다 한 번 설치한다.

설치하는 것
nvm(macOS·Linux) 또는 NVM for Windows 2.0(Windows), Node.js 24, docx 스킬
먼저 해 둘 것
VS Code와 Antigravity 확장. 아직이면 VS Code에서 R 실행하기를 먼저 따라 한다.
이 환경을 쓰는 자료
분산분석: 일원배치에서 혼합 설계까지의 결과보고서
01

무엇을 왜 설치하나

이름하는 일왜 필요한가
Node.jsJavaScript 프로그램을 컴퓨터에서 실행한다스킬 설치 명령 npx와 docx 스킬이 Word 파일을 만드는 코드가 Node.js로 돌아간다
nvmNode.js의 여러 버전을 설치하고 바꿔 쓴다관리자 권한 없이 설치하고, 버전 문제가 생기면 쉽게 바꿀 수 있다
에이전트 스킬에이전트가 특정 작업을 할 때 읽는 지침과 도구를 묶은 폴더다docx 스킬이 있으면 에이전트가 Word 문서의 표, 그림, 서식을 다루는 절차를 그대로 따른다

운영체제에 맞는 절만 따라 한 뒤 04절로 간다.

02

macOS·Linux: nvm과 Node.js 24

  1. nvm을 설치한다. 터미널에서 실행한다.
    터미널
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.8/install.sh | bash
  2. 터미널을 새로 열고 확인한다. nvm이 출력되면 된다. which nvm은 쓰지 않는다. nvm은 프로그램 파일이 아니라 셸 함수라서 설치되어 있어도 아무것도 나오지 않는다.
    터미널
    command -v nvm
  3. Node.js 24를 설치하고 기본값으로 정한다.
    터미널
    nvm install 24
nvm alias default 24
  4. 버전을 확인한다. node -v가 v24로 시작하면 된다.
    터미널
    node -v
npx -v
macOS에서 nvm: command not found가 나오면

macOS의 기본 셸은 zsh이고 nvm은 ~/.zshrc에 설정을 적는다. 이 파일이 없으면 만든 뒤 설치 명령을 다시 실행한다.

터미널
touch ~/.zshrc

그래도 안 되면 ~/.zshrc 끝에 아래 두 줄을 넣고 터미널을 새로 연다.

~/.zshrc
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && \. "$NVM_DIR/nvm.sh"
03

Windows: NVM for Windows 2.0과 Node.js 24

Windows용은 macOS·Linux의 nvm과 다른 프로젝트다. 2.0부터 저장소가 github.com/nvm-windows/nvm으로 옮겨졌다. 예전 안내에 나오는 coreybutler/nvm-windows의 1.x 설치 파일을 받지 않도록 주의한다.

  1. 설치 파일을 내려받는다. 최신 안정 버전 페이지의 Assets에서 고른다. 대부분의 PC는 x64이고, ARM 노트북이면 arm64다. 버전 2.0.1이면 파일 이름은 다음과 같다. 이름에 beta가 들어간 시험판은 받지 않는다.
    내려받을 파일
    nvm-2.0.1-x64-setup.exe      일반 PC (Intel, AMD)
nvm-2.0.1-arm64-setup.exe    ARM 노트북
  2. 일반 사용자 권한으로 실행한다. "관리자 권한으로 실행"을 쓰지 않는다. 관리자로 설치하면 내 계정이 아니라 관리자 계정에 설정된다. 설치 중 권한 확인 창이 떠도 거부해도 동작에는 문제가 없다.
  3. PowerShell이나 VS Code 터미널을 새로 열고 Node.js 24를 설치한다. nvm use 24가 이 버전을 기본값으로 정한다.
    PowerShell
    nvm install 24
nvm use 24
  4. 버전을 확인한다. node -v가 v24로 시작하면 된다.
    PowerShell
    node -v
npx -v
nvm default

이미 Node.js가 설치되어 있다면. 설치 마법사가 기존 Node.js를 어떻게 할지 물을 수 있으니 안내를 읽고 고른다. 설치 뒤 문제가 있으면 nvm doctor로 점검한다. NVM for Windows 1.x를 쓰고 있었다면 설치 파일이 2.0으로 옮겨 준다.

04

docx 스킬 설치

스킬은 skills.sh에서 찾을 수 있다. 여기서는 Anthropic이 공개한 docx 스킬을 설치한다.

  1. 작업 폴더를 VS Code로 열고 터미널을 연다. 스킬은 지금 폴더에 설치되므로, 분석을 할 폴더에서 실행한다.
  2. 설치 명령을 실행한다.
    터미널
    npx skills add https://github.com/anthropics/skills --skill docx
  3. 질문에 답한다. 처음 실행하면 skills 패키지를 설치할지 묻는다. y를 누른다. 어느 에이전트에 설치할지 물으면 Antigravity를 고른다. 설치 범위를 물으면 이 폴더(Project)를 고른다.
  4. 설치를 확인한다. 목록에 docx가 보이고, 작업 폴더에 .agents/skills/docx/SKILL.md가 생기면 된다.
    터미널
    npx skills list
질문 없이 한 번에 설치하려면

에이전트를 지정하고 확인을 건너뛴다.

터미널
npx skills add https://github.com/anthropics/skills --skill docx -a antigravity -y

모든 작업 폴더에서 쓰려면 -g를 더한다. 이때는 ~/.gemini/antigravity/skills/에 설치된다.

작업 폴더/
├── .agents/
│   └── skills/
│       └── docx/
│           ├── SKILL.md      에이전트가 읽는 지침
│           ├── LICENSE.txt   이용 조건
│           └── scripts/      문서를 다루는 도구
└── skills-lock.json          설치한 스킬의 기록

스킬은 에이전트의 권한으로 실행된다. 설치 도구도 사용 전에 검토하라고 안내한다. 믿을 수 있는 곳의 스킬만 설치하고, SKILL.md를 한 번 읽어 본다. docx 스킬의 이용 조건은 오픈 소스가 아니라 LICENSE.txt를 따르므로, 저장소를 공개한다면 이 폴더를 함께 올려도 되는지 먼저 확인한다.

05

스킬 쓰기와 문제 해결

Antigravity의 대화를 새로 시작하고, 스킬을 쓰라고 적어 시킨다. 아래 프롬프트로 설치를 시험한다.

프롬프트 · 설치 시험
.agents/skills/docx 의 docx 스킬을 읽고, 그 안내대로 output/report/test.docx 를 만들어 줘.
- 제목 한 줄, 문단 한 개, 가로선만 있는 2행 2열 표 한 개를 넣는다.
- 어떤 스킬을 읽었는지와, 설치가 더 필요했던 것이 있는지 알려 준다.
증상원인해결
node나 npx를 찾을 수 없다설치 전에 열어 둔 터미널이다터미널을 새로 연다. VS Code도 다시 시작한다
node -v가 24가 아니다다른 버전이 기본값이다macOS·Linux는 nvm alias default 24, Windows는 nvm use 24
npx skills가 실행되지 않는다Node.js 버전이 낮다. skills는 22.20 이상이 필요하다위와 같이 24로 바꾼다
에이전트가 스킬을 쓰지 않는다설치 전에 시작한 대화이거나 다른 폴더를 열었다스킬을 설치한 폴더를 열고 대화를 새로 시작한다. 프롬프트에 경로를 적는다
Cannot find module 'docx'스킬이 쓰는 JavaScript 패키지가 없다스킬의 안내대로 작업 폴더에서 npm install docx를 실행한다
soffice나 pdftoppm이 없다는 메시지완성한 문서를 그림으로 바꿔 살피는 도구(LibreOffice, Poppler)가 없다문서는 만들어진다. 에이전트에게 이 점검을 건너뛰게 하고, Word로 직접 열어 확인한다

확인 범위

스킬 설치 명령은 macOS의 임시 폴더에서 비대화 방식(-a antigravity -y)으로 실행해 위 구조로 설치되는 것을 확인했다. 이때 Node.js는 22.22였다. 스킬이 쓰는 docx 패키지로 가로선 표, 기울임꼴, 그림이 든 Word 파일이 만들어지는 것도 확인했다. nvm과 NVM for Windows의 명령은 공식 문서(2026년 10월 기준)를 옮긴 것으로, 이 자료를 쓰며 Windows와 Linux에서 직접 실행하지는 않았다. Antigravity가 스킬을 실제로 불러오는 것도 직접 확인하지 않았으니, 위 설치 시험 프롬프트로 확인한다.
