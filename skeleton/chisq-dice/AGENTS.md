# AGENTS.md

이 폴더에서 일하는 코딩 에이전트(Codex, Claude Code 등)가 따르는 규칙이다.
사람이 R 코드를 직접 쓸 때도 같은 규칙을 따른다.

## 이 폴더

[멘델의 독립 법칙은 조작일까? - 카이제곱 통계량 소개](https://qmakescl.github.io/class-material/data-science/mendel-chi-square-intro.html)
자료의 10절 "컴퓨터로 확인하기"와 11절 "주사위로 실험하기"를 따라 하는 실습 폴더다.

- 10절: 멘델(1866)의 완두 556개가 9:3:3:1을 따르는지 카이제곱 적합도 검정을 한다. 관찰 개수는
  프롬프트에 숫자로 주어지므로 자료 파일이 없다. 스크립트에 그 숫자를 그대로 적는다.
- 11절: 웰던(Weldon, 1894)의 주사위 실험을 컴퓨터로 재현한다. 주사위 12개를 한 번에 던지기를
  여러 번 되풀이한 것을 흉내 내고, 던진 횟수를 늘려 가며 각 눈의 개수 차이·비율 차이와 카이제곱
  통계량이 어떻게 달라지는지 본다. 같은 실험을 실제 주사위로 되풀이한 래비(Labby, 2009)의 기록과
  견주고, 웰던이 센 방식(한 번 던질 때 5 또는 6이 나온 주사위의 수)으로도 센다.

## 폴더와 경로

```text
chisq-dice/
├── AGENTS.md        # 이 규칙
├── scripts/         # R 스크립트 (.R)
├── dataset/
│   ├── raw/         # 실측 자료. 읽기만 한다
│   │   └── labby_2009_faces.csv
│   └── working/     # 컴퓨터로 흉내 낸 결과와 정리한 자료
└── output/          # 표(CSV)와 그림(PNG)
```

- 작업 폴더는 언제나 `chisq-dice/`이다. 스크립트 안의 경로는 이 폴더를 기준으로 한 상대 경로로
  적는다. 예: `dataset/raw/labby_2009_faces.csv`, `output/weldon_chisq.png`.
- `setwd()`나 사용자 컴퓨터의 절대 경로(`/Users/...`, `C:\...`)를 쓰지 않는다.
- 스크립트는 `scripts/`에, 그림과 표는 `output/`에 둔다. 파일 이름은 영문 소문자와 `-`, `_`로 쓴다.

## 자료

- `dataset/raw/labby_2009_faces.csv`: 래비(2009)가 주사위 12개를 한 번에 던지기를 26,306번 되풀이해
  얻은 눈별 개수(모두 315,672개)다. 열은 `face`(눈, 1~6)와 `observed`(나온 횟수) 두 개다.
  출처: Rundel, C. (2013). Lecture 13 – χ² Tests, Statistics 102, Duke University, 5쪽의 표.
  **실측 자료이므로 고치거나 덮어쓰지 않는다.**
- 웰던 본인의 집계는 이 폴더에 없다. 웰던의 실험은 컴퓨터로 흉내 내어 재현한다.

## 컴퓨터로 흉내 내기 (시뮬레이션)

- 주사위는 눈마다 1/6의 확률로 흉내 낸다. 난수를 쓰는 스크립트는 맨 앞에서 `set.seed()`로 시드를
  정하고, 사용자에게 결과와 함께 그 시드를 알린다. 프롬프트가 시드를 정하지 않으면 1894를 쓴다.
- 흉내 낸 결과는 `dataset/working/`에 둔다(예: `weldon_sim.rds`). 한 행이 한 번 던지기이고
  `throw`(몇 번째)와 `d1`~`d12`(주사위 12개의 눈) 열을 둔다. 다른 스크립트는 이 파일을 읽어 쓰고,
  다시 흉내 내지 않는다.
- 흉내 낸 결과를 실측 자료(`dataset/raw/`)에 섞거나 실측인 것처럼 적지 않는다. 표와 그림의 제목이나
  범례에 "컴퓨터로 흉내 낸 주사위"와 "래비의 실제 주사위"를 구별해 적는다.
- 던진 횟수를 늘려 가며 볼 때는 따로따로 다시 흉내 내지 않고, 한 번 흉내 낸 기록의 처음 n번을
  잘라 쓴다(20번, 200번, 2,000번, 20,000번, 200,000번).

## R 규칙

- **tidyverse를 쓴다.** 스크립트 맨 위에서 `library(tidyverse)`로 불러온다.
  - 파일은 readr(`read_csv()`, `write_csv()`, `read_rds()`, `write_rds()`)로 읽고 쓴다.
  - 자료 가공은 dplyr(`filter()`, `mutate()`, `count()`, `group_by()`, `summarise()`)와
    tidyr(`pivot_longer()`, `pivot_wider()`), 반복은 purrr(`map()`)로 한다.
  - 파이프는 tidyverse(magrittr)의 `%>%`를 쓴다. R 기본 파이프 `|>`는 쓰지 않는다.
  - base R의 `read.csv()`, `subset()`, `table()`로 표 만들기, `apply` 계열로 요약하기는 쓰지 않는다.
- 난수(`sample()`), 검정과 분포 함수(`chisq.test()`, `pchisq()`, `qchisq()`, `dbinom()`)는 R 기본 함수를 쓴다.
- 눈이 한 번도 나오지 않은 칸도 0으로 세어 여섯 칸을 모두 둔다(눈을 `factor(levels = 1:6)`로 다룬다).
- 기대 개수가 5보다 작은 칸이 있으면 끝 칸끼리 합쳐 모든 칸이 5 이상이 되게 하고, 어떻게 합쳤는지와
  그에 따른 자유도를 알린다.
- 표의 숫자가 잘려 보이지 않도록 스크립트 앞부분에 `options(pillar.sigfig = 7)`을 둔다.

## 시각화 규칙

- **그림은 tidyverse에 들어 있는 ggplot2로만 그린다.** base 그래픽(`plot()`, `hist()`,
  `barplot()`, `curve()`)과 다른 그래픽 패키지는 쓰지 않는다.
- 그림은 `ggsave()`로 `output/`에 PNG로 저장한다. 크기는 인치로 정한다(예: `width = 7, height = 5`).
- 축 이름과 제목은 한국어로 쓴다. 예: `"던진 횟수"`, `"카이제곱 통계량"`, `"비율 차이 (%p)"`.
- 던진 횟수(20 ~ 200,000)를 가로축에 둘 때는 로그 눈금(`scale_x_log10()`)을 쓴다.
- 색은 컴퓨터로 흉내 낸 값에 `#0ea968`(초록), 래비의 실제 기록에 `#0b1220`(먹색),
  이론값(기대 개수, 1/6, 0선)에 `#0b1220` 점선, 판단 기준선(유의수준 0.05의 임계값)에 `#d1264f` 점선을 쓴다.

## 한글 글꼴 규칙

- **한글은 showtext로 Google Fonts의 Noto Sans KR을 쓴다.** 스크립트 앞부분에 다음을 둔다.

  ```r
  library(showtext)
  font_add_google("Noto Sans KR", "notosanskr")
  showtext_auto()
  showtext_opts(dpi = 300)   # ggsave()의 기본 해상도와 맞춘다
  ```

- ggplot의 테마에는 `base_family = "notosanskr"`를 준다. 예: `theme_minimal(base_family = "notosanskr")`.
- extrafont, 시스템에 설치된 다른 한글 글꼴, `par(family = ...)`는 쓰지 않는다.
- `font_add_google()`은 처음 한 번 인터넷에서 글꼴을 내려받는다. 인터넷이 없어 실패하면
  다른 글꼴로 바꾸지 말고 그 사실을 사용자에게 알린다.

## 패키지

- 필요한 패키지는 tidyverse와 showtext 두 가지다.
- 설치되어 있지 않으면 마음대로 설치하지 말고, 설치 명령
  `install.packages(c("tidyverse", "showtext"))`을 사용자에게 알려 동의를 받은 뒤 실행한다.

## 실행과 보고

- 스크립트를 쓰면 `chisq-dice/`에서 `Rscript scripts/<파일>.R`로 실제로 실행해 오류가 없는지 확인한다.
- 사용자에게는 실행한 명령, 쓴 시드, 콘솔에 나온 주요 수치, 저장한 파일 경로를 알린다.
  숫자를 지어내거나 실행하지 않은 결과를 적지 않는다.
- 설명은 한국어로 한다. 통계 용어는 자료 페이지의 표기를 따른다(영가설, 대안가설, 기대 개수, 자유도, p값).
- 검정 결과는 "카이제곱(자유도, N = 센 주사위 수) = 값, p = 값"으로 적는다. 유의하지 않으면
  "공정하다"가 아니라 "공정하지 않다고 볼 증거가 없다"로 쓴다.
- 결과를 해석해 결론을 대신 내려 주기보다, 표와 그림에서 무엇을 보면 되는지를 알려 준다.
  판단은 사용자가 한다.
