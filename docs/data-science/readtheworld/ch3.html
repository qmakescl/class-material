3.1데이터프레임이라는 공통 개념

R과 Python 모두 표 모양의 데이터를 데이터프레임이라고 부른다. 한 행이 관측 하나, 한 열이 변수 하나다. 지하철 데이터에서 한 행은 “어느 날, 어느 역의 승차(또는 하차)”다.

R에서는 tidyverse의 dplyr와 stringr, Python에서는 pandas를 쓴다. 이름은 다르지만 하는 일은 거의 일대일로 대응한다. 2장에서 읽어 들인 subway를 이어서 쓴다.

3.2열 빼기와 이름 바꾸기

연번은 줄 번호일 뿐이라 뺀다. 자주 쓸 열은 이름을 짧게 바꾼다.

R
subway <- subway |>
  select(-연번) |>
  rename(역 = 역명,
         구분 = 승하차구분)
Python
subway = (subway
          .drop(columns="연번")
          .rename(columns={"역명": "역",
                           "승하차구분": "구분"}))

3.3행 거르기

조건에 맞는 행만 남긴다. 2호선 강남역의 승차 기록만 골라 보자.

R
subway |>
  filter(호선 == "2호선",
         역 == "강남",
         구분 == "승차")
Python
subway.query(
    '호선 == "2호선" and 역 == "강남"'
    ' and 구분 == "승차"')
자주 하는 실수 같은지 비교할 때는 =가 아니라 ==다. 결과가 0행이면 먼저 값의 표기를 확인한다. 예를 들어 역 이름이 강남인지 강남역인지는 데이터를 봐야 안다.

3.4정렬하기

아침 8시대에 가장 많이 탄 기록을 본다. 열 이름이 숫자로 시작하거나 -가 들어 있으면 R에서는 `(백틱)로 감싼다.

R
subway |>
  filter(구분 == "승차") |>
  arrange(desc(`08-09시간대`)) |>
  head(10)
Python
(subway
 .query('구분 == "승차"')
 .sort_values("08-09시간대", ascending=False)
 .head(10))

3.5새 열 만들기

시간대 20개 열을 옆으로 모두 더해 하루 열을 만든다. “여기부터 저기까지의 열”을 한 번에 가리킬 수 있다.

R
subway <- subway |>
  mutate(하루 = rowSums(
    across(`06시이전`:`24시이후`)))
Python
subway["하루"] = (
    subway.loc[:, "06시이전":"24시이후"]
    .sum(axis=1))

3.6그룹별 요약

“역별로 묶어서 평균을 낸다”처럼, 묶는 기준과 계산을 차례로 적는다.

R
subway |>
  filter(구분 == "승차") |>
  group_by(역) |>
  summarise(평균승차 = mean(하루),
            행수 = n()) |>
  arrange(desc(평균승차))
Python
(subway
 .query('구분 == "승차"')
 .groupby("역")
 .agg(평균승차=("하루", "mean"),
      행수=("하루", "size"))
 .sort_values("평균승차", ascending=False)
 .reset_index())

결과를 보고 생각해 볼 것: 행수가 다른 역의 두세 배인 역이 있다. 환승역은 호선마다 역번호가 달라 따로 기록되기 때문이다. 역 이름만으로 묶으면 여러 호선이 합쳐진다.

3.7명령 이어 쓰기

위 예제들은 이미 여러 명령을 이어 쓰고 있다. R은 |>(파이프)로, Python은 .(메서드 체이닝)으로 잇는다. 둘 다 “앞의 결과를 받아서 다음 일을 한다”로 읽는다.

3.8자료형 확인하기: 날짜인가, 글자인가

수송일자는 2025-01-01처럼 적혀 있다. 연도 네 자리, 월 두 자리, 일 두 자리를 -로 잇는 YYYY-mm-dd는 날짜의 국제 표준 표기다. 그런데 모양이 날짜라고 해서 컴퓨터가 날짜로 알고 있는 것은 아니다. 자료형을 확인한다.

R
class(subway$수송일자)
# "Date" 이면 날짜형
# "character" 이면 문자열
Python
subway["수송일자"].dtype
# datetime64 이면 날짜형
# object 또는 str 이면 문자열
두 언어가 다르게 읽는다 같은 파일인데 결과가 다를 수 있다. R의 read_csv()는 표준 표기의 날짜를 알아보고 스스로 날짜형으로 읽는다. Python의 pd.read_csv()는 시키지 않으면 문자열로 둔다. 그래서 읽은 뒤에는 자료형부터 확인한다.

3.9정규표현식: 모양으로 글자를 다루기

한 해치의 수많은 값이 전부 YYYY-mm-dd 모양인지 눈으로 확인할 수는 없다. 정해진 글자가 아니라 모양을 말로 적어 검사하는 도구가 정규표현식이다.

기호뜻예
\d숫자 한 글자\d\d는 숫자 두 글자
{n}, {m,n}바로 앞의 것이 n번, m~n번\d{4}는 숫자 네 글자
^, $문자열의 처음, 끝^\d{4}는 맨 앞의 숫자 네 글자
\b단어의 경계. 숫자가 끝나는 자리\d\b는 뒤에 숫자가 더 없는 숫자
( )찾은 부분을 기억해 둔다바꿀 때 \1로 다시 꺼내 쓴다
.와 \.아무 글자 하나 / 글자 그대로의 마침표\d\.\d는 숫자, 마침표, 숫자

모양 검사하기

“숫자 4개, 붙임표, 숫자 2개, 붙임표, 숫자 2개”를 정규표현식으로 적으면 ^\d{4}-\d{2}-\d{2}$다. 모든 값이 이 모양인지 묻는다. TRUE(True) 하나가 나와야 한다.

R
all(str_detect(
  as.character(subway$수송일자),
  "^\\d{4}-\\d{2}-\\d{2}$"))
Python
(subway["수송일자"]
 .astype(str)
 .str.fullmatch(r"\d{4}-\d{2}-\d{2}")
 .all())
두 언어의 차이 R은 문자열 안에서 \를 두 번 써야 한다("\\d"). Python은 따옴표 앞에 r을 붙이면 한 번만 써도 된다(r"\d"). 정규표현식 자체는 같다.

다른 표기를 만났을 때: 모양으로 바꾸기

모든 파일이 표준 표기인 것은 아니다. 같은 자료의 2024년 파일은 날짜가 2024.1.1처럼 마침표로 적혀 있고 한 자리 숫자 앞에 0이 없다. 이런 값을 표준 표기로 고치는 두 단계를 작은 예로 연습한다.

R
x <- c("2024.1.1", "2024.10.5", "2024.12.25")

x |>
  str_replace_all(fixed("."), "-") |>
  str_replace_all("-(\\d)\\b", "-0\\1")
# "2024-01-01" "2024-10-05" "2024-12-25"
Python
x = pd.Series(["2024.1.1", "2024.10.5", "2024.12.25"])

(x.str.replace(".", "-", regex=False)
  .str.replace(r"-(\d)\b", r"-0\1", regex=True))
# 2024-01-01, 2024-10-05, 2024-12-25
  • 첫 줄은 글자 그대로의 마침표를 붙임표로 바꾼다. 정규표현식에서 .는 “아무 글자 하나”라서, 글자 그대로라고 알려준다(R은 fixed(), Python은 regex=False).
  • 둘째 줄의 -(\d)\b는 “붙임표, 숫자 하나(기억해 둠), 숫자가 거기서 끝남”이다. 이것을 -0\1, 곧 “붙임표, 0, 기억해 둔 숫자”로 바꾼다. 두 자리 숫자는 건드리지 않는다.

3.10날짜형으로 바꾸기

표준 모양의 문자열을 날짜형으로 바꾼다. 날짜형이어야 요일을 묻거나 날짜끼리 뺄 수 있다. 이미 날짜형으로 읽힌 R에서도 같은 코드를 실행해 새 열 날짜를 만든다.

R
subway <- subway |>
  mutate(날짜 = as_date(수송일자))

class(subway$날짜)     # "Date"
Python
subway["날짜"] = pd.to_datetime(
    subway["수송일자"], format="%Y-%m-%d")

subway["날짜"].dtype   # datetime64

Python의 format은 문자열이 어떤 모양인지 알려주는 것이다. %Y는 네 자리 연도, %m은 월, %d는 일이다. 마침표 표기였다면 "%Y.%m.%d"라고 적는다.

날짜형이 되면 할 수 있는 일:

R
range(subway$날짜)               # 처음과 끝
max(subway$날짜) - min(subway$날짜)  # 며칠 간격

subway |>
  mutate(요일 = wday(날짜, label = TRUE),
         월 = month(날짜)) |>
  count(요일)
Python
subway["날짜"].min(), subway["날짜"].max()
subway["날짜"].max() - subway["날짜"].min()

(subway["날짜"]
 .dt.day_name()
 .value_counts())
문자열 "2025-01-01"날짜형 2025-01-01
정렬글자 순서시간 순서
요일, 월 뽑기못 한다할 수 있다
날짜끼리 빼기못 한다며칠인지 나온다
그래프의 가로축값마다 눈금 하나시간의 흐름으로 그려진다

3.11시각까지 담기: 날짜시각형

날짜형은 “어느 날”까지만 안다. “어느 날 몇 시”를 담으려면 날짜시각형을 쓴다. 이 데이터에서 시각은 값이 아니라 08-09시간대 같은 열 이름에 들어 있다. 정규표현식으로 시작 시각을 꺼내 날짜와 합친다.

R
시 <- str_extract("08-09시간대", "^\\d{2}")
시                                  # "08"

ymd_h(str_c("2025-01-01", " ", 시))
# "2025-01-01 08:00:00 UTC"
Python
import re
시 = re.match(r"\d{2}", "08-09시간대").group()
시                                  # '08'

pd.to_datetime("2025-01-01 " + 시,
               format="%Y-%m-%d %H")
# Timestamp('2025-01-01 08:00:00')

지금은 값 하나로 연습했다. 표 전체에 적용하려면 시간대가 열 이름이 아니라 값으로 들어 있어야 한다. 그 변환이 과제의 첫 단계다.
