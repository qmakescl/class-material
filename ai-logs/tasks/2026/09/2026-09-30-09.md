## 수행 작업

### 식 표기 전환

- 두 번째 식: `(104² + 97² + 11² + 11² + 6²) / 229 = 20,503 / 229`
  → `(104/229)×104 + (97/229)×97 + (11/229)×11 + (11/229)×11 + (6/229)×6`
- 첫 번째 식(투수 기준)은 `(104 + … + 6) / 5` 그대로 두되, 설명 문단에 "첫 번째 식은
  다섯 명에게 `1/5`씩 똑같이 나눠 주지만, 두 번째 식은 각 투수에게 `(자기 투구수)/229`
  만큼 나눠 준다"는 대비를 넣었다.

### 블록 제목과 도입 교체

- `왜 제곱을 하나` → **`왜 가중치가 104/229인가`**
- 도입문도 "왜 같은 수를 두 번 곱하는지" → "가중치가 왜 104/229인지"로 바꿨다.
- 설명 문단 교체: "104 × 104가 곧 104²" 중심 → "적는 숫자 229개 중 104개가 값 104이므로
  값 104의 몫은 104/229. **가중치가 곧 그 값이 등장하는 비율**이고, 등장 횟수가 값
  자체와 같기 때문에 가중치도 값에 비례한다"로 정리했다.

### 표에 분수 추가

여섯 열 모두 `분수<br>= 결과` 형태로 바꿨다.

| 열 | 이전 | 이후 |
| --- | --- | --- |
| 투수 기준 가중치 | `20.0%` | `1/5` / `= 20.0%` |
| 투구 기준 가중치 | `45.4%` | `104/229` / `= 45.4%` |
| 투수 기준 기여 | `20.80` | `(1/5)×104` / `= 20.80` |
| 투구 기준 기여 | `47.23` | `(104/229)×104` / `= 47.23` |

합계 행도 `5/5 = 100%` · `229/229 = 100%`로 적어 가중치 합이 1임을 보이게 했다.
투구수 열 머리글에 `n`을 덧붙여 본문의 `n/229` 표기와 연결했다.

### 제곱의 위치 이동

- 기본 층 표 아래에 `p.note`를 추가: 투구 기준 기여 `(104/229)×104`를 줄여 쓰면
  `104²/229`이고, **앞의 104는 가중치의 분자, 뒤의 104는 값**이다. 우연히 같은 숫자라서
  제곱처럼 보이는 것이며, 통계지식 층에서는 이 줄여 쓴 형태를 쓴다고 안내했다.
- 통계지식 층의 σ² 유도 도입을 가중평균에서 출발하도록 고쳤다.
  \(\sum_i (n_i/N) \cdot n_i = \sum_i n_i^2 / N = \sum_i n_i^2 / \sum_i n_i\) 식을 새로 넣어,
  가중평균 → 제곱 형태 → \(\mathrm{E}[X^2]/\mathrm{E}[X]\) → \(\mu + \sigma^2/\mu\)로
  단계가 끊기지 않게 했다.
