# AGENTS.md

이 폴더에서 일하는 코딩 에이전트(Antigravity, Claude Code, Codex 등)가 따르는 규칙이다.
학생이 R 코드를 직접 쓸 때도 같은 규칙을 따른다.

## 이 폴더

「숫자로 읽는 세상」 레포트 과제의 작업 폴더다. 2025년 서울 지하철 역별·일별·시간대별 승하차 인원,
서울의 평균기온·최고기온·강수량, 2025년 휴일 자료를 다룬다.
이 파일은 작업 환경과 기록 방식만 정한다. 과제를 어떻게 풀지는 모두 학생이 정한다.
[R과 Python 을 이용해 세상읽기](https://qmakescl.github.io/class-material/data-science/readtheworld/index.html)
에서 다룬 방법을 쓴다. 이 과제에서는 **R만 쓴다.**

## 에이전트의 역할

- **학생이 요청한 작업만 한다.** 요청하지 않은 분석, 다음 단계, 보고서 문장을 먼저 하거나 제안하지 않는다.
- **권고하지 않는다.** 분석 방향, 순서, 기준, 방법, 해석, 결론, 한계에 대해 권하거나 선택지를 늘어놓지 않는다.
  결정은 모두 학생이 한다.
- 무엇을 할지 정해지지 않은 요청(예: "무엇부터 할까?", "다 해 줘")에는 작업하지 않고,
  무엇을 할지 정해 달라고만 답한다. 할 만한 작업의 예도 들지 않는다.
- 요청한 작업에 학생이 정하지 않은 기준이 필요하면, 어떤 기준이 필요한지 이름만 말하고 정해 달라고 묻는다.
  예시 값, 선택지, 각 선택의 영향은 말하지 않는다. 임의로 정하지 않는다.
- 요청받은 작업을 하기 전에 자료를 미리 살펴 특이점을 알려 주지 않는다. 요청받은 작업을 하다가 실행이
  막히면(예: 계산할 수 없는 값) 막힌 사실과 개수만 알리고 어떻게 할지 묻는다.
- 해석, 결론, 한계, 보고서 문장을 써 달라는 요청에는 쓰지 않고, 학생이 직접 쓸 부분이라고만 답한다.
  학생이 자기 원고를 주고 표현 수정을 요청하면 내용과 판단은 바꾸지 않고 표현만 고친다.
  고친 문장은 그 요청의 대화 절 "제안한 보고서 문장"에 전문을 남긴다.

## 가장 먼저: 폴더 이름 확인

작업 폴더의 이름이 아직 `report-sno`이면, 첫 답변에서 학생에게 폴더 이름을 `report-본인의학번`
(예: `report-2026123456`)으로 바꾸라고 알린다. 에디터 창을 닫고 바꾼 뒤 다시 열어야 한다는 것도 알린다.
에이전트가 폴더 이름을 직접 바꾸지는 않는다.

## 대화 기록

**모든 요청에 대해, 답변을 마치기 직전에 `dialogues/`에 기록을 남긴다.**
코드를 만들지 않은 질문, 설명 요청, 실패한 시도도 빼지 않는다. 이 기록은 과제 평가에 쓰인다.

- 파일: `dialogues/YYYY-MM-DD.md` (한국 시간 기준 그날 날짜). 없으면 만들고, 있으면 맨 아래에 이어 쓴다.
  새 파일의 맨 위에는 `# YYYY-MM-DD 대화 기록` 한 줄을 둔다.
- 서식: `dialogues/_template.md`를 그대로 따른다. 한 요청이 한 절(`## NN · HH:MM`)이다.
  `NN`은 그 파일 안의 일련번호로 01부터 시작하며, 파일의 마지막 번호에 1을 더한다.
- **요청**: 학생이 보낸 글을 고치거나 줄이지 않고 그대로 인용(`>`)한다. 붙여 넣은 긴 오류 메시지만 줄여도 된다.
- **응답 요약**: 무엇을 했고 무엇을 답했는지 3~6줄로 적는다.
- **제안한 보고서 문장**: 보고서에 쓸 문구를 제안한 경우에만 이 칸을 두고 전문을 줄이지 않고 적는다.
- **만들거나 바꾼 파일**: 경로와 목적. 없으면 `없음`.
- **실행 결과**: 실제로 실행해서 나온 숫자와 메시지만 적는다. 실행하지 않았으면 `실행하지 않음`.
  숫자를 지어내거나 짐작한 값을 적지 않는다.
- **내가 확인한 것**: 학생이 직접 쓰는 칸이다. 에이전트는 제목만 두고 **비워 둔다.**
- 이전 기록은 고치거나 지우지 않는다. 틀린 것이 있으면 새 절에 정정으로 적는다.
- 학생이 "기록해 줘"라고 하면 빠진 요청을 지금 시각의 새 절로 적고, 응답 요약 첫 줄에 `(나중에 기록함)`을 붙인다.
  요청 원문을 알 수 없으면 요청 칸에 `원문 없음 · 학생 회고`라고 적고 학생이 말해 준 내용을 옮긴다.
- API 키, 비밀번호, 컴퓨터 사용자 이름이 든 절대 경로는 적지 않는다.

## 폴더와 경로

```text
report-본인의학번/   (받았을 때 이름은 report-sno)
├── AGENTS.md        # 이 규칙
├── dialogues/       # 대화 기록 (날짜별 .md)
├── scripts/         # R 스크립트 (.R)
├── dataset/
│   ├── raw/         # 원자료. 읽기만 한다
│   └── working/     # 정리한 분석용 자료
├── output/          # 표(CSV)와 그림(PNG)
└── report/          # 학생이 쓰는 보고서 초안
```

- 작업 폴더는 언제나 이 폴더다. 스크립트 안의 경로는 이 폴더를 기준으로 한 상대 경로로 적는다.
  예: `dataset/raw/seoul-subway-2025.csv`, `output/rain-hourly.png`.
- `setwd()`나 사용자 컴퓨터의 절대 경로(`/Users/...`, `C:\...`)를 쓰지 않는다.
- `dataset/raw/`의 파일은 고치거나 덮어쓰지 않는다. 정리한 결과는 `dataset/working/`에 UTF-8 CSV로 새로 쓴다.
- `output/`에는 그림과 요약표만 둔다. 역별·시간대별 긴 표처럼 큰 중간 자료는 `dataset/working/`에 둔다.
- 제출할 때 작업 폴더를 통째로 압축하며 크기 제한은 100MB다. 같은 큰 표를 이름만 바꿔 여러 번 저장하지 않는다.
- 스크립트는 `scripts/`에 단계 순서가 보이게 번호를 붙여 둔다. 예: `01-read.R`, `02-daily.R`.
  파일 이름은 영문 소문자, 숫자, `-`로 쓴다.

- 지하철과 기상 파일은 학생이 직접 내려받아 넣는다. 파일이 없으면 만들어 내지 말고 `README.md`의 안내를 알려 준다.
- 휴일 파일은 들어 있다. 휴일 목록을 기억으로 만들거나 이 파일에 날짜를 더하지 않는다.
- **가상 데이터를 만들지 않는다.** 예시용 숫자나 임의의 표로 대신하지 않는다.
- 지하철과 기상 파일은 EUC-KR이다. `read_csv(..., locale = locale(encoding = "EUC-KR"))`로 읽고,
  오류가 나면 `"CP949"`로 바꾼다.

## 바깥 숫자

이 폴더의 자료에 없는 숫자를 바깥 숫자라 한다.

- 바깥 숫자는 학생이 출처(URL)와 함께 알려 준 것만 쓰고, 쓸 때 출처를 함께 적는다.
- **에이전트가 기억이나 짐작으로 통계를 내놓지 않는다.** 학생이 알려 주지 않은 바깥 숫자가 필요하면 쓰지 않는다.

## R 규칙

- **tidyverse를 쓴다.** 스크립트 맨 위에서 `library(tidyverse)`로 불러온다.
  - 파일은 readr(`read_csv()`, `write_csv()`)로 읽고 쓴다.
  - 가공은 dplyr·tidyr(`filter()`, `mutate()`, `group_by()`, `summarise()`, `left_join()`, `pivot_longer()`)로 한다.
  - 문자열은 stringr, 날짜는 lubridate를 쓴다.
  - 파이프는 `%>%`를 쓴다. R 기본 파이프 `|>`는 쓰지 않는다.
- 모형 적합(`lm()`, `cor()`, `t.test()` 등)은 R 기본 함수를 그대로 쓴다.
- 표의 숫자가 잘려 보이지 않도록 스크립트 앞부분에 `options(pillar.sigfig = 7)`을 둔다.
- Python, 노트북(.ipynb), Quarto/R Markdown은 쓰지 않는다. `.R` 스크립트만 쓴다.

## 시각화 규칙

- **그림은 ggplot2로만 그린다.** base 그래픽(`plot()`, `hist()`, `barplot()`)과 다른 그래픽 패키지는 쓰지 않는다.
- 그림은 `ggsave()`로 `output/`에 PNG로 저장한다. 크기는 인치로 정한다(예: `width = 7, height = 5`).
- 축 이름과 제목은 한국어로 쓰고 단위를 괄호로 붙인다. 예: `"하루 승차 인원 (명)"`, `"평균기온 (°C)"`.
- 그림 아래 캡션에 자료 출처를 적는다. 예: `"자료: 서울교통공사, 기상청 (2025)"`.

## 한글 글꼴 규칙

- **한글은 showtext로 Google Fonts의 Noto Sans KR을 쓴다.** 스크립트 앞부분에 다음을 둔다.

  ```r
  library(showtext)
  font_add_google("Noto Sans KR", "notosanskr")
  showtext_auto()
  showtext_opts(dpi = 300)
  ```

- ggplot의 테마에는 `base_family = "notosanskr"`를 준다. 예: `theme_minimal(base_family = "notosanskr")`.
- extrafont나 시스템에 설치된 다른 한글 글꼴은 쓰지 않는다. 인터넷이 없어 글꼴을 받지 못하면 그 사실을 알린다.

## 패키지

- 기본 패키지는 tidyverse와 showtext다.
- 설치되어 있지 않거나 다른 패키지가 필요하면 마음대로 설치하지 않는다. 왜 필요한지와 설치 명령을
  알려 주고 동의를 받은 뒤 실행한다.

## 실행과 보고

- 스크립트를 쓰면 이 폴더에서 `Rscript scripts/<파일>.R`로 실제로 실행해 오류가 없는지 확인한다.
- 학생에게는 실행한 명령, 콘솔에 나온 주요 수치, 저장한 파일 경로를 알린다.
- 결과에 해석이나 평가를 덧붙이지 않는다.
- 설명은 한국어로 한다. 통계 용어는 수업 자료의 표기를 따른다(예: 영가설, 대안가설).
