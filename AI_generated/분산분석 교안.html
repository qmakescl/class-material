분산분석(ANOVA) 교안

세 개 이상의 평균을 한 번에 비교할 때, 왜 "평균"이 아니라 "분산"을 나누는지를 일원배치에서 먼저 확인합니다. 같은 논리를 이원배치, 반복측정, 혼합 설계로 넓혀 갑니다. 모든 수치는 R 내장 데이터셋으로 계산했습니다.

PART 1

일원배치 분산분석

t 검정은 두 평균을 비교합니다. 집단이 셋 이상이면 쌍마다 t 검정을 반복하고 싶어지지만, 세 집단이면 3번, 다섯 집단이면 10번의 검정이 필요하고 그만큼 1종 오류가 쌓입니다. α = .05로 독립인 검정 3번을 하면 하나라도 잘못 기각할 확률은 1 − 0.95³ ≈ .143입니다. 분산분석은 "모든 집단 평균이 같다"는 하나의 가설을 F 통계량 하나로 검정합니다.

1.1 예제 데이터와 가설

PlantGrowth는 대조군(ctrl)과 두 처리(trt1, trt2)에서 기른 식물의 건조 중량(weight)을 집단마다 10개씩 기록한 데이터입니다(Dobson, 1983).

H₀ : μ_ctrl = μ_trt1 = μ_trt2 H₁ : 적어도 한 집단의 평균이 다르다 모형 : y_ij = μ + τ_j + ε_ij , ε_ij ~ N(0, σ²) 독립 (j = 1,…,k 집단, i = 1,…,n_j 관측)

모형의 가정은 세 가지입니다. ① 관측의 독립성, ② 각 집단 안의 오차가 정규분포, ③ 모든 집단의 오차 분산 σ²가 같음(등분산성). 독립성은 연구 설계로 확보하고, 정규성과 등분산성은 자료로 점검합니다.

1.2 각 집단의 분산 동질성 검정

F 검정의 분모는 집단 내 분산을 합쳐서(pooled) 하나의 σ² 추정치로 씁니다. 이 합치기가 정당하려면 집단마다 분산이 같아야 합니다. 등분산 검정의 가설은 다음과 같습니다.

H₀ : σ²_ctrl = σ²_trt1 = σ²_trt2 (등분산) H₁ : 적어도 한 집단의 분산이 다르다
  • Levene 검정: 각 관측값이 자기 집단의 중심에서 떨어진 절대편차 |yij − ỹj|를 새 변수로 만들고, 그 편차에 일원배치 분산분석을 적용합니다. 분산이 큰 집단일수록 절대편차의 평균이 큽니다. R의 car::leveneTest()는 기본값으로 중앙값을 중심으로 쓰는 Brown–Forsythe 변형(center = median)을 사용해 정규성 위반에 덜 민감합니다.
  • Bartlett 검정: 집단 분산의 로그를 비교하는 우도비 기반 검정입니다. 정규성이 성립하면 검정력이 높지만, 정규성에서 벗어나면 등분산이어도 쉽게 기각합니다.

두 검정 모두 p > .05이므로 등분산 가정을 유지하고, 합동 분산을 쓰는 고전적 F 검정을 그대로 진행합니다. trt1의 분산(0.630)이 trt2(0.196)의 약 3.2배이지만, 표본이 작을 때 이 정도 차이는 우연으로 충분히 생깁니다. 집단 크기가 같으면 F 검정은 분산 차이에 비교적 강건합니다.

등분산이 기각되면

Welch의 일원배치 분산분석 oneway.test(weight ~ group, var.equal = FALSE)을 쓰고, 사후검정은 Games–Howell 방법(rstatix::games_howell_test())으로 바꿉니다.

1.3 분산을 자유도에 따라 분해하기

분산분석의 핵심은 모든 관측값의 편차를 두 조각으로 쪼개는 항등식입니다. 하나는 "집단이 달라서 생긴 차이", 다른 하나는 "같은 집단 안에서도 생기는 차이"입니다.

(y_ij − ȳ) = (ȳ_j − ȳ) + (y_ij − ȳ_j) 전체 편차 집단 간 편차 집단 내 편차 제곱해서 모두 더하면 교차항이 0이 되어 SST = SSB + SSW 14.258 = 3.766 + 10.492 df : N−1 = (k−1) + (N−k) 29 = 2 + 27

아래 그림에서 단계를 바꿔 가며 확인하세요. 점 하나를 누르면 그 관측값의 편차가 두 조각으로 나뉘는 계산이 나옵니다.

점을 누르면 편차 분해가 여기에 나옵니다.

자유도와 평균제곱, F

제곱합은 더하는 항의 개수가 많을수록 커지므로, 자유도로 나누어 "편차 하나당 평균 크기"인 평균제곱(MS)으로 바꿉니다. 집단 간 자유도가 k − 1인 이유는 k개의 집단 평균이 전체 평균을 중심으로 합이 0이 되도록 묶여 있기 때문이고, 집단 내 자유도가 N − k인 이유는 각 집단에서 평균을 하나씩 추정하느라 자유도를 하나씩 쓰기 때문입니다.

MSB = SSB / (k−1) = 3.766 / 2 = 1.883 MSW = SSW / (N−k) = 10.492 / 27 = 0.389 (= 합동분산 σ̂²) F = MSB / MSW = 4.846 ~ F(2, 27) (H₀ 하에서)

H₀가 참이면 MSB와 MSW는 모두 σ²를 추정하므로 F는 1 근처에 있습니다. 집단 평균이 다르면 MSB에 처리효과 n Σ τj² / (k − 1)가 더해져 F가 커집니다.

1.4 사후 검정 (Post Hoc)

F 검정이 유의하다는 것은 "적어도 하나는 다르다"까지만 말해 줍니다. 어느 쌍이 다른지는 사후 검정으로 확인합니다. 여러 쌍을 동시에 비교하므로 가족단위 오류율(FWER)을 α로 묶어 두는 방법을 씁니다.

  • Tukey HSD: 모든 쌍 비교. 스튜던트화 범위분포 q를 써서 FWER을 정확히 α로 맞춥니다. 등분산·같은 표본 크기에서 표준적인 선택입니다.
  • Bonferroni: 각 비교의 p에 비교 횟수 m을 곱합니다. 단순하지만 보수적입니다.
  • Dunnett: 모든 처리를 대조군 하나와만 비교할 때 사용합니다.

결과 보고 예시

처리에 따라 식물 건조 중량의 평균이 유의하게 달랐다, F(2, 27) = 4.85, p = .016, η² = .26. Tukey HSD 사후검정 결과 trt2(M = 5.53)가 trt1(M = 4.66)보다 유의하게 무거웠고(p = .012), 두 처리와 대조군(M = 5.03) 사이의 차이는 유의하지 않았다.

1.5 전체 과정을 위한 R 코드

코드에서 밑줄이 그어진 함수 이름에 마우스를 올리면(모바일은 탭) 목적, 인수, 반환값이 나옵니다.

oneway_anova.R
options(repos = c(CRAN = "https://cloud.r-project.org/"))
# install.packages(c("tidyverse", "car", "rstatix", "extrafont"))
library(tidyverse)
library(car)
library(rstatix)

dir.create("dataset/raw", recursive = TRUE, showWarnings = FALSE)
dir.create("dataset/working", recursive = TRUE, showWarnings = FALSE)
dir.create("output", showWarnings = FALSE)

# 1) 데이터 준비 ----------------------------------------------------
write_csv(PlantGrowth, "dataset/raw/plantgrowth.csv")
pg <- read_csv("dataset/raw/plantgrowth.csv") %>%
  mutate(group = factor(group, levels = c("ctrl", "trt1", "trt2")))

# 2) 집단별 기술통계 --------------------------------------------------
desc <- pg %>%
  group_by(group) %>%
  summarise(n = n(), mean = mean(weight), sd = sd(weight), var = var(weight))
desc
write_csv(desc, "output/oneway_desc.csv")

# 3) 등분산 검정 -----------------------------------------------------
leveneTest(weight ~ group, data = pg)            # center = median (Brown-Forsythe)
bartlett.test(weight ~ group, data = pg)

# 4) 분산분석 --------------------------------------------------------
fit <- aov(weight ~ group, data = pg)
summary(fit)
shapiro.test(residuals(fit))                       # 잔차 정규성
eta_squared(fit)                                   # rstatix: η²

# 5) 사후 검정 -------------------------------------------------------
TukeyHSD(fit)
pg %>% tukey_hsd(weight ~ group)                   # 같은 결과를 tibble로

# 6) 분산 분해 시각화 -------------------------------------------------
gm <- mean(pg$weight)
pg_plot <- pg %>%
  group_by(group) %>%
  mutate(gmean = mean(weight)) %>%
  ungroup() %>%
  mutate(x = as.numeric(group) + runif(n(), -0.25, 0.25))

p_decomp <- ggplot(pg_plot, aes(x = x, y = weight, colour = group)) +
  geom_hline(yintercept = gm, linetype = "dashed") +                     # 전체 평균
  geom_segment(aes(xend = x, y = gmean, yend = weight), alpha = 0.5) +   # 집단 내 편차
  geom_segment(aes(x = as.numeric(group) - 0.32, xend = as.numeric(group) + 0.32,
                   y = gmean, yend = gmean), linewidth = 1.2) +          # 집단 평균
  geom_segment(aes(x = as.numeric(group) + 0.36, xend = as.numeric(group) + 0.36,
                   y = gm, yend = gmean), linewidth = 1.4,
               arrow = arrow(length = unit(0.15, "cm"))) +              # 집단 간 편차
  geom_point(size = 2.4) +
  scale_x_continuous(breaks = 1:3, labels = levels(pg$group)) +
  labs(x = "집단", y = "건조 중량", title = "SST = SSB + SSW") +
  theme_minimal(base_family = "KoPubDotum Medium")
ggsave("output/oneway_decomposition.png", p_decomp, width = 7, height = 4.5, dpi = 300)

PART 2

이원배치 분산분석

요인이 둘이면 각 요인의 주효과와 함께, 한 요인의 효과가 다른 요인의 수준에 따라 달라지는지(교호작용)를 함께 검정합니다. ToothGrowth는 기니피그 60마리에게 비타민 C를 보충 방법(supp: 오렌지주스 OJ, 아스코르브산 VC) 2가지와 용량(dose: 0.5, 1, 2 mg/day) 3가지로 나누어 준 뒤 상아질 세포 길이(len)를 잰 2 × 3 균형 설계입니다(칸마다 n = 10).

y_ijk = μ + α_i + β_j + (αβ)_ij + ε_ijk α_i : supp 주효과 β_j : dose 주효과 (αβ)_ij : 교호작용 SST = SS_supp + SS_dose + SS_supp×dose + SS_error df : 59 = 1 + 2 + 2 + 54

2.1 분산의 구성 시각화

일원배치에서 SSB 하나였던 "설명된 변동"이 이원배치에서는 세 조각으로 나뉩니다. 균형 설계에서는 이 세 조각이 서로 직교하므로 분해가 유일합니다. 불균형 설계에서는 제곱합의 유형(Type I/II/III)에 따라 값이 달라집니다.

2.2 교호작용

교호작용이 없으면 두 요인의 효과는 더해지기만 합니다(가법 모형). 그러면 용량에 따른 평균 변화선이 보충 방법별로 평행합니다. 아래에서 "가법 모형 예측"을 누르면 교호작용 항을 뺐을 때의 예측값 μ̂ + α̂i + β̂j가 그려집니다. 관측 평균과의 차이가 교호작용 효과 (αβ)ij입니다.

OJ (오렌지주스)VC (아스코르브산)

저용량(0.5, 1)에서는 OJ가 VC보다 5~6 길지만, 2 mg에서는 두 방법의 차이가 사라집니다. 선이 수렴하는 이 모양이 유의한 교호작용(p = .022)의 실체입니다.

교호작용이 유의하면 주효과만으로 결론을 내리면 안 됩니다. "OJ가 VC보다 낫다"는 supp 주효과는 2 mg에서는 성립하지 않기 때문입니다. 대신 한 요인의 수준마다 다른 요인의 효과를 따로 보는 단순 주효과(simple main effect) 분석을 합니다. 오차항은 전체 모형의 MSE(13.19, df = 54)를 그대로 씁니다.

2.3 R 코드

twoway_anova.R
library(tidyverse)
library(car)
library(rstatix)

tg <- ToothGrowth %>%
  mutate(dose = factor(dose), supp = factor(supp, levels = c("OJ", "VC")))

# 칸별 기술통계
tg %>% group_by(supp, dose) %>% summarise(n = n(), mean = mean(len), sd = sd(len))

# 등분산(6개 칸)
leveneTest(len ~ supp * dose, data = tg)

# 이원배치 분산분석 (균형 설계: Type I = II = III)
fit2 <- aov(len ~ supp * dose, data = tg)
summary(fit2)
tg %>% anova_test(len ~ supp * dose)      # 부분 η²(pes)는 effect.size = "pes"

# 교호작용 도표
p_int <- tg %>%
  group_by(supp, dose) %>%
  summarise(m = mean(len), se = sd(len) / sqrt(n()), .groups = "drop") %>%
  ggplot(aes(x = dose, y = m, colour = supp, group = supp)) +
  geom_line(linewidth = 1) +
  geom_point(size = 3) +
  geom_errorbar(aes(ymin = m - se, ymax = m + se), width = 0.08) +
  labs(x = "용량 (mg/day)", y = "평균 len (±SE)", colour = "보충 방법") +
  theme_minimal(base_family = "KoPubDotum Medium")
ggsave("output/twoway_interaction.png", p_int, width = 6.5, height = 4.2, dpi = 300)

# 단순 주효과: 용량별 supp 효과 (전체 모형의 오차항 사용)
model <- lm(len ~ supp * dose, data = tg)
tg %>%
  group_by(dose) %>%
  anova_test(len ~ supp, error = model) %>%
  adjust_pvalue(method = "bonferroni")

PART 3

반복측정 분산분석 (Repeated Measures)

같은 개체를 여러 시점이나 조건에서 반복해서 측정하면 관측이 더 이상 독립이 아닙니다. 대신 개체마다 다른 기본 수준(무거운 병아리는 모든 시점에서 무겁다)을 따로 떼어낼 수 있어서, 오차가 작아지고 검정력이 커집니다.

예제는 ChickWeight에서 21일 동안 12번 모두 측정된 병아리 45마리의 6일, 12일, 18일 체중(g)입니다.

y_it = μ + π_i + τ_t + ε_it π_i : 개체 효과, τ_t : 시점 효과 SST = SS_subject + SS_time + SS_error 505,647 = 126,865 + 310,957 + 67,825 df: 134 = 44 + 2 + 88

3.1 개체 변동을 떼어내면 무엇이 달라지나

같은 자료를 독립 세 집단으로 잘못 분석하면 개체 간 변동 126,865가 오차에 섞여 F(2, 132) = 105.4가 됩니다. 반복측정 분석은 이를 떼어내어 오차가 67,825로 줄고 F(2, 88) = 201.7이 됩니다.

3.2 구형성 가정 (Sphericity)

반복측정 F 검정은 모든 시점 쌍의 차이 점수 분산이 같다는 구형성 가정을 필요로 합니다. 독립 설계의 등분산 가정이 반복측정에서 바뀐 모습입니다. 구형성이 깨지면 F가 실제보다 커져 1종 오류가 늘어납니다.

구형성 : Var(y_t1 − y_t2) 가 모든 시점 쌍 (t1, t2)에서 동일

차이 점수 분산이 670에서 2,805까지 4배 넘게 벌어집니다. 성장하면서 개체 간 격차가 커지는 자료에서 흔한 모습입니다.

3.3 평균 변화 도표로 읽는 유의한 결과

평균은 74.9 → 132.8 → 192.4 g으로 거의 직선으로 늘어납니다. 개체별 궤적을 켜면 대부분의 선이 같은 방향으로 올라가면서 기울기가 제각각임을 볼 수 있습니다. 이 기울기 차이가 구형성 위반의 원인입니다.

1요인과 반복측정 (혼합 설계)

개체 간 요인 하나와 개체 내(반복측정) 요인 하나가 함께 있는 설계입니다. 분할구획(split-plot) 설계라고도 합니다. 여기서는 사료(Diet, 4종, 개체 간)와 일령(Time, 3시점, 개체 내)을 함께 봅니다. 사료별 병아리 수는 16, 10, 10, 9마리로 불균형입니다.

SST = [ SS_Diet + SS_S/Diet ] + [ SS_Time + SS_Diet×Time + SS_Time×S/Diet ] 개체 간 변동 (df 44 = 3 + 41) 개체 내 변동 (df 90 = 2 + 6 + 82) Diet 의 F = MS_Diet / MS_S/Diet (분모 df 41) Time, Diet×Time = MS_effect / MS_Time×S/Diet (분모 df 82)

두 종류의 효과가 서로 다른 오차항으로 검정된다는 점이 핵심입니다. 개체 간 요인은 "같은 사료 안의 개체 차이"와 비교하고, 개체 내 효과는 "개체마다 다른 시간 변화"와 비교합니다.

구형성 가정이 기각되어(W = 0.31, p < .001) 개체 내 효과에 Greenhouse–Geisser 보정을 적용하였다. 사료의 주효과, F(3, 41) = 5.11, p = .004, η²G = .19, 일령의 주효과, F(1.18, 48.6) = 234.96, p < .001, η²G = .68, 사료 × 일령 교호작용, F(3.55, 48.6) = 3.42, p = .019, η²G = .09가 모두 유의하였다. 사료 간 체중 차이는 일령에 따라 달랐으며, 18일에는 Diet 3이 가장 무거웠다.

4.3 R 코드

mixed_anova.R
library(tidyverse)
library(rstatix)

chick <- read_csv("dataset/working/chick_6_12_18.csv") %>%
  mutate(Chick = factor(Chick), Time = factor(Time), Diet = factor(Diet))

# 가정 점검
chick %>% group_by(Time) %>% levene_test(weight ~ Diet)
box_m(chick %>% pivot_wider(names_from = Time, values_from = weight) %>%
        select(`6`, `12`, `18`), chick %>% distinct(Chick, Diet) %>% pull(Diet))

# 혼합 설계 분산분석
res_mix <- anova_test(data = chick, dv = weight, wid = Chick,
                      between = Diet, within = Time)
res_mix
get_anova_table(res_mix, correction = "GG")

# 단순 주효과: 시점별 Diet 효과
chick %>% group_by(Time) %>% anova_test(dv = weight, wid = Chick, between = Diet) %>%
  adjust_pvalue(method = "bonferroni")
chick %>% group_by(Time) %>% emmeans_test(weight ~ Diet, p.adjust.method = "bonferroni")

# 단순 주효과: 사료별 Time 효과
chick %>% group_by(Diet) %>% anova_test(dv = weight, wid = Chick, within = Time) %>%
  get_anova_table(correction = "GG")

# 사료별 평균 변화 도표
p_mix <- chick %>%
  group_by(Diet, Time) %>%
  summarise(m = mean(weight), se = sd(weight) / sqrt(n()), .groups = "drop") %>%
  ggplot(aes(x = Time, y = m, colour = Diet, group = Diet)) +
  geom_line(linewidth = 1) +
  geom_point(size = 2.8) +
  geom_errorbar(aes(ymin = m - se, ymax = m + se), width = 0.08) +
  labs(x = "일령 (일)", y = "평균 체중 (±SE)", colour = "사료") +
  theme_minimal(base_family = "KoPubDotum Medium")
ggsave("output/mixed_profile.png", p_mix, width = 6.5, height = 4.2, dpi = 300)

5. 민감도 분석: 시점을 4·8·12·16일로 바꿔 같은 분석을 반복하고 교호작용의 보정 전·후 p를 비교 표로
