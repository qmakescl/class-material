ggplot 을 이용한 시각화

R의 패키지 ggplot2 가 제공하는 ggplot() 을 이용해 시각화를 진행합시다. 코드 상자 옆에는 같은 일을 코딩 에이전트에게 시키는 프롬프트를 함께 두었으니, 코드 생성의 어려움보다 어떤 구성요소를 지정해서 도표를 그리도록 지시하는지 확인해 봅시다.

ggplot(data, aes(...))데이터 + 매핑
+ geom_*() / stat_*()레이어
+ scale_*()척도
+ coord_*() + facet_*()좌표·분할
+ labs()레이블
+ theme()비데이터 요소
예제 데이터
R 내장 자료 둘. 01절은 cars(자동차 50대의 속도와 제동 거리), 02절부터는 주로 mtcars(1974년 Motor Trend 잡지가 실은 자동차 32종의 무게 wt, 연비 mpg, 실린더 수 cyl, 변속 방식 am)를 씁니다.
기준 버전
ggplot2 4.0(2025년 9월). 이 자료의 R 코드와 그림은 ggplot2 4.0.3, showtext 0.9.8에서 실행해 확인했습니다.
그림
단추로 움직이는 그림(02·05·07~10절)은 배경·격자·축·글꼴을 브라우저에서 흉내 낸 근사치입니다. 01·03·04절의 그림은 R에서 실행해 저장한 실제 출력입니다.
작업환경
R과 VS Code, 코딩 에이전트(Antigravity)를 아직 설치하지 않았다면 VS Code에서 R 실행하기를 먼저 따라 합니다.
코딩 에이전트
R 코드를 직접 치지 않고 프롬프트를 코딩 에이전트에 붙여 넣어도 됩니다. 위젯이 만드는 코드 아래의 프롬프트도 설정을 바꾸면 함께 바뀝니다. 프롬프트로 생성한 코드를 실행해 보고 그림과 맞춰보며, 무엇을 지시할 수 있는지 확인해 봅시다.

코드 한 줄씩 읽기

  
    
    
  1. library(ggplot2): 패키지를 불러옵니다. library(tidyverse)를 실행해도 ggplot2가 함께 불러와집니다.
    2. 
    
  2. ggplot( … ): 그림을 그릴 판을 만듭니다. 인수가 여럿이므로 인수마다 한 줄씩 적었습니다. 여는 괄호부터 닫는 괄호까지만 실행하면 아무것도 없는 회색 판이 나옵니다.
    3. 
    
  3. data = cars: 그릴 데이터를 정합니다.
    4. 
    
  4. mapping = aes( … ): 미적 매핑. 안쪽의 x = speed, y = dist처럼 인수마다 한 줄씩, 어느 열을 어느 위치에 놓을지 연결합니다. 축의 범위와 눈금은 척도가 이 매핑을 보고 정합니다.
    5. 
    
  5. ) +: 닫는 괄호 뒤의 +가 레이어나 설정을 더합니다. 줄 끝에 둡니다. 다음 줄 맨 앞에 두면 R은 앞 줄에서 명령이 끝났다고 보고, 뒤의 + geom_point()를 따로 실행하다 오류를 냅니다.
    6. 
    
  6. geom_point(): 기하 객체. 행 하나를 점 하나로 그립니다. 인수를 주지 않았으므로 점의 색·크기·모양도 기본값(검정, 크기 1.5, 모양 19의 채운 원)입니다. ggplot2 4.0부터 이 값은 테마가 정합니다.
    7.

# 시각화를 위한 규칙

이 폴더에서는 R과 ggplot2로 그림을 그린다.

## 환경
- 시각화는 ggplot2 을 사용하고, 한글 글꼴은 showtext 의 font_add_google() 로 Noto Sans KR 을 등록하고 사용한다. 다른 패키지가 필요하면 먼저 이유를 말하고 내 허락을 받은 뒤 install.packages() 로 설치한다.
- R 스크립트는 scripts/ 폴더에 06_cars.R 처럼 번호를 붙여 만들고, 작업 폴더 맨 위에서 터미널로 Rscript 를 써서 실행한다(Windows PowerShell 에서는 Rscript.exe).
- 여러 스크립트가 함께 불러 쓰는 파일(바탕 그림, 공통 테마)은 프롬프트가 정한 이름 그대로 둔다(예: scripts/07_base_plot.R, scripts/theme_project.R).
- 모든 결과물은 작업 폴더 맨 위의 output/ 폴더에 저장한다. 그림은 ggsave() 로 output/figures/ 폴더에 PNG로 저장한다. 폴더가 없으면 만든다.
- 내 자료의 원본은 dataset/raw/ 에 두고 고치지 않는다. 다듬은 자료는 dataset/working/ 에 저장한다.

## 진행 방식
- 내가 시킨 것만 바꾼다. 시키지 않은 구성요소(테마, 색, 축 범위 등)는 기본값이나 지금 상태 그대로 둔다.
- 스크립트를 고치면 바뀐 줄을 보여 주고, 다시 실행해 그림을 저장한다.
- 새로 쓴 함수마다 그 함수가 그림의 어느 구성요소(data, aes, geom, stat, position, scale, coord, facet, guide, labs, theme)를 바꾸는지 한 줄로 설명한다.
- 확실하지 않은 함수나 인수는 지어내지 말고 확실하지 않다고 말한다.



  
이 규칙은 실습하면서 늘려 갑니다. 09절에서는 프로젝트의 모든 그림이 같은 테마로 나오도록 "그림 모양" 규칙을 덧붙입니다. 파일을 저장했으면 첫 그림부터 시킵니다. 이후 프롬프트는 하나씩, 앞의 결과를 확인한 다음에 보냅니다. 한글 제목은 글꼴 설정(10절)이 필요할 수 있으므로 여기서는 영어로 붙입니다.

  
프롬프트 0을 보내면 에이전트는 아래와 비슷한 파일을 만들어 실행합니다. 규칙(규칙 확인, 폴더 만들기, output/figures/에 저장)이 코드에 어떻게 나타나는지 봐 두면, 뒤의 프롬프트에서 에이전트가 고친 줄을 읽을 때 기준이 됩니다. 세부 모양은 에이전트마다 조금 다릅니다.

aes(): 내 데이터를 미적 속성에 연결하기

  
미적 속성(aesthetics)은 위치(x, y), 색(colour), 채움색(fill), 크기(size), 모양(shape), 투명도(alpha), 선 종류(linetype)처럼 그림에서 눈으로 구별하는 성질입니다. aes()는 데이터의 열을 이 성질에 연결합니다. 같은 colour도 aes() 안에 쓰느냐 밖에 쓰느냐에 따라 뜻이 완전히 달라집니다. 아래 그림은 모두 R(ggplot2 4.0.3)에서 그대로 실행한 결과입니다.


  
aes() 안과 밖

  

    
aes() 안에 쓸 때aes() 밖(geom_*()의 인수)에 쓸 때

    
      
무엇을 주나데이터의 열(변수) 이름고정값 하나. 예: "steelblue", 2, 0.5

      
점마다그 행의 값에 따라 달라짐모두 같음

      
척도와 범례척도가 값을 색·크기로 바꾸고, 범례가 생김척도도 범례도 없음

      
쓰는 곳ggplot(mapping = aes(…)) 또는 geom_*(aes(…))geom_point(colour = "steelblue")

    
  

  

    
    
  

  
반대 실수도 있습니다. 열 이름을 aes() 밖에 쓰면(geom_point(colour = cyl)) R은 데이터 안이 아니라 작업 공간에서 cyl이라는 객체를 찾다가 object 'cyl' not found 오류를 냅니다. 열 이름은 aes() 안에, 고정값은 aes() 밖에 둡니다.


  
변수의 종류가 척도를 정한다

  
같은 열이라도 R이 숫자로 아는지 범주로 아는지에 따라 척도와 범례가 달라집니다. mtcars의 cyl(실린더 수)은 4, 6, 8 세 값뿐인 범주지만 숫자로 저장되어 있어서, 그대로 넣으면 연속형 색 띠가 생기고 5나 7처럼 없는 값까지 눈금에 나옵니다. factor(cyl)로 바꾸면 구별되는 세 색이 됩니다.

colour, fill색 띠(그라데이션)구별되는 색colour는 점·선의 색, fill은 막대·상자의 안쪽 색

shape쓸 수 없음○ (여섯 가지 안팎까지)연속형을 넣으면 "A continuous variable cannot be mapped to the shape aesthetic." 오류

      
linetype쓸 수 없음○선을 그리는 geom에서 쓴다. 연속형은 shape와 같은 오류

      
label글자로 쓸 열geom_text(), geom_label()이 그리는 글자

geom_*(): 그림 요소 더하기

  
geom_*()은 데이터를 무엇으로 그릴지 정합니다. 점, 선, 막대, 상자처럼 그리는 모양마다 함수가 있고, 레이어 하나에 geom 하나가 들어갑니다. +로 더한 레이어는 앞의 레이어 위에 그려집니다. 어떤 geom을 쓸지는 무엇을 보여 주려는지와 변수의 종류로 정합니다. 아래 그림은 모두 R에서 그대로 실행한 결과입니다.

그림 객체: ggplot()의 결과를 변수에 담기

  
지금까지는 ggplot()부터 마지막 geom_*()까지 한 번에 실행해 바로 그림을 보았습니다. 사실 ggplot()은 그림을 그리는 함수가 아니라 그림 객체(ggplot 객체)를 만드는 함수입니다. 데이터, 매핑, 레이어, 테마 설정이 모두 이 객체 하나에 담기고, 그림은 이 객체를 출력할 때 그려집니다. 그래서 결과를 변수에 담아 두면 같은 그림을 다시 그리고, 저장하고, 요소를 더해 다른 그림을 만드는 데 쓸 수 있습니다. 07절부터 나오는 p가 바로 이 변수입니다.

R Markdown/Quarto에서 글자 크기가 이상함청크마다 dpi가 다름청크 옵션 fig.showtext = TRUE
