작업환경 구축

R을 설치하고, uv로 Python 3.12 가상환경을 만들고, VS Code에서 두 언어의 노트북을 실행한다.

이 장을 마치면
  • 자기 컴퓨터(Windows 또는 macOS)에 R을 설치할 수 있다.
  • uv로 Python 3.12 가상환경을 만들 수 있다.
  • VS Code에서 Python 노트북과 R 노트북을 각각 실행할 수 있다.
  • AI 에이전트에게 지킬 규칙을 파일로 알려줄 수 있다.

1.1무엇을 설치하는가

설치할 것은 네 가지다. 아래 순서대로 진행한다.

순서구성 요소역할받는 곳
1RR 코드 실행r-project.org
2Visual Studio Code와 확장노트북(.ipynb)을 열고 실행하는 편집기code.visualstudio.com
3uvPython 3.12와 패키지를 프로젝트 폴더 안에 설치터미널 명령 한 줄
4IRkernelR을 노트북에 연결R 안에서 설치

Python은 따로 내려받지 않는다. uv가 Python 3.12를 대신 받아 준다.

1.2R 설치하기

R은 운영체제에 따라 설치 파일이 다르다. 두 경우 모두 출발점은 같다.

  1. https://r-project.org에 접속해 왼쪽 메뉴의 CRAN(또는 본문의 download R)을 누른다.
  2. 내려받을 서버(미러) 목록이 나온다. 맨 위의 0-Cloud나 Korea 아래의 주소 중 하나를 고른다.
  3. 자기 운영체제에 맞는 링크를 누르고 아래 설명을 따른다.

Windows

  1. Download R for Windows를 누른다.
  2. base를 누른다.
  3. 맨 위의 Download R-4.x.x for Windows를 눌러 .exe 파일을 받는다.
  4. 받은 파일을 실행한다. 설치 언어는 한국어를 고르고, 나머지는 기본값 그대로 다음을 눌러 끝낸다.
  5. 설치 위치(기본값 C:\Program Files\R\R-4.x.x)를 적어 둔다. 1.5에서 쓴다.

macOS

  1. 먼저 자기 Mac의 프로세서 종류를 확인한다. 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여를 열고 아래 표와 맞춰 본다.
  2. Download R for macOS를 누른다.
  3. 표에서 확인한 프로세서 종류에 맞는 .pkg 파일을 받는다.
  4. 받은 파일을 실행하고 기본값 그대로 계속을 눌러 설치한다.
화면에 나오는 것프로세서 종류받을 파일
칩: Apple M1, M2, M3 …Apple silicon이름에 arm64가 있는 .pkg
프로세서: … Intel …Intel이름에 x86_64가 있는 .pkg
잘못 받기 쉬운 곳 macOS에서 프로세서 종류에 맞지 않는 파일을 받으면 설치는 되지만 패키지 설치에서 오류가 난다. 파일 이름의 arm64와 x86_64를 꼭 확인한다.

설치 확인

설치된 R 프로그램을 실행한다(Windows: 시작 메뉴의 R, macOS: 응용 프로그램의 R). 창이 뜨면 아래를 입력해 버전이 출력되는지 본다. 확인한 김에 이 가이드에서 쓸 패키지도 설치한다. 몇 분 걸린다.

R
R.version.string
install.packages(c("tidyverse", "IRkernel"))

1.3VS Code와 확장 설치하기

  1. code.visualstudio.com에서 설치 파일을 받아 설치한다.
  2. VS Code 왼쪽의 확장 탭에서 Python과 Jupyter(둘 다 Microsoft 제공)를 설치한다.
  3. 작업할 폴더 subway-weather를 원하는 위치에 만들고, 파일 → 폴더 열기로 연다.
  4. 메뉴의 터미널 → 새 터미널을 연다. 이후의 터미널 명령은 모두 여기에 입력한다.
폴더 경로 폴더 경로에 한글이나 공백이 없도록 한다. 예: C:\work\subway-weather, ~/work/subway-weather. 사용자 이름이 한글인 Windows에서 특히 문제가 잦다.

1.4uv로 Python 가상환경 만들기

가상환경은 이 프로젝트만 쓰는 Python을 폴더 안에 따로 두는 것이다. 다른 수업이나 프로그램의 Python과 섞이지 않고, 모든 학생이 같은 버전(3.12)을 쓰게 된다.

uv 설치

Windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
macOS
curl -LsSf https://astral.sh/uv/install.sh | sh

설치가 끝나면 터미널을 닫고 새로 연다. uv --version을 입력해 버전이 나오면 된다.

프로젝트 초기화와 가상환경

subway-weather 폴더가 열린 터미널에서 아래 두 줄을 차례로 실행한다. 두 운영체제에서 명령이 같다.

터미널
uv init --python 3.12
uv venv
명령하는 일생기는 것
uv init --python 3.12이 폴더를 Python 3.12 프로젝트로 등록한다pyproject.toml, .python-version, main.py, README.md
uv venv가상환경을 만든다. Python 3.12가 없으면 자동으로 받는다.venv 폴더

패키지 설치

패키지는 pip install이 아니라 uv add로 설치한다. 설치한 목록이 pyproject.toml에 기록되어, 다른 컴퓨터에서도 같은 환경을 다시 만들 수 있다.

터미널
uv add jupyter ipykernel pandas matplotlib

노트북에서 가상환경 고르기

  1. notebooks 폴더를 만들고 그 안에 확인_py.ipynb 파일을 만든다.
  2. 오른쪽 위 커널 선택 → Python 환경에서 .venv가 붙은 Python 3.12를 고른다.
  3. 셀에 import pandas를 입력하고 실행해 오류가 없는지 본다.

1.5R을 노트북에 연결하기

노트북은 원래 Python용 도구다. R을 노트북에서 쓰려면 1.2에서 설치한 IRkernel을 Jupyter에 등록해야 한다. 등록할 때 R이 jupyter 명령을 찾을 수 있어야 하므로, 가상환경을 켠 터미널에서 R을 실행한다. 한 번만 하면 된다.

1단계: 가상환경 켜기

Windows
.venv\Scripts\activate
macOS
source .venv/bin/activate

터미널 줄 맨 앞에 (subway-weather)가 붙으면 켜진 것이다.

2단계: 그 터미널에서 R 실행하기

Windows
& "C:\Program Files\R\R-4.x.x\bin\R.exe"
macOS
R

Windows는 R이 설치된 위치를 직접 적어야 한다. R-4.x.x 자리에 1.2에서 적어 둔 실제 버전 번호를 넣는다.

3단계: 커널 등록하기

R
IRkernel::installspec()   # Jupyter에 R 커널 등록
q()                       # R 종료. 저장 여부를 물으면 n

VS Code를 다시 시작한 뒤, 새 노트북 확인_R.ipynb의 커널 선택 → Jupyter Kernel에 R이 보이면 성공이다.

막힐 때 jupyter를 찾을 수 없다는 오류가 나면 1단계의 가상환경이 켜지지 않은 것이다. Windows에서 activate가 “스크립트를 실행할 수 없다”며 막히면, 터미널 오른쪽 위 + 옆 화살표에서 Command Prompt를 골라 새 터미널을 열고 .venv\Scripts\activate.bat을 실행한 뒤 2단계를 "C:\Program Files\R\R-4.x.x\bin\R.exe"로 실행한다.
초안 메모 1.5의 절차는 Windows와 macOS 실습 컴퓨터에서 직접 따라 해 보고 확정해야 한다. 특히 Windows의 R 경로 입력과 PowerShell 실행 정책이 초보자가 막히기 쉬운 곳이다.

1.6프로젝트 폴더 구조

여기까지 마치면 폴더는 아래와 같다. data와 output 폴더는 직접 만든다. 에이전트도 이 폴더 안만 본다.

subway-weather/ ├─ .venv/ 가상환경. 직접 건드리지 않는다 ├─ pyproject.toml 설치한 Python 패키지 목록 ├─ data/ │ ├─ raw/ 내려받은 원본. 절대 고치지 않는다 │ └─ processed/ 정리한 결과를 저장하는 곳 ├─ notebooks/ 장별 노트북 (R용, Python용 한 쌍씩) ├─ output/ 그림과 표 └─ AGENTS.md 에이전트에게 주는 규칙

노트북은 장마다 두 개씩 만든다. 예: 3_명령_R.ipynb, 3_명령_py.ipynb. 셀 순서를 똑같이 맞춰 두면 VS Code에서 좌우로 띄워 비교하기 좋다.

1.7AI 에이전트와 일하는 규칙

에이전트는 폴더의 파일과 노트북 셀, 터미널 출력을 읽는다. 여러분의 머릿속 계획이나 화면에 떠 있는 그림은 보지 못한다. 그래서 규칙을 글로 적어 둔다.

AGENTS.md
# 이 프로젝트의 규칙
- data/raw 의 파일은 읽기만 한다. 수정하거나 지우지 않는다.
- 정리한 데이터는 data/processed 에, 그림은 output 에 저장한다.
- Python은 uv 가상환경(.venv, Python 3.12)을 쓴다.
  패키지는 uv add 로만 설치하고 pip install 은 쓰지 않는다.
- R은 tidyverse, Python은 pandas와 matplotlib만 쓴다.
- 코드를 고칠 때는 무엇을 왜 바꿨는지 한 줄로 설명한다.
- 데이터를 바꾸는 작업 전후에는 행 수를 출력해서 보여준다.
초안 메모 규칙 파일의 이름과 위치는 에이전트 종류에 따라 다르다(예: AGENTS.md, CLAUDE.md, .github/copilot-instructions.md). 수업에서 쓸 에이전트가 정해지면 이 절의 파일 이름과 화면 설명을 확정한다.

에이전트에게 요청할 때의 세 가지 습관:

  • 데이터를 먼저 보여준다. 앞 다섯 줄과 열 이름을 보여준 뒤에 요청한다.
  • 한 번에 한 단계만 시킨다. “전처리 다 해줘”가 아니라 “사용일자를 날짜형으로 바꿔줘”.
  • 고친 뒤에는 처음부터 다시 실행한다. 커널을 재시작하고 전체 셀을 실행해서 오류 없이 끝나는지 확인한다.
