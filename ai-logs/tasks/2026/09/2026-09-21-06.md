## 사용자 요청

> 자유도가 2, 8, 16, 32 로 변함에 따라 t 분포의 모양이 어떻게 변하는지를 시각화하는 페이지를 만들어줘.
> 배경에는 표준정규분포의 모양을 넣어야 한다.

## AI 응답 요약

표준정규분포를 배경으로 깔고 자유도 2, 8, 16, 32의 t 분포 곡선을 겹쳐 그리는 새 통계 자료 페이지를 만들고 통계 목록에 등록했다.

## 수행 작업

- 사이드 레일 레이아웃의 새 자료 페이지를 작성했다: 왜 t 분포인가(KaTeX 수식), 자유도별 비교 차트(켜고 끄기·차례로 보기), 오른쪽 꼬리 확대 차트, 수치 비교 표.
- 확률밀도함수는 Lanczos 로그감마로, 표의 임계값·꼬리확률은 페이지 안에서 수치적분(Simpson)과 이분법으로 계산한다.
- `docs/assets/materials.js`에 항목을 추가해 통계 목록·홈에 반영되게 했다.

## 변경 파일

## 검증

- 로컬 서버 응답(200), 헤드리스 Chrome DOM 덤프로 KaTeX 오류 0건 확인
- 표 값(봉우리 높이, 임계값 4.303/2.306/2.120/2.037, 꼬리확률 18.9/8.6/6.8/5.9%)을 Python 독립 계산과 대조
- 스크린샷으로 차트 두 개와 표의 렌더링을 육안 확인. 버튼 토글·차례로 보기 동작은 코드 검토만 했고 브라우저에서 조작해 보지는 않았다.
