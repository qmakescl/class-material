데이터 전처리

원본을 점검하고, 하루 단위로 요약하고, 기상 데이터와 조인한다.

이 장을 마치면
  • 원본에 섞여 있는 빈 행과 필요 없는 열을 찾아 정리할 수 있다.
  • 역·시간대 단위의 표를 하루 단위로 요약할 수 있다.
  • 두 표를 날짜로 조인하고, 조인이 제대로 됐는지 확인할 수 있다.

전처리는 “분석할 수 있는 모양으로 데이터를 고치는 일”이다. 목표는 하루가 한 행이고, 그날의 지하철 승차 인원과 날씨가 나란히 들어 있는 표 하나다. 새 노트북에서 처음부터 다시 시작한다.

4.1읽고 점검하기

R
library(tidyverse)

subway <- read_csv(
  "../dataset/raw/seoul-subway-2025.csv",
  locale = locale(encoding = "EUC-KR"))

nrow(subway)
sum(is.na(subway$수송일자))   # 날짜가 빈 행
Python
import pandas as pd

subway = pd.read_csv(
    "../dataset/raw/seoul-subway-2025.csv",
    encoding="euc-kr", low_memory=False)

len(subway)
subway["수송일자"].isna().sum()   # 날짜가 빈 행

2장에서 본 대로 199,424행 가운데 134행은 날짜가 비어 있다. 표 아래에 쉼표만 있는 빈 행이 딸려 온 것으로, 엑셀에서 저장한 파일에서 흔하다. 빈 행을 지우고 3장의 정리를 다시 한다.

R
subway <- subway |>
  filter(!is.na(수송일자)) |>
  select(-연번) |>
  rename(역 = 역명, 구분 = 승하차구분)

nrow(subway)
count(subway, 구분)   # 승차와 하차가 같은 수인가
Python
subway = (subway
          .dropna(how="all")
          .drop(columns="연번")
          .rename(columns={"역명": "역",
                           "승하차구분": "구분"}))

len(subway)
subway["구분"].value_counts()   # 승차와 하차가 같은 수인가

남은 행은 199,290이고, 승차와 하차가 99,645행씩이어야 한다.

4.2날짜형으로 바꾸기

3장에서 한 대로 수송일자를 날짜형 열 날짜로 만든다. 바꾸지 못한 값이 있는지도 센다.

R
subway <- subway |>
  mutate(날짜 = as_date(수송일자))

sum(is.na(subway$날짜))   # 0이어야 한다
range(subway$날짜)
Python
subway["날짜"] = pd.to_datetime(
    subway["수송일자"], format="%Y-%m-%d")

subway["날짜"].isna().sum()   # 0이어야 한다
subway["날짜"].min(), subway["날짜"].max()

기간이 2025-01-01부터 2025-12-31까지로 나오는지 확인한다.

4.3하루 단위로 요약하기

날씨는 하루에 값이 하나다. 지하철 데이터도 하루에 한 행이 되도록 줄인다. 먼저 시간대 20개 열을 더해 하루를 만들고, 승차 행만 골라 날짜별로 더한다.

R
subway <- subway |>
  mutate(하루 = rowSums(
    across(`06시이전`:`24시이후`)))

daily <- subway |>
  filter(구분 == "승차") |>
  group_by(날짜) |>
  summarise(승차 = sum(하루))

nrow(daily)   # 365
Python
subway["하루"] = (
    subway.loc[:, "06시이전":"24시이후"]
    .sum(axis=1))

daily = (subway
         .query('구분 == "승차"')
         .groupby("날짜", as_index=False)["하루"]
         .sum()
         .rename(columns={"하루": "승차"}))

len(daily)   # 365
왜 승차만 세는가 한 사람이 한 번 이동하면 승차 한 번, 하차 한 번이 기록된다. 둘을 더하면 같은 이동을 두 번 세게 된다. “그날 지하철을 탄 횟수”는 승차만으로 충분하다.

4.4날짜에서 새 변수 만들기

지하철 이용은 평일과 주말이 크게 다르다. 요일과 주말 여부를 만들어 둔다. 6장에서 결정적인 역할을 한다.

R
daily <- daily |>
  mutate(
    요일 = wday(날짜, label = TRUE),
    주말 = wday(날짜) %in% c(1, 7)
  )
# wday(): 1 = 일요일, 7 = 토요일
Python
daily["요일"] = daily["날짜"].dt.day_name()
daily["주말"] = daily["날짜"].dt.dayofweek >= 5
# dayofweek: 0 = 월요일, 6 = 일요일
공휴일은 평일로 남겨 둔다 2025년 1월 1일은 수요일이지만 쉬는 날이다. 위 코드는 이날을 평일로 분류한다. 설·추석 연휴도 마찬가지다. 본문에서는 공휴일을 따로 처리하지 않고 요일만으로 평일과 주말을 나눈다. 공휴일을 반영하면 결과가 얼마나 달라지는지는 과제에서 직접 확인한다.

4.5기상 데이터 정리하기

기상 파일도 같은 순서로 다룬다. 읽고, 필요한 열만 남기고, 이름을 바꾸고, 날짜형으로 고친다.

R
weather <- read_csv(
  "../dataset/raw/seoul-temp-raining-2025.csv",
  locale = locale(encoding = "EUC-KR")
) |>
  select(날짜 = 일시,
         기온 = `평균기온(°C)`,
         강수량 = `일강수량(mm)`) |>
  mutate(날짜 = as_date(날짜))

nrow(weather)   # 365
Python
weather = pd.read_csv(
    "../dataset/raw/seoul-temp-raining-2025.csv",
    encoding="euc-kr")

weather = weather.rename(columns={
    "일시": "날짜",
    "평균기온(°C)": "기온",
    "일강수량(mm)": "강수량",
})[["날짜", "기온", "강수량"]]
weather["날짜"] = pd.to_datetime(weather["날짜"])

len(weather)   # 365
열 이름의 ° 기호 평균기온(°C)의 °는 키보드에 없는 글자다. 직접 치지 말고 이 가이드의 코드에서 복사하거나, 파일을 먼저 읽어 출력된 열 이름에서 복사한다.

비어 있는 강수량은 무엇인가

강수량 열에는 빈칸(결측)이 많다. 먼저 몇 개인지 센다.

R
weather |>
  summarise(결측 = sum(is.na(강수량)))
Python
weather["강수량"].isna().sum()

365일 가운데 205일이 빈칸이다. 그런데 빈칸과 별개로 0이 적힌 날도 43일 있다. 빈칸과 0이 따로 있다는 것부터가 둘의 뜻이 다르다는 단서다.

빈칸을 어떻게 할지는 코드가 아니라 데이터 설명서가 정한다. “측정하지 못했다”는 뜻이면 그대로 두어야 하고, “비가 오지 않았다”는 뜻이면 0으로 채워도 된다. 설명서와 실제 날씨를 확인한 뒤에 아래를 실행한다.

R
weather <- weather |>
  mutate(강수량 = replace_na(강수량, 0),
         비 = 강수량 > 0)
Python
weather["강수량"] = weather["강수량"].fillna(0)
weather["비"] = weather["강수량"] > 0

4.6두 표 합치기

daily의 각 날짜에 그날의 날씨를 붙인다. 왼쪽 표를 기준으로 붙이므로 왼쪽 조인이다. 두 표의 날짜가 둘 다 날짜형이어야 짝이 맞는다. 한쪽이 문자열이면 하나도 붙지 않는다.

R
nrow(daily)                       # 조인 전

daily <- daily |>
  left_join(weather, by = "날짜")

nrow(daily)                       # 조인 후
sum(is.na(daily$기온))            # 못 붙은 날
Python
len(daily)                        # 조인 전

daily = daily.merge(
    weather, on="날짜", how="left")

len(daily)                        # 조인 후
daily["기온"].isna().sum()        # 못 붙은 날

조인 전후 모두 365행이고, 못 붙은 날은 0이어야 한다.

조인 뒤 반드시 확인할 두 가지 첫째, 행 수가 조인 전과 같은가. 늘었다면 오른쪽 표에 같은 날짜가 두 번 들어 있다. 둘째, 날씨가 비어 있는 날이 없는가. 있다면 두 표의 기간이나 날짜 자료형이 다르다.

4.7정리한 데이터 저장하기

하루 단위 표와 함께, 정리된 원래 표도 저장해 둔다. 뒤의 것은 과제에서 쓴다. 우리가 만드는 파일은 UTF-8로 저장한다. R의 write_csv()는 항상 UTF-8로 쓴다. Python의 utf-8-sig는 엑셀에서 열어도 한글이 깨지지 않게 표시를 붙인 UTF-8이다.

R
write_csv(daily,
          "../dataset/working/daily.csv")

subway |>
  select(-수송일자, -하루) |>
  write_csv("../dataset/working/subway_clean.csv")
Python
daily.to_csv(
    "../dataset/working/daily.csv",
    index=False, encoding="utf-8-sig")

(subway
 .drop(columns=["수송일자", "하루"])
 .to_csv("../dataset/working/subway_clean.csv",
         index=False, encoding="utf-8-sig"))

이제 5장과 6장은 daily.csv 하나만 읽으면 된다. 원본은 dataset/raw에 그대로 남아 있으므로, 전처리를 잘못했더라도 이 노트북을 처음부터 다시 실행하면 된다.
