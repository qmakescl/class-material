## AI 응답 요약

저장소에는 없어 기상청 공개 데이터로 새로 준비하기로 하고, NASA GISTEMP 공개 월별 편차표에서 연평균(J-D)을 뽑아 회귀분석 실습용 xlsx를 만들어 `docs/downlodable/`에 추가했다.

## 수행 작업

- `datasets/temperature/GLB.Ts+dSST.csv`에 NASA GISTEMP(GISS Surface Temperature Analysis v4) 원본 월별 편차표를 내려받았다.
- `src/python/build_temperature_dataset.py`를 작성해 연도·J-D(연평균) 값만 추출하고, 아직 연간 집계가 끝나지 않은 최신 연도는 제외하도록 했다. 산점도+추세선 차트와 출처를 적은 "설명" 시트를 포함해 `docs/downlodable/연간평균기온-실습데이터.xlsx`를 생성했다.
- `README.md`에 데이터셋 설명과 재생성 방법을 추가했다.

## 변경 파일

- `src/python/build_temperature_dataset.py`: 데이터 생성 스크립트
- `datasets/temperature/GLB.Ts+dSST.csv`: 원본 데이터
- `docs/downlodable/연간평균기온-실습데이터.xlsx`: 생성된 실습 파일
- `README.md`: 안내 추가

## 검증

- `uv run python -m compileall -q src/python/build_temperature_dataset.py` 성공
- 스크립트 실행으로 xlsx 생성 성공(146개 연도)
- `openpyxl`로 재열람해 헤더·연도 범위·값이 원본 CSV와 일치함을 확인
