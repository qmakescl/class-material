> **이 숫자는 어떤 과정을 거쳐 내 앞에 왔는가?**

- **주제 1**은 *누구를 골랐는지*를 놓친다. 극단적인 값을 보여준 대상을
  골라내면, 그 극단성의 일부는 우연이었으므로 다음 측정에서 사라진다.
- **주제 2**는 *어떻게 뽑혔는지*를 놓친다. 표본에 들어올 확률이 개체마다

맞다. 틀리는 것은 숫자에서 결론으로 넘어가는 한 걸음이다.

### 2. 공통 준비 — 세 가지 기본 도구

이후 모든 설명이 이 세 도구 위에서 진행된다.

#### 2.1 관측값의 분해

하나의 관측값은 **변하지 않는 실력**과 **그때그때의 우연**으로 나뉜다.

```
X   =   θ   +   e
관측값   실력      우연(오차),  E[e] = 0
```

둘이 독립이면 분산이 그대로 더해진다.

```
Var(X) = Var(θ) + Var(e)
관측 산포 =  실력 산포  +  우연 산포
```

여기서 **신뢰도**(reliability)를 정의한다.

```
         Var(θ)        실력 산포
  ρ  =  ─────────  =  ──────────      (0 ≤ ρ ≤ 1)
         Var(X)        관측 산포
```

ρ는 "관측된 차이 중 실력이 설명하는 몫"이다. ρ = 1이면 관측값이 곧 실력,
ρ = 0이면 관측된 차이가 전부 우연이다.

> **실무 요령:** Var(θ)를 직접 볼 수는 없지만, Var(X)는 데이터에서 계산할 수
> 있고 Var(e)는 이론적으로 알 수 있다(다음 항). 따라서
> **Var(θ) ≈ Var(X) − Var(e)** 로 빼서 추정한다. 이 한 줄이 주제 1의 핵심
> 계산이다.

#### 2.2 비율의 표집오차

성공/실패를 n번 관측해 비율 p̂를 구하면

```
              p(1 − p)                    √(p(1 − p))
  Var(p̂) =  ──────────  ,     SE(p̂) =  ─────────────
                 n                            √n
```

야구 타율로 바꿔 보면 감이 잡힌다. 참 실력이 .270인 타자를 45타수만 보면

```
  SE = √(0.270 × 0.730 / 45) = 0.066
```

**표준오차가 66포인트다.** 실력이 똑같은 타자 둘을 45타수씩 관측하면 한 명은
.200, 다른 한 명은 .340이 나오는 일이 흔하다는 뜻이다. 45타수 타율은 실력의
측정치라기보다 거의 난수에 가깝다.

#### 2.3 비율은 가중평균이다

집단을 여러 층으로 나눌 수 있을 때, 전체 비율은 층별 비율의 **가중평균**이다.

```
                            n_i
  p_전체 = Σ w_i · p_i ,   w_i = ───   (Σ w_i = 1)
             i                    N
```

가중치 w_i가 비교 대상 사이에서 다르면, 층별 p_i의 대소가 전체 p의 대소를
보장하지 않는다. 주제 3 전체가 이 한 줄의 따름정리다.

### 3. 주제 1 — 대조군 없는 전후 비교는 못 믿는다

#### 3.1 현상: 평균으로의 회귀

**정의.** 어떤 변수에서 극단적인 값을 보인 대상을 골라 다시 측정하면, 두 번째
값은 평균 쪽으로 이동하는 경향이 있다.

이 현상은 갈턴(Francis Galton, 1886)이 부모와 자녀의 키를 비교하며 발견했다.
키 큰 부모의 자녀는 부모보다 작고, 키 작은 부모의 자녀는 부모보다 크다.
갈턴은 이것을 "평범함으로의 회귀(regression towards mediocrity)"라 불렀고,
여기서 오늘날의 **회귀분석**이라는 이름이 나왔다.

**수식.** 두 측정값을 각각 표준화(평균 0, 표준편차 1)하고 상관계수를 r이라 하면

```
  E[ Z_2 | Z_1 = z ] = r · z
```

r < 1이면 항상 |r·z| < |z|다. 즉 **상관이 완전하지 않은 한, 회귀는 예외가
아니라 규칙이다.** r = 0.5인 지표에서 상위 2 표준편차를 뽑으면 다음 측정의
기대값은 1 표준편차다. 아무 개입 없이도 절반이 사라진다.

#### 3.2 왜 착각이 생기는가 — 선택이 잡음을 증폭한다

2.1의 분해를 쓰면 기제가 한눈에 보인다. 관측값이 큰 대상을 고르면

```
  X 큰 대상  =  θ가 큰 대상  +  e가 큰 대상
                (다음에도 유지)   (다음에는 사라진다)
```

선발 집단에는 두 종류가 섞여 있다. 실력이 좋은 쪽은 다음에도 좋지만, 운이
좋았던 쪽은 다음에 평균으로 돌아간다. **집단 평균은 반드시 내려간다.** 하위
집단은 대칭적으로 반드시 올라간다.

여기에 개입을 얹으면 세 가지 설명이 구분되지 않는다.

| 관측된 개선 | 가능한 원인 |
|---|---|
| 하위 집단의 점수가 올랐다 | ① 개입이 효과가 있었다 |
| | ② 평균으로의 회귀 |
| | ③ 자연 경과·성숙·계절성 |

**대조군 없는 전후 비교는 ①②③을 분리할 수 없다.** 무작위로 배정된 대조군을
두면 ②와 ③이 두 군에 똑같이 작용하므로, 두 군의 차이가 ①만 남긴다. 이것이
무작위 대조시험이 필요한 근본적인 이유다.

> **고전적 사례.** 이스라엘 공군 교관들은 "잘한 조종사를 칭찬하면 다음에
> 나빠지고, 못한 조종사를 질책하면 다음에 좋아진다"는 경험에서 질책이
> 효과적이라고 결론지었다. 카너먼은 이것이 순수한 회귀 현상임을 지적했다.
> 극단값을 기준으로 개입을 배정하는 순간, 회귀는 개입 효과로 위장한다.

#### 3.3 실측 근거 — 2025 KBO 타율

전반기 150타수 이상, 후반기 100타수 이상인 타자 65명이다. 리그 평균 타율은
.262다.

| 집단 | 전반기 | 후반기 | 변화 |
|---|---|---|---|
| 전반기 **상위** 10명 | .327 | **.280** | −.047 |
| 전반기 **하위** 10명 | .226 | **.283** | +.057 |

양쪽이 모두 리그 평균 .262 쪽으로 끌려왔다. 개별 선수로 보면 더 극적이다.

| 선수 | 전반기 | 후반기 | 변화 |
|---|---|---|---|
| 전민재 | .323 | .213 | −.110 |
| 박민우 | .328 | .260 | −.068 |
| 구본혁 | .238 | .355 | +.117 |
| 김태연 | .223 | .312 | +.090 |

가장 중요한 두 수치는 개별 성적이 아니라 상관계수다.

```
  corr(전반기 타율, 후반기 타율)      = +0.109
  corr(전반기 타율, 전·후반기 변화량) = −0.530
```

- **+0.109**: 같은 선수, 같은 시즌인데도 전반기 타율은 후반기 타율을 거의
  예측하지 못한다.
- **−0.530**: 전반기에 잘한 만큼 떨어지고, 못한 만큼 올라간다. **이 상관이
  음수라는 것이 회귀 현상의 진단 신호다.**

만약 전반기 하위 10명에게 "타격폼 교정 프로그램"을 시행했다면 10명 전원이
개선되었을 것이고, 프로그램은 성공으로 보고되었을 것이다.

#### 3.4 정량적 처방 — 스테인의 역설

회귀 현상을 **문제**로만 보면 "조심하자"에서 끝난다. 그런데 회귀는 예측
가능한 크기를 가지므로, **처방**으로 바꿀 수 있다.

**최적 예측.** 2.1의 분해 아래에서 다음 값을 가장 정확하게 예측하는 규칙은

```
  θ̂ = ρ · X  +  (1 − ρ) · μ
```

관측값 X와 전체 평균 μ를 신뢰도 ρ로 가중평균하는 것이다. 이것은 정규-정규
모형이나 베타-이항 모형의 **베이즈 사후평균**과 같고, 축소추정(shrinkage
estimation)이라 부른다.

- ρ가 작다(정보가 적다) → 전체 평균 쪽으로 많이 끌어당긴다
- ρ가 크다(정보가 많다) → 관측값을 거의 그대로 쓴다

**James–Stein 추정량**은 ρ를 데이터에서 직접 추정한다. k개 대상의 표준화된
관측값 y_i에 대해

```
                 k − 3
  ρ̂ = 1 −  ─────────────── ,     θ̂_i = ȳ + ρ̂ (y_i − ȳ)
             Σ(y_i − ȳ)²
```

1961년 James와 Stein은 k ≥ 4일 때 이 추정량이 **모든 경우에** 개별 관측값보다
총평균제곱오차가 작다는 것을 증명했다. 개별 추정값이 각각 불편추정량인데도
전체적으로 지는 것이다. 이것이 **스테인의 역설**이다.

**왜 이기는가 — 편향·분산 절충.**

```
  MSE = 편향² + 분산
```

관측값 X는 편향이 0이지만 분산이 크다. 평균 쪽으로 끌어당기면 편향이 조금
생기지만 분산이 크게 줄어든다. ρ가 작을 때는 후자의 이득이 압도한다.

> **주의:** 이것은 **집단 전체의 총오차**에 대한 보장이다. 특정 한 명만 보면
> 축소추정이 더 나쁠 수도 있다. "실력이 정말 좋은 선수의 값을 깎아 손해를
> 본다"는 반론은 맞지만, 그 손해보다 다수의 우연을 걷어내는 이득이 크다.

**실측 재현.** Efron과 Morris(1977)는 이 추정량을 야구 타율로 설명했다. 그
설계(시즌 초 45타수로 이후 전체를 예측)를 2025 KBO에 그대로 적용했다.

먼저 2.1의 분산 분해다.

```
  관측 타율 sd  0.0656
  표집오차 sd   0.0654   ← SE = √(p(1−p)/45)
  ───────────────────
  실력 sd 추정  0.0050
```

**첫 45타수에서 선수 간 타율 차이는 사실상 전부 우연이다.** 신뢰도는
ρ ≈ (0.0050 / 0.0656)² ≈ 0.006이다.

관측 타수를 늘려 가면 신뢰도가 자라난다.

| 관측 타수 | 관측 sd | 표집오차 sd | 실력 sd 추정 | 신뢰도 ρ | James–Stein ρ̂ |
|---|---|---|---|---|---|
| 45타수 | 0.0656 | 0.0654 | 0.0050 | 0.006 | 0.031 |
| 100타수 | 0.0451 | 0.0442 | 0.0091 | 0.041 | 0.068 |
| 200타수 | 0.0376 | 0.0313 | 0.0208 | 0.306 | 0.329 |

두 방식으로 독립적으로 구한 축소량이 200타수에서 0.306과 0.329로 거의 일치
한다. **정보가 쌓이면 축소량이 자동으로 줄어든다.**

예측 성능(예측오차 총합 SSE, 작을수록 좋다):

| 관측 타수 | ① 관측 타율 그대로 | ② 전원 리그평균 | ③ James–Stein |
|---|---|---|---|
| 45타수 (117명) | 0.6495 (1.00배) | 0.1601 (**4.06배**) | 0.1567 (**4.14배**) |
| 100타수 (99명) | 0.3289 (1.00배) | 0.1276 (2.58배) | 0.1287 (2.55배) |
| 200타수 (68명) | 0.1983 (1.00배) | 0.1170 (1.70배) | 0.1239 (1.60배) |

**"각 타자의 실제 타율"보다 "전원을 리그 평균으로 예측"하는 쪽이 4배
정확하다.** 개별 정보를 버리는 것이 이긴다.

| 선수 | 첫 45타수 | JS 추정 | 이후 타수 | 실제 이후 타율 |
|---|---|---|---|---|
| 강민호 | **.400** | .271 | 367 | **.253** |
| 김지찬 | **.400** | .271 | 272 | **.261** |
| 손아섭 | **.400** | .271 | 327 | **.272** |
| 플로리얼 | **.133** | .263 | 213 | **.300** |
| 노시환 | **.156** | .264 | 494 | **.269** |

> **정직한 단서:** "정답"으로 쓴 이후 타율에도 표집오차가 있다. 이 때문에 모든
> SSE에 공통 하한이 깔려 있어 위의 개선 배수는 **과소평가**된 값이다(부풀려진
> 방향이 아니다).

### 4. 주제 2 — 표본이 어떻게 뽑혔는지 보라

같은 모집단인데도 답이 달라지는 두 가지 서로 다른 고장을 구분한다.

| 고장 | 기제 | 대표 이름 |
|---|---|---|
| (a) **크기 편향 표집** | 표본에 들어올 확률이 값의 크기에 비례 | 검사 역설, 길이 편향 |
| (b) **범위 제한·선택** | 특정 조건을 통과한 개체만 표본에 들어옴 | 범위 제한, 생존 편향, 버크슨 |

#### 4.1 크기 편향 표집 (검사 역설)

**정의.** 개체가 표본에 뽑힐 확률이 그 개체의 값 X에 비례할 때, 관측된 평균은
참 평균보다 크다.

**수식.** P(선택) ∝ X 인 표집에서 관측값의 기대값은

```
              E[X²]        σ²
  E_size[X] = ──────  =  μ + ───
               E[X]           μ
```

**편향량이 정확히 σ²/μ다.** 분산이 클수록 심해지고, 모든 값이 같으면(σ² = 0)
편향이 사라진다.

**최소 예시.** 강의 세 개에 수강생이 10명, 10명, 100명이라 하자.

```
  강의 기준 평균 = (10 + 10 + 100) / 3 = 40명
  학생 기준 평균 = (10×10 + 10×10 + 100×100) / 120 = 10200/120 = 85명
```

학교는 "평균 수강인원 40명"이라 발표하고, 학생은 "평균 85명"이라 체감한다.
**둘 다 맞다.** 관측 단위가 강의인지 학생인지가 다르기 때문이다. 큰 강의는
학생 명단에 100번 등장하고, 작은 강의는 10번만 등장한다.

**실측 근거.** 2025 KBO 타석 56,139개, 투구 217,970개다.

| 질문 | 평균 투구수 |
|---|---|
| (A) **타석**을 무작위로 뽑을 때, 그 타석의 투구수 | **3.883** |
| (B) **투구**를 무작위로 뽑을 때, 그 투구가 속한 타석의 투구수 | **4.811** |

공식과 정확히 맞는다(타석 투구수의 분산 σ² = 3.606).

```
  μ + σ²/μ = 3.883 + 3.606/3.883 = 3.883 + 0.929 = 4.811  ✓
```

중계를 아무 때나 켜면 평균보다 24% 긴 타석을 보게 된다. 긴 타석이 시간을 더
많이 차지하므로 "무작위 시점"에 걸릴 확률이 높다.

**같은 구조의 다른 사례**

| 사례 | 편향 방향 |
|---|---|
| 버스 대기시간 | 간격이 긴 구간에 도착할 확률이 높다 → 체감 대기가 길다 |
| 친구 수 (친구 역설) | 친구 많은 사람이 더 많은 명단에 등장 → 내 친구들의 친구 수 > 내 친구 수 |
| 가구당 자녀 수 | 자녀에게 물으면 형제가 많은 가구가 과대표집 |
| 입원 기간 | 어느 날 병동을 조사하면 장기 입원 환자가 과대표집 |
| 웹사이트 체류시간 | 오래 머무는 세션이 로그에 더 많이 남는다 |

**교정.** 크기 편향을 알면 되돌릴 수 있다. 관측값에 1/X 가중치를 주면
(역가중) 참 분포의 추정치를 얻는다.

#### 4.2 범위 제한 (상관의 변화)

**정의.** 특정 조건을 통과한 개체만으로 이루어진 집단에서 계산한 상관계수는
모집단의 상관계수와 다르다.

**직관.** 산점도에서 한 축의 흩어짐을 잘라내면 남은 부분에서는 관계가 덜
선명해진다. 선발 변수의 표준편차가 S에서 s로 줄었을 때, 제한된 집단의 상관
r_s는 근사적으로

```
                    r · (s/S)
  r_s  ≈  ───────────────────────────────
            √( 1 − r² + r² (s/S)² )
```

s/S가 작아질수록 r_s는 0으로 끌려간다. 이것을 **상관의 감쇠**(attenuation)라
부른다.

**실측 근거.** 타석 수 기준을 올려 가며 정확도(타율)와 파워(ISO)의 상관을
계산했다.

| 대상 | 인원 | corr(타율, ISO) |
|---|---|---|
| 전체 타자 | 296 | **+0.483** |
| 100타석 이상 | 155 | +0.329 |
| 200타석 이상 | 112 | +0.219 |
| 350타석 이상 | 70 | +0.126 |
| 450타석 이상 (핵심 주전) | 42 | **+0.087** |

전체 선수에서는 "잘 치는 타자가 장타도 많다"는 뚜렷한 관계가, 주전급만 보면
거의 사라진다.

**왜 그런가 — 이것은 단순 절단이 아니다.** 타석 수는 타율이나 ISO를 직접
자른 것이 아니다. 타석 수는 **타율과 파워 양쪽의 결과**다. 감독은 둘 중
하나라도 좋으면 계속 출장시킨다.

```
        타율  ──┐
                ├──▶  타석 수(출장 기회)      ← 이 변수로 표본을 잘랐다
        파워  ──┘
```

두 원인이 모여 하나의 결과를 만드는 지점을 **충돌부**(collider)라 하고, 충돌부
값을 고정하면 원인들 사이에 없던 상관(여기서는 음의 방향 편향)이 생긴다.
이것이 **버크슨의 역설**과 같은 구조다.

> **같은 구조의 고전 사례:** 하버드 입학생만 보면 SAT 점수와 운동 능력이 음의
> 상관을 보인다. 둘 중 하나만 뛰어나도 합격하므로, 합격자 집단은 "공부만 잘
> 하는 사람"과 "운동만 잘하는 사람"으로 채워지고 둘 다 뛰어난 사람은 드물다.
> "잘생긴 남자는 성격이 나쁘다"는 통념도 같은 구조다.

**반례도 함께 알아야 한다.** 제한이 항상 상관을 약화시키지는 않는다.

| 대상 | corr(직구 구속, 삼진율) |
|---|---|
| 전체 투수 (250명) | +0.470 |
| 600구 이상 (130명) | **+0.575** |

여기서는 제한이 상관을 **강화**했다. 무엇을 기준으로 잘랐는지, 그 기준이
두 변수와 어떤 인과 관계인지에 따라 방향이 달라진다. **"표본을 자르면 상관이
약해진다"는 규칙으로 암기하면 틀린다.**

### 5. 주제 3 — 층화하지 않으면 속는다

#### 5.1 수학적 뿌리

2.3을 다시 쓴다. 전체 비율은 층별 비율의 가중평균이다.

```
  p_전체 = Σ w_i · p_i
```

비교하는 두 집단 A, B의 가중치가 다르면(w_i^A ≠ w_i^B), 모든 층에서
p_i^A < p_i^B 여도 p_전체^A > p_전체^B 가 될 수 있다. **모순이 아니다.**
가중평균은 그런 연산이다.

**손으로 검증하는 최소 예시.**

| | 층 1 | 층 2 | **전체** |
|---|---|---|---|
| A | 63/90 = **.700** | 4/10 = **.400** | 67/100 = **.670** |
| B | 8/10 = **.800** | 45/90 = **.500** | 53/100 = **.530** |

A는 층 1에서도 지고(.700 < .800) 층 2에서도 진다(.400 < .500). 그런데 전체는
A가 이긴다(.670 > .530). A는 성적이 좋은 층 1에 90%가 몰려 있고, B는 성적이
나쁜 층 2에 90%가 몰려 있기 때문이다.

#### 5.2 심슨의 역설

**발생 조건 세 가지.** 모두 갖춰져야 역전이 일어난다.

1. 층화변수 Z가 **결과와 연관**되어 있다 (층별로 비율이 다르다)
2. Z의 **분포가 비교 두 집단에서 다르다** (가중치가 불균형하다)
3. 그 불균형의 영향이 **층 내 차이보다 크다**

**"역설"이라는 이름은 오해를 부른다.** 수학적으로는 아무 모순이 없다. 진짜
문제는 하나뿐이다.

> **층별 결과와 전체 결과 중 어느 쪽을 믿어야 하는가?**

#### 5.3 그래서 어느 쪽인가 — 교란변수와 충돌부

**데이터만으로는 결정할 수 없다.** 층화변수가 인과 구조에서 어디에 있는지가
답을 정한다.

**경우 1: 교란변수(confounder) — 층화해야 한다**

```
            Z (층화변수)
          ↙   ↘
        X  →   Y
```

Z가 X와 Y의 **공통 원인**이면, 층화하지 않은 전체 비교는 Z의 효과에 오염되어
있다. **층별 결과가 맞다.**

- 버클리 대학원 입학(Bickel et al., 1975): 전체로 보면 남성 합격률 44%, 여성
  35%로 성차별처럼 보인다. 학과별로 보면 6개 중 4곳에서 여성 합격률이 더
  높다. **학과**가 교란변수다. 여성이 경쟁률 높은 학과에 몰려 지원했다.
- 신장결석 치료법(Charig et al., 1986): 전체로는 치료 B(83%)가 치료 A(78%)보다
  낫지만, 결석 크기로 나누면 두 경우 모두 A가 낫다. **결석 크기**가 교란
  변수다. 어려운 케이스를 A가 맡았다.

**경우 2: 충돌부(collider) — 층화하면 안 된다**

```
        X  →  Z  ←  Y
```

Z가 X와 Y의 **공통 결과**면, Z로 층화하는 순간 없던 상관이 생긴다. **전체
결과가 맞다.** 4.2의 타석 수가 이 경우다.

> **같은 통계량, 반대 처방.** 심슨의 역설은 보통 교란변수 문제이고, 버크슨의
> 역설은 충돌부 문제다. 숫자만 보면 구분할 수 없다. **인과 다이어그램이
> 필요하다.** 여기서 주제 2와 주제 3이 만난다.

#### 5.4 실측 근거 — KBO에서 찾은 심슨 역설

전 조합을 탐색해 실제 역전 쌍을 찾았다.

**좌완/우완 투수 스플릿** (11쌍 발견)

| | 우완 상대 | 좌완 상대 | **전체** |
|---|---|---|---|
| 홍창기 | **.336** (37/110) | **.2031** (13/64) | **.287** (50/174) |
| 하주석 | .332 (67/202) | .2027 (15/74) | **.297** (82/276) |

홍창기가 우완·좌완 상대 모두 높은데 전체 타율은 낮다. 홍창기의 좌완 상대
타수 비중(37%)이 하주석(27%)보다 커서, 타율이 낮은 좌완 스플릿에 가중치가
더 실렸다. 단 좌완 스플릿 차이는 소수 네째 자리에서만 갈리므로 실질적으로는
동률에 가깝다.

**전·후반기 스플릿** (50쌍, 최대 역전폭 .035)

| | 전반기 | 후반기 | **전체** |
|---|---|---|---|
| 한태양 | **.333** (17/51) | **.257** (46/179) | **.274** (63/230) |
| 김도영 | .330 (33/100) | .100 (1/10) | **.309** (34/110) |

> **수업에서 쓸 때의 단서:** 김도영의 후반기는 10타수뿐이다(부상). 이 점을
> 반드시 밝혀야 한다. 오히려 **극단적 표본 불균형이 심슨 역설의 엔진**이라는
> 핵심을 설명하기 좋은 지점이다.

**정직한 음성 결과.** 홈/원정 스플릿으로는 122명을 탐색해 역전 쌍이 **0개**
였다. 홈과 원정 타수는 선수마다 대체로 균형을 이루므로(조건 2가 성립하지
않는다) 역전이 일어나지 않는다. **역설이 나타나지 않는 조건**을 보여주는
대조 사례로 쓸 수 있다.

전반적으로 한 시즌 데이터의 역전폭은 최대 .035로 크지 않다. 고전적 사례
(지터·저스티스, 2년 합산 .040)만큼의 극단적 타수 불균형이 한 시즌 안에서는
잘 생기지 않기 때문이다.

#### 5.5 윌 로저스 현상

**정의.** 한 개체를 A집단에서 B집단으로 옮겼을 때, **두 집단의 평균이 모두
오르는** 현상.

**조건.** 옮기는 개체의 값이 A의 평균보다 낮고 B의 평균보다 높으면 된다.

```
  B평균  <  옮기는 값  <  A평균
```

**최소 예시.**

```
  A = {10, 8, 6}  평균 8        B = {4, 2}      평균 3
                   6을 A에서 B로 옮긴다
  A = {10, 8}     평균 9 ↑      B = {6, 4, 2}   평균 4 ↑
  전체 = {10, 8, 6, 4, 2}  평균 6  (변화 없음)
```

**이름의 유래.** "오클라호마 사람들이 캘리포니아로 이주하면 두 주의 평균
지능이 모두 올라간다"는 윌 로저스의 농담에서 왔다.

**의학의 고전 사례(Feinstein et al., 1985).** CT 도입으로 폐암 진단이 정밀해
지자, 과거 1기로 분류됐던 환자 중 미세 전이가 발견된 사람들이 2기로 재분류
되었다.

- 1기 생존율 상승 (중증자가 빠져나감)
- 2기 생존율도 상승 (상대적 경증자가 들어옴)
- **전체 생존율은 변화 없음** (치료법은 그대로다)

이를 **병기 이동**(stage migration)이라 하고, 진단 기술이 바뀐 시기를 걸친
생존율 비교를 무효화한다.

**실측 근거.** 200타석 이상 112명을 상위 12명(A, 평균 .3236)과 나머지
100명(B, 평균 .2592)으로 나눈 뒤 리베라토(.313)를 A에서 B로 옮기면

- A: .3236 → **.3246** (+.0010)
- B: .2592 → **.2598** (+.0005)
- 전체: **변화 없음** (선수 구성이 같다)

변화폭은 작지만 방향은 정확히 이론대로다. 집단 크기가 작고 평균 차이가 클
때 효과가 커진다.

**경고.** "모든 하위 집단의 지표가 개선되었다"는 보고는 전체 개선의 증거가
**아니다.** 분류 기준이나 분모가 바뀌지 않았는지 먼저 확인해야 한다.

#### 5.6 핫핸드 착각 — 층화하지 않은 풀링

**주장.** "안타를 친 타자는 다음 타석에서도 잘 친다(hot hand)."

**풀링한 데이터.**

| 조건 | 타율 | 타수 |
|---|---|---|
| 직전 타석 안타 | **.2702** | 12,775 |
| 직전 타석 아웃 | **.2587** | 35,949 |

차이 **+.0115**. "핫핸드가 있다"로 읽힌다.

**그런데 두 집단의 구성이 다르다.** "안타 뒤 타석"은 잘 치는 타자에게 더 많이
생긴다. 즉 이 비교는 **서로 다른 타자 구성**을 비교하고 있다. 선수를 층으로
잡아 다시 계산하면

```
  풀링 차이               : +0.0115
  선수 내 차이의 가중평균 : +0.0091   (100명)
  선수별 차이의 부호      : 양수 58명 / 음수 42명   ← 동전 던지기 수준
```

**정확히 심슨의 구조다.** 개체 내(within) 변동과 개체 간(between) 변동을
분리하지 않으면, 개체 간 차이가 효과로 위장한다.

**연속 안타 관점에서도 확인된다.**

| 연속 안타 | 실제 관측 | 독립가정 기대 | 관측/기대 |
|---|---|---|---|
| 4연속 이상 | 190회 | 186.6회 | 1.02 |
| 5연속 이상 | 44회 | 52.4회 | 0.84 |
| 6연속 이상 | 7회 | 14.9회 | 0.47 |

관측이 독립가정 기대치와 같거나 오히려 적다. 연속 안타는 우연이 만들어내는
정확한 분량이다.

> **정직한 단서 — 이 분석 자체에도 함정이 있다.** Miller와 Sanjurjo(2018)는
> 유한한 수열에서 "안타 뒤"를 조건으로 잡아 비율을 계산하면 **구조적으로 아래
> 방향 편향**이 생긴다는 것을 증명했다. 핫핸드 연구의 고전(Gilovich, Vallone,
> Tversky, 1985)이 이 편향 때문에 핫핸드를 과소평가했다는 것이다. 위의
> +0.0091도 같은 편향을 받는다. **"핫핸드는 없다"보다 "풀링만으로는 판정할 수
> 없고, 층화해도 편향 보정이 더 필요하다"가 정확한 결론이다.** 수업에서
> 이 단서까지 다루면 "역설을 아는 것"과 "올바르게 분석하는 것"의 거리를
> 보여줄 수 있다.

**일반 원리.** 같은 개체를 반복 관측한 데이터에서 그냥 풀링하면 개체 간
차이를 효과로 오인한다. 층화, 고정효과 모형, 다수준 모형이 해법이다.

### 6. 세 주제의 연결

| | 주제 1 | 주제 2 | 주제 3 |
|---|---|---|---|
| **놓친 질문** | 누구를 골랐나 | 어떻게 뽑혔나 | 어떻게 합쳤나 |
| **핵심 수식** | Var(X) = Var(θ) + Var(e) | E_size[X] = μ + σ²/μ | p = Σ w_i p_i |
| **틀리는 지점** | 우연을 효과로 읽음 | 표본 평균 ≠ 모집단 평균 | 부분의 대소 ≠ 전체의 대소 |
| **진단** | 사전값 vs 변화량 상관 | 표집확률·관측단위 점검 | 층화해서 재계산 |
| **교정** | 대조군, 축소추정 | 역가중, 모집단 재정의 | 층화, 인과 구조 규명 |

한 문장씩 요약하면 다음과 같다.

1. **극단값은 다시 극단이 아니다.** 선택이 우연을 신호로 위장한다.
2. **표본은 모집단의 축소판이 아니다.** 뽑힐 기회가 균등했는지 먼저 묻는다.
3. **전체는 부분의 요약이 아니다.** 가중치가 결론을 만든다.

그리고 세 주제가 공통으로 요구하는 태도는 하나다. **데이터를 낳은 과정을
모형화하라.** 숫자만으로는 어느 것도 판정할 수 없다.

### 부록 A. KBO 수치의 계산 방법

모든 수치는 `datasets/kbo_dashboard.sqlite3`의 `plate_appearances`(56,139행)와
`pitches`(217,970행) 테이블에서 계산했다. 재현 스크립트는 아직 저장소에 커밋
되어 있지 않다.

| 수치 | 계산 방법 |
|---|---|
| 전·후반기 타율 | `game_date`를 2025-07-01 기준으로 분할, `is_ab`/`is_hit` 집계 |
| 실력 sd 추정 | Var(관측) − mean(p(1−p)/n). 표집분산을 빼서 실력분산을 남긴다 |
| James–Stein ρ̂ | 아크사인 분산안정화 후 1 − (k−3)/Σ(y−ȳ)² |
| 타석당 투구수 (A) | `pitches`를 (`game_pk`, `at_bat_number`)로 묶어 개수의 평균 |
| 크기 편향 평균 (B) | Σn²/Σn (= E[X²]/E[X]) |
| ISO | 총루타/타수 − 타율 |
| 좌·우완 구분 | `release_pos_x` 부호. 투수 내 일관성 98.9%, 우완 146 : 좌완 54 |
| 연속 안타 기대치 | 선수별 p에 대해 p^L·(1 + (n−L)(1−p)) 합산 |

**주의 사항**

- `inning_topbot`의 값은 소문자 `top`/`bot`이다. 대문자로 비교하면 모든 행이
  한쪽으로 분류되어 조용히 틀린 결과가 나온다.
- 좌·우완 구분은 `release_pos_x` 부호에서 **복원한 추정치**이며 원본 데이터에
  투수 투구손 컬럼이 따로 있는 것은 아니다.
- 연속 안타는 경기 경계를 넘어 타석 순서대로 이어 세었다.
