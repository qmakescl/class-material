읽는 법

  • 코드는 왼쪽에 R, 오른쪽에 Python을 나란히 둔다. 같은 줄 높이의 코드가 같은 일을 한다.
  • 장마다 R용과 Python용 노트북을 하나씩 만들고, 가이드의 코드를 직접 입력해 실행한다.
  • 주황색 상자는 자주 틀리는 곳이다. 점선 상자는 아직 확정되지 않은 초안 메모다.

초안 상태

지하철 데이터의 열 구성은 2024년 파일의 앞 10행으로 확인했고, 2025년 파일도 같다고 가정했다. 2025년 파일의 날짜 표기(YYYY-mm-dd)와 인코딩(EUC-KR)은 알려주신 내용을 따랐다. 2~6장의 Python 코드는 같은 구조로 만든 연습용 가상 데이터에서 끝까지 실행해 보았다. R 코드와 기상 파일의 열 이름은 아직 확인하지 않았다. 2025년 실제 데이터로 계산한 결과표와 그림은 들어 있지 않다.
