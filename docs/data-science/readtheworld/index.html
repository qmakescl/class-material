지하철과 날씨로 배우는 R·Python

비 오는 날, 더운 날에 지하철 승객은 어떻게 달라질까? 이 질문 하나에 답하기 위해 2025년 한 해의 실제 데이터를 찾고, 읽고, 다듬고, 요약한다. 모든 작업을 R과 Python 두 가지로 나란히 해 본다.

대상
프로그래밍을 처음 하는 비전공 학생
도구
VS Code, Jupyter Notebook, AI 에이전트
주 데이터
서울교통공사 역별 일별 시간대별 승하차인원, 2025년
함께 쓰는 데이터
기상청 종관기상관측 일 자료, 서울 지점, 2025년
분석 기간
2025년 1월 1일~12월 31일(365일)

차례

  1. 1

    작업환경 구축

    R을 설치하고, uv로 Python 3.12 가상환경을 만들고, VS Code에서 두 언어의 노트북을 실행한다.

    결과물: R·Python 커널이 연결된 프로젝트 폴더

  2. 2

    데이터셋 가져오기

    질문에 맞는 공공데이터를 직접 찾아 내려받고, 노트북으로 읽어 들인다.

    결과물: dataset/raw 의 2025년 지하철·기상 원본 파일

  3. 3

    R과 Python의 데이터 다루는 명령

    고르기, 거르기, 그룹 요약을 익히고, 정규표현식과 날짜 자료형을 다룬다.

    결과물: 날짜형으로 바꾼 표와 두 언어 대조표

  4. 4

    데이터 전처리

    원본을 점검하고, 하루 단위로 요약하고, 기상 데이터와 조인한다.

    결과물: dataset/working/daily.csv

  5. 5

    기초 통계 구하기

    평균과 퍼짐, 분포, 집단 비교, 상관을 구하고 그림으로 확인한다.

    결과물: 요약표와 그림 세 장

  6. 6

    데이터로 인사이트 얻기

    비 오는 날 승객이 줄어드는지 확인하고, 각자 질문 하나에 답한다.

    결과물: 한 문단과 그림 한 장

  7. 과

    과제: 시간대로 나누어 다시 보기

    표를 긴 형식으로 바꾸고, 날씨의 영향은 낮 시간대에서 봐야 한다는 주장이 맞는지 자기 그림으로 판단한다.

    결과물: 시간대별 그림 두 장과 설명 한 쪽

읽는 법

  • 코드는 왼쪽에 R, 오른쪽에 Python을 나란히 둔다. 같은 줄 높이의 코드가 같은 일을 한다.
  • 장마다 R용과 Python용 노트북을 하나씩 만들고, 가이드의 코드를 직접 입력해 실행한다.
  • 주황색 상자는 자주 틀리는 곳이다.
  • 코드 옆의 # 365 같은 숫자는 실제 파일에서 나와야 하는 값이다. 다르게 나오면 앞 단계를 다시 본다.

데이터 출처

이 가이드는 가상 데이터를 쓰지 않는다. 아래 두 공공데이터의 원본 파일을 각자 내려받아 쓴다. 파일을 이 자료실에서 다시 나눠 주지 않으므로, 2장의 안내에 따라 직접 받는다.

자료제공받는 곳내려받을 때
서울교통공사_역별 일별 시간대별 승하차인원 정보, 2025년 파일서울교통공사서울 열린데이터광장파일내려받기의 2025년 파일
종관기상관측(ASOS) 일 자료, 서울(108) 지점, 2025-01-01~2025-12-31, 평균기온·최고기온·일강수량기상청기상자료개방포털회원 가입과 로그인이 필요하다. 고를 항목은 2장의 화면 참고

2~6장의 코드는 위 두 파일로 R 4.6(tidyverse 2.0)과 Python 3.12(pandas 3.0, matplotlib 3.11)에서 처음부터 끝까지 실행해 확인했다(2026년 10월).
